# 功能与结果

## 操作参数

| 入口 | 主要参数与限额 |
| --- | --- |
| `press_keys` | keys为1～5的非重复通道；press_ms与release_ms各10～60000；count为1～1000；总时长≤600000ms |
| `run_key_sequence` | 每步mask为0～31，duration_ms为10～60000；最多128步；repeat为1～1000，总时长≤600000ms |
| `power_select` | source为off、battery或external；控制信号先断后通，不保证设备立即完全掉电 |
| `charge_set` | enabled为布尔值；只有真实电池供电且未切换时可开启 |
| `uart_configure` | 9600、19200、38400、57600、115200、230400、460800、921600；固定8N1，配置前禁TX |
| `uart_tx` | enabled为布尔值；禁用等待发送结束，最多5秒，超时明确为未确认禁用 |
| `uart_write` | data_hex为偶数长度十六进制，最多4096字节；拒绝无意的文本转义和超限拆分 |
| `read_data` | measurements、uart、events三个独立游标；after为上次next，limit最多500条 |
| `job_status` | 用request_id查询后台记录；action_id是另一个板上动作编号 |
| `cancel_keys` | 传板上action_id和独立取消请求request_id；取消成功后原按键任务变为cancelled |

这些是当前软件限额，物理触点时序和持续吞吐仍需实测。输入参数必须符合工具额定条件；外部电源自身的调压、限流由其专用工具负责。

## 任务与异常

`accepted` 表示后台已记录；`running` 表示执行中；`succeeded` 表示取得该操作的执行完成证据；`cancelled` 表示原动作被取消；`failed` 不保证此前没有任何影响；`unknown` 表示证据不足。设备状态查询失败不会否定已保存的成功证据。

重复请求编号只可指向原内容和设备。固件保留最近64个变更请求；超出保留范围不能把查不到解释成未执行。电脑端保存任务日志，重启后未完成项标为未知，不自动重新下发。

接管操作权要同时提供 `device_status.control.revision` 与 `device_status.device_state.revision`，即后台和设备两个版本。会话失联后输出保持，写权不自动移交。重新连接原工具后先查状态，再显式申请或接管；同一设备同一启动的采集游标继续，重启则形成新数据段并报告缺失。

记录目录包含测量JSONL、事件JSONL、串口BIN及串口索引。二进制文件与索引配套使用，索引携带设备/启动身份、字节位置及缺失情况。停止显示不影响原始记录，停止记录后检查状态是completed还是failed。

## 校准与时序

0.1.1按实装INA226提供电池电压/电流，电流步进125µA、电压步进1.25mV。原INA228电池通道的校准记录会标为无效，须在实际芯片上重新校准；ADS1115四路记录格式保持。芯片未校准失调上限在手册规定条件下折合约±500µA，不能把名义零读数或增加显示小数位解释为通过±100µA整机精度验收。

1. 在已知接线、参考仪表和稳定输入下取得两组名义值x1/x2与参考值y1/y2，x1不能等于x2。
2. 计算 `gain=(y2-y1)/(x2-x1)`，`offset=y1-gain*x1`。电流使用A，电压使用V；校准记录写明仪表、点位、温度和日期。
3. `calibration_set` 只保存一个通道；设定min_value/max_value为实际验证区间。继续用其他独立点验证，不能用两个拟合点证明整个量程精度。
4. 近零前端饱和/非线性不能靠单一偏移恢复，准确下限待实测。不自动扣除测量接入负载。
5. `set_switch_timing` 设置本次启动先断后通间隔10～1000ms；100ms为未实测工程初值，重启恢复。应通过实际MOS关断波形确定参数；软件计时测试不等于物理关断验证。

工具没有自动过流关断、主动放电、自动换源或掉电隔离保证。校准系数应用成功与硬件额定精度通过分别报告。
