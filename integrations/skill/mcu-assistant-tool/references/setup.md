# 安装与连接

本 Skill 随 MCU TOOL 完整工程交付，单独复制说明文件不能启动硬件能力。首版使用 Windows、Python 3.11 及 Node.js 22；辅助 `.ps1` 脚本用PowerShell 7运行，日常启动直接使用Python。具体依赖由工程锁文件固定。

1. 在工程目录运行 `scripts/install.ps1`，完成项目 Python 环境与网页构建。
2. 双击 `启动工具.cmd`，打开本机网页。共享后台仅监听回环地址，默认端口8766。
3. 参考工程 `integrations/mcp.example.json` 配置 AI 客户端；`command` 和 `--data-dir` 必须指向实际工程绝对路径。不覆盖已有其他 MCP 配置。
4. 此 Skill 文件夹可复制到客户端支持的 Skill 目录，或由用户显式引用。MCP 命名空间由客户端配置决定，工具名以 `ping` 返回清单为准。

电脑端项目数据保存在 `.mcutool/`；其中 `runtime.json` 含本机访问凭据，不写入报告或分享。日志和记录也不应在未经检查时上传。移动工程后更新 MCP 绝对路径。

首次连接需明确设备。USB 选择工具的原生 USB Serial/JTAG 端口，握手后核对设备身份；已有网页连接可直接 `connect()` 复用。切换 USB/Wi-Fi 需要明确断开及重新连接，不自动换通道。

Wi-Fi 首次配置可在 USB 连接下通过网页“设备设置”保存网络。也可连接工具首次启动或长按 CONFIG 三秒开启的 `MCUTOOL-xxxxxx` 热点，密码 `mcutool-setup`，访问 `http://192.168.4.1/setup`。配置成功后热点关闭；正常网络失联不会自动开热点。设备地址从 USB 网络状态或路由器获得，访问令牌从 USB 状态或配网页面获得；令牌不写入普通操作记录。

已有后台不可达时，先读取本机状态和日志；不另开原始串口、杀掉所有 Python 进程或清空活跃锁文件。任务结果未知时先查询记录。后台不兼容或配置路径错误时明确修正环境，不通过另一套连接实现绕过。
