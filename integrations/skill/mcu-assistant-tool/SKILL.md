# MCU TOOL 使用入口

通过本工具操作被测设备，按具体项目解释日志与判定结果。MCP 工具清单和参数以当前 schema 为准；功能与额度先看 `ping` 和连接后的设备能力。

## 连接与观察

1. `runtime_status` 只查现有后台；`connect()` 附着同一后台，网页已连接设备时复用其选择。后台尚未运行时，明确的 `connect` 会启动本机共享后台，但不会自行选择硬件。
2. 未连接设备时，`discover_devices` 只枚举端口。按用户明确的工具端口或 Wi-Fi 地址调用 `connect(kind=..., port=... / address=..., token=...)`。候选 ESP USB 端口不等于已验证工具，多设备时不能选第一台。已有连接且参数冲突时保持原设备。
3. `device_status` 查看设备身份、启动标识、控制状态、数据时间和校准状态。正常读取不需要操作权，也不停止他人的采集。
4. 连续数据使用 `read_data(kind, after, limit)`，保留各数据类型自己的 `next`。读取不会消耗其他客户端的数据；检查 `lost`、事件和后台 `instance_id`，后台重启后旧游标不可继续使用。

Skill 只提供使用规范，需要完整软件及 MCP 配置。首次安装或移动目录时查[安装与连接](references/setup.md)。

## 操作与任务

- 修改设备前调用 `claim_control()`。已有操作者时先查询状态，只有用户允许交接才使用 `takeover=true`，传入刚观测的后台及设备状态版本。有在途动作时不能接管。用户已授权的测试流程不必为每个常规步骤重复确认。
- 每个写操作先生成并保存独立 `request_id`。调用返回已受理/执行中时，用 `job_status(request_id)` 取得终态；超时不表示未执行。`job_reconcile` 只查询已知板上动作的执行证据，不重放操作。结果未知时先核对状态和项目证据。
- 按键由板上计时，使用 `press_keys` 或 `run_key_sequence`；不要用网络等待拆成按下/释放。取消使用 `cancel_keys`，仅释放该动作的按键。
- `power_select` 只选择供电通路，不调节外部电源。`charge_set(true)` 要求真实电池通路；切换/关闭主供电前先显式关充电。关闭通路不代表电压立即为零。
- UART 默认为 TX 高阻，RX 独立接收；发送前显式 `uart_tx(true)`，被测设备掉电前显式禁 TX，并确认完成。发送完成不表示对端处理成功。`uart_write` 为十六进制原始字节，文本需按项目编码转换，不自动附加换行或拆分超限消息。
- `recording(start/stop/status)` 控制电脑端原始记录。显示暂停、关闭网页及 `detach` 不停止已开启的记录。磁盘失败或缓存丢失必须披露。原操作者失联且无在途任务时，可在用户明确要求下，用最新后台版本显式停止无人记录；这不取得硬件操作权。
- 正常完成本客户端任务后，按用户意图释放自己的操作权并 `detach`。`disconnect` 影响共享设备通信，只有明确需要时才调用；不把退出会话当作关闭供电或取消动作。

具体操作参数、限额和错误处理见[功能与结果](references/operations.md)。

## 电气与数据含义

- 按键触点：五路独立、无极性，目标≤6V/20mA。主供电目标2.8～12V、双向3A；独立充电输入5V/2A；电压测量范围与供电范围分别定义。
- 电池端电流正值为经分流器向被测设备供电，包含经过该通路的接入负载。电池接口电压是工具输出端测点，不包含外接线缆压降。
- 当前实板为INA226＋20mΩ，电流名义步进125µA、电池电压1.25mV；原INA228小电流精度目标不能直接沿用。稳定测量约1Hz，四路电压顺序采样；INA226平均结果可能包含动作前数据。检查采样窗口与质量，不能据此判断瞬间尖峰或同步波形。
- 未校准、校准损坏、超范围、过期、传输缺失和有效零值各自有含义。不得把缺失填成零，不把未校准名义值解释为满足额定精度。近零电压准确下限尚待实测。
- 校准只使用参考仪表证据；读[校准流程](references/operations.md#校准与时序)后操作，不能为了读数好看编造系数。
- 网络故障不改变供电/充电，已接收的定时按键继续执行。失败按原始错误和任务证据处理，不自动换通道、降级协议或重放写操作。

工具自身 USB 与 DC 供电人工二选一。当前软件交付不等于实物精度、开关时序、温升及UART电气表现已经验收。
