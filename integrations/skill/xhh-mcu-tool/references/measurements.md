# 测量与区间分析

用于查看读数、分析波形、比较按键/供电前后状态，或计算区间最大值、最小值、平均值和净电量。

## 先分清显示与测量

0.4.1 的双轴、A/B 游标、颜色、每格电压和显示偏移属于界面状态。它们不改变设备采样或原始数据；曲线隐藏、暂停显示不停止采集。四路名称单选只决定当前 Y 轴刻度和实线标识，其他曲线各自使用独立比例。

电池图和四路图各自保留最近4小时、各自暂停/开始、清空及导出CSV；清空只作用于对应图表，记录文件保持。CSV包含该组全部保留采样（包括隐藏曲线），电流单位A，暂停时导出冻结历史。显示历史在页面刷新后重新建立，不等于后台缓存或持久记录。

实时状态下滚轮缩放保留最新采样跟随；拖动回看历史后可“回到实时”，保留时间跨度。开始显示也恢复实时跟随。界面删去长说明，完整含义以使用说明和本Skill为准。

MCP 当前提供原始测量和记录接口，没有“设置图表颜色”“读取界面 A/B 游标”或直接“计算容量”的工具。AI 分析使用 `device_status`、`read_data` 或用户指定的原始记录文件。用户只要求调整显示偏移时，不能调用 `calibration_set`。

## 获取数据

| 内容 | 入口与关键字段 |
| --- | --- |
| 当前六路读数 | `device_status().latest`，检查 `value`、`unit`、`quality`、`stale`、`age_ms` |
| 持续测量 | `read_data(kind="measurements", after=上次next, limit=...)` |
| 对照按键、供电和缺失事件 | `read_data(kind="events", after=事件next, limit=...)` |
| 已保存记录 | `测量.jsonl`、`事件.jsonl`、`会话.json`；会话元数据确认记录是 completed 还是 failed |

先确定用户要分析的时间段与被测设备状态。已有清楚的“最近一分钟”或绝对采样时间时直接按该范围取数；仅给界面上的 A/B 数字时，还要确定该页面对应的采样起点。

为每个数据类型分别保存 `next`，读取下一页直至覆盖所需区间；每次检查 `lost` 和 `instance_id`。后台缓存有界，`after=0` 不保证取得整个测试过程。长时间测试应在授权范围内提前开启原始记录。

同一统计区间必须属于同一 `device_id` 和 `boot_id`。`t_us` 是工具板采样时钟的微秒数，`received_at` 是电脑收到数据的时间，不能互相替代。后台重启后旧读取游标不再沿用；新设备/启动的数据单独分析。

## 单位与完整性

- `battery_v` 和 `ain1`～`ain4` 原始单位是 **V**；`battery_i` 原始单位是 **A**，网页显示为 mA。只转换一次，`I_mA = I_A × 1000`。
- 按通道、采样时间排序；重复读取的同一记录去重。与 0.4.1 界面核对时，同一时间的记录使用较新的后台 `cursor`。
- `value=null`、非有限值、`sensor_error`、`invalid_calibration`、`out_of_range` 不作为有效统计点。`uncalibrated` 可以按名义值分析，但保留未校准说明；`outside_calibrated_range` 要说明已超出校准验证范围。
- 固件0.1.2的10Hz数据相邻有效采样间隔超过 **0.25 秒**、中间出现无效点或明确丢样时，断开区间，不跨缺口插值或积分。这是当前软件连续性判据，不是丢样不存在的证明。旧版本记录须先核对原采样配置，不能把新判据直接套用于旧的1Hz数据。
- 读取返回 `lost`、事件记录测量丢失或文件状态为 failed 时，先定位缺失与所选区间的关系；无法排除其影响，就不把结果报告为完整区间统计。缺失不能补成零。
- 获取游标读数需要同一连续段内的有效样本覆盖两侧；区间之外不外推。只取得区间内部样本而没有覆盖 A、B 边界时，不宣称完成该完整区间的计算。

## 计算口径

对用户指定的 A～B 区间，使用相邻有效采样之间的线性插值求边界值；最大/最小值覆盖边界和内部有效点。

- 时长：`Δt_s = (t_B_us - t_A_us) / 1_000_000`，必须大于 0。
- 区间积分：每段使用梯形面积 `Σ((x_i + x_i+1) / 2 × Δt_i_s)`。
- 时间加权平均值：区间积分除以区间总时长。采样不等间隔时，不用普通算术平均代替。
- 净电量：原始电流单位 A 时，`Q_mAh = Σ((I_i + I_i+1) / 2 × Δt_i_s) × 1000 / 3600`。若已转换为 mA，则只除以 3600。

保留电流正负号；正值表示经测量通路向被测设备供电，负值表示反向流动。充入与流出会在净电量中抵消。净电量不是电池标称容量或剩余电量；用户若要求单独累计充入或流出电量，先明确这种口径，不把绝对值积分称为净电量。

例：持续 60 秒的 12 mA 电流，净电量为 `12 × 60 / 3600 = 0.2 mAh`。包含负电流时必须保留符号。

## 观察动作结果

动作成功只说明控制执行完成。把操作事件时间与后续测量、串口和项目判定条件对照。每路固定10Hz，四路电压顺序采样；电池传感器平均窗口可能跨过操作时刻。使用采样窗口及质量判断读数是否主要反映动作之后的状态，不用这些曲线推断瞬时尖峰或严格同步关系。

报告至少给出：设备/启动、区间和时间单位、数据来源及完整性、校准状态、统计值及单位。无法计算的通道明确列出原因，其他通道的完整结果可分别报告。
