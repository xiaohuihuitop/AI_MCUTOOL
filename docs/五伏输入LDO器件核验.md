# 五伏输入LDO器件核验

> 2026-11-04更新：用户最终确认U3采用微盟ME6211A33PG-N（C236673，标称500mA），输入/输出各10µF陶瓷电容，前级SS34保持。本文保留ST LDL1117选型历史；当前以[替换核验](工具电源C236673替换核验.md)为准。旧0.75A不再作为当前能力，也不是实际持续耗电。

日期：2026-10-23。用户已确认取消工具12V输入，DC与Type-C统一使用5V/2A，并将工具内部电源改为LDO。本文件仅核验5V输入隔离之后的3.3V LDO，不修改入口、固件或DUT供电行为。4.75V、5.0V、5.25V为板端工程核验点，不在此新增输入额定承诺。

**推荐原理样机采用ST LDL1117S33R，SOT223、固定3.3V、1.2A。** 相比传统1117，它在1.2A、VOUT>2.5V、−40℃<TJ<125℃条件下给出600mV最大压差；当前入口方案的低端余量足够。主要待闭合项是0.75A持续负载下约1.2～1.55W的散热，以及现有大输出去耦和掉电反向电流。默认小焊盘不能据1.2A额定直接宣称达标。

本轮优先选择有明确高电流、全温压差上限的ST器件。AP完整包装编码为`AP7361C-33ER-13`；ER代表SOT223R，E代表另一引脚排列，不能凭“都是SOT223”直接互换。没有据旧预发布文档判定AP已停产，也没有核同口径报价。[S1第6、18页；S2第1～6、13页]

ST官方订购表列出`LDL1117S33R`，输出3.3V、标记LL33；授权分销商Mouser存在该准确料号产品页。本轮不把页面库存当作交期承诺，不据此编造采购费用。[S1第18页；S3]

补充核验的TI TLV767虽然明确支持1～220µF标称输出电容、有效容量≥0.5µF、ESR 2～500mΩ，且有接地散热焊盘，但1A全温最大压差为WSON/DRV **1.4V**、HVSSOP/DGN **1.5V**。按3.3V＋1%高端，WSON就需约4.733V，超过本轮入口4.645V算例，不能用0.9V典型压差或按电流线性缩放替代最大值。它也没有反向阻断保证，因此不替换ST，不继续扩展其他LDO。[S4第3～7、19～20页]

## 准确接线与样机外围

以下为ST SOT223官方**顶视图**。手册明确写明“**The tab is connected to VOUT**”，散热片不得接地。[S1第3页]

| 引脚/器件 | 连接与样机初值 |
| --- | --- |
| pin1，GND | 工具公共地；输入、输出电容地短接到该地回路 |
| pin2，VOUT | 工具3.3V轨，连接输出电容、模组及外围负载 |
| pin3，VIN | 两路LM66100隔离后汇合的5V输入节点 |
| Tab，大散热片 | **VOUT/3.3V网络**；通过宽铜及同网络导热过孔散热，不能并入GND平面 |
| CIN | 标称**4.7µF、16V、X7R**作为初稿；最终料号在最高实际输入、温度和容差下有效容量须≥1µF，保留偏压及瞬态余量 |
| COUT | 局部**4.7µF、10V、X7R**，采用ST正文推荐的输出陶瓷组合；与既有模组22µF及其他去耦共同核验实际容量、ESR和布局 |

该型号没有独立EN或可编程软启动引脚，输入供电后按芯片自身启动过程建立输出。不增加GPIO使能、自动供电识别、备用电源或新的协议。

## 电容、ESR及启动边界

ST明确要求**输入电容最小1µF**，推荐1µF输入与4.7µF输出作为稳定性、瞬态和面积的折中。正文还明确写出“Any good quality ceramic capacitor can be used”以及控制环路“is designed to work with an output ceramic capacitor”。因此4.7µF陶瓷输出是有原始资料依据的初稿；本轮输入取4.7µF给DC偏压下降和线路瞬态留余量，最终仍须确认有效容量≥1µF。[S1第7页]

对于3.3V型号，手册没有单独给出一个覆盖任意ESR和外部去耦的“最小有效COUT”数字。4.7µF是推荐标称组合，不能伪称为厂商已规定的最低有效值，也不能不查偏压就把4.7µF标称当作实际容量。具体电容选型需提供3.3V偏压下的容量及ESR曲线。

图20/21为5V及1.2V输出的稳定性图，横轴明确是**标称COUT**，纵轴为100kHz ESR；4.7µF附近下界在十几至约20mΩ量级，且区域随条件变化。不能将其伪写成3.3V全温保证区间，也不能仅凭这两张典型图把厂家正文推荐的正常陶瓷设计判为不可用。本机既有模组入口**22µF＋0.1µF**，不能视为不存在；它与局部4.7µF、其他去耦及走线共同形成实际输出网络，原理图和PCB按该明确组合做负载阶跃与振铃验证，不假设任意加大电容仍无条件稳定。[S1第7、12页；项目模组最小系统核验]

本轮不擅自在输出增加隔离电阻、磁珠或补偿网络。较大的输出储能可能改善一次负载阶跃，也会增加启动充电电流，并改变输入掉电后的反向电流条件；不能只凭瞬态看起来更平滑就认定稳定。

手册有无负载典型输出曲线，没有要求外加固定最小负载；但±3%精度条目的测试负载为10mA，负载调整率覆盖10mA～1.2A，不能据此宣称完全空载也有同一最大误差保证。不增加耗电假负载，样机直接验证空载、轻载、模组启动及Wi-Fi活动状态。[S1第6、8页]

输入4.7µF应与前级每路1µF及其他输入端电容联合核算，保持Type-C输入电容量预算方向；即使保守把两个入口1µF都计入并按各±20%计算，三者也约8.04µF，其他电容及寄生仍须加上，且实际端口可见路径由LM66100连接决定。输出电容经LDO启动充电产生的输入电流也要观察。当前没有完成USB/Type-C插入行为验证，不据该算例宣称合规。

## 低端压差与输出误差

按入口代理提供的保守条件：板端电压4.75V已经包含外部线缆压降，LM66100用3.6V档RON最大140mΩ、0.75A估算，LDO输入约`4.75−0.75×0.14＝4.645V`，板内走线压降另计。不能从适配器端标称值开始计算时漏掉线材，也不能在板端电压中重复扣除线损。

LDL1117的600mV压差上限在1.2A、VOUT>2.5V及全工作结温条件下给出；**其定义是输出已比名义值低100mV的位置**，不是仍保持完整输出精度的压差。因此`Vpre,min≥Vout,max＋Vdrop,max`只能作为必要的余量筛选，不能替代电气特性表的测试条件。[S1第6页]

以3.3V全温初始误差±3%、最大负载调整15mV及最多约0.7mV输入调整变化作保守预算：

| 项目 | 预算及条件 |
| --- | --- |
| 初始输出 | 3.201～3.399V，10mA、−40℃<TJ<125℃ |
| 负载变化 | 最大15mV，10mA～1.2A；预算按两方向加入 |
| 输入变化 | 最大0.02%/V；以约4.3V参考至5.25V变化计算约0.63mV，取0.7mV预算 |
| 合并静态预算 | 约**3.1853～3.4147V**，不含启动/负载瞬态及测量不确定度 |
| 压差筛选 | 3.4147＋0.600≈4.0147V，低于4.645V约0.63V；仍需扣板内压降 |

4.645V输入也高于主要电气测试的`VOUT＋1V`条件附近，明显优于前轮高压降入口。该预算采用1.2A条目保守覆盖0.75A规划，但仍须实测动态负载，不能把1.2A额定视为已验证的整机瞬态最大需求。

静态预算高端距AUP及ESP32的3.6V上限约185mV，必须留给上电及卸载上冲。低端约3.185V虽然仍在LM7705允许输入范围内，却低于其3.3V负轨测试条件；原−0.232V负轨和缓冲正偏置不能不经验证直接沿用。应联测正轨、负轨及接近0V的测量误差，不通过软件强制归零掩盖供电影响。

## 持续功耗与可实施的散热起点

`PLDO≈(VIN−VOUT)×IOUT＋VIN×IQ`，IQ全负载/全温表列最大500µA。为避免用最大入口压降反而低估热，最坏热预算不给前级压降记收益：[S1第6～7页]

| 条件 | LDO功耗预算 |
| --- | ---: |
| 板端5.0V、入口压降按0.105V、输出3.3V、0.75A | 约1.20W |
| 板端5.25V、入口压降暂按0、输出静态低端3.1853V、0.75A | 约**1.55W** |
| 同一高输入/低输出条件、1.0A | 约2.07W，不能沿用0.75A的热结论 |

手册列θJA=120℃/W、θJC=15℃/W；在缺少实际PCB热验证时，120℃/W不能支持本任务的持续功耗。例如1.55W乘120℃/W已达186℃温升，显然不能按默认小焊盘使用。正常工作结温上限为125℃；150℃绝对最大结温及约175℃热关断点均不是持续运行设计目标。[S1第5～7页]

**样机热设计目标：LDO附近局部环境≤50℃、实测等效θJA≤45℃/W。** 1.55W下结温估算约120℃，距125℃仅约5℃，必须检查元件及测量误差；这两个数是工程目标，不是SOT223封装自带保证。

可从以下布局起步：给OUT/tab安排约25mm×25mm连续铜区，背面提供相近面积的OUT铜区，优先2oz铜；用多颗导热过孔连接两面，避免只靠一条细输出线散热。孔径、数量、焊盘开窗及是否塞孔由PCB厂工艺确定。该面积是布板起点，**不能宣称必然达到45℃/W**；高温负载、其他发热器件、外壳与风流均会改变结果。OUT热岛和过孔属于3.3V网络，不能接GND，外加散热件也须考虑其电气电位。

验收时记录局部空气温度、封装与tab附近温度、输入/输出电压电流及热稳态时间，并按对应测点方法估算结温；不能把某一点板温直接当结温。实际若长期需要1A，局部环境50℃、125℃结温上限对应θJA需约36℃/W或更低，必须重新验证，不能拿0.75A测试代替。当前不增加自动降载或额外散热控制。

## 掉电反向电流与剩余验证

ST绝对额定列`VOUT≤VIN＋0.3V`，手册未给出反向阻断或Ioff最大保证。前级LM66100隔离外部输入下拉，原始入口4.7kΩ泄放也在隔离器之前；这降低了外部直接拉低公共输入节点的条件，却不等于LDO自身具有反向阻断。**正常拔除电源的VIN/VOUT衰减轨迹也必须验证**，尤其既有模组22µF及其他输出储能仍连接时。输入快速下降、外部接口注入3.3V或输出被外部供电均不能仅靠LM66100认定安全，也不能只测适配器端“没有电流”便排除LDO内部反流。[S1第5页]

本轮不擅自添加保护二极管、泄放电阻、自动断开或新的电源轨。正常拔除电源、输入快速拉低、外部接口仍连接及最大输出去耦条件下的反向路径是原理图定版前待闭合项；在未核准前不宣称任意掉电顺序均已支持。

芯片自带限流、SOA、过温及快速热梯度保护，出现保护后可能自行重试，这是器件固有行为，不是本工具新增的恢复策略。不能让样机依赖周期性热保护维持运行。首批至少验证0.75A热稳态、1A附近短时负载、模组实际启动/Wi-Fi瞬态、轻载与空载、总输出电容下的稳定性、正负轨及近零测量、掉电反流。
