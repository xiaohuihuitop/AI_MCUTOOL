# 供电接线与中文丝印核验

日期：2026-11-04。已保存到主工程 `D:\LCEDA\projects\AI_TOOL\AI_TOOL.eprj3`。

原理图第4～6页增加供电、测流及充电接线说明。PCB对应接口使用中文丝印，并保留位号和正负极性。

| 接口 | PCB中文名称 | 接线用途 |
| --- | --- | --- |
| J9 | 真实电池输入 | 接真实电池 |
| J10 | 可调电源输入 | 接模拟电池的外部可调电源 |
| J11 | 产品供电输出 | 接产品电池/供电端；1脚为正，2脚为公共地 |
| J12 | 充电器输入5V | 接独立5V充电器 |
| J13 | 产品充电输出 | 接产品充电口 |

主供电路径为：J9或J10 → MOS选择 → RSH1串联测流 → J11 → 产品。产品电流已从该路径采样，不需要另接测流线。充电路径为：J12 → 充电开关 → J13 → 产品充电口；产品电池端仍接J11。

同时补充按键1～5、电压1～4、串口3.3V、发TX/收RX/地、复位/下载/配置、电源/状态和工具电源名称。中文采用客户端内置黑体，主要供电接口字高1.4mm；其余标签约1.05～1.2mm。调整文字位置以避开焊盘、元件包络及板边。
