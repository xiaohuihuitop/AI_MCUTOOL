## 客户端接口注意事项

本轮实测发现，文件同步后旧图页可能继续返回缓存几何，因此关键检查包含保存、关闭图页并重开后的回读。不能只检查文件已写入或 API 返回 `ok:true`。

4.1.78 的 `startAutoRouting` 作业接口曾返回空任务 ID；普通 `autoRouting` 已用于本轮分批布线。`ok:true`、成功网络计数或调用超时都不能代替实际连接与 DRC 验收。覆铜边框锁定会影响重铺，应先核对锁定状态。本轮通过官方图元接口、原生布线器、覆铜重建及保存重开检查完成，没有直接改写工程源码。
