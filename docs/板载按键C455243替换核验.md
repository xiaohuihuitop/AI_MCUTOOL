# 板载按键C455243替换核验

日期：2026-11-04。按用户指定，将工具自身RESET、BOOT和CONFIG三颗实体按键统一为C455243；仅修改嘉立创专业版本地工程第2页原理图，PCB最后统一更新。

## 当前器件及连接

三颗均为讯普TS-1009S-03826（C455243），四脚常开、单刀单掷轻触开关。正式库参数为本体4.5×4.5mm、高3.8mm、操作力2.6N，额定12V/50mA，适用于当前3.3V弱电按键。

| 位号 | 功能 | 1/2脚 | 3/4脚 |
| --- | --- | --- | --- |
| SW1 | RESET | ESP_EN | COMMON_GND |
| SW2 | BOOT | ESP_BOOT／GPIO0 | COMMON_GND |
| SW3 | CONFIG | CONFIG_KEY／GPIO17 | COMMON_GND |

采用正式库器件UUID `9181b8e9e8694e79b1b5b82dc3d36559`，绑定TS-1009S-03826专用符号、SMD四脚封装和3D模型。保留三颗原位号、实例ID、Unique ID及中心位置；按新符号脚距重接九组局部导线，信号端从符号上方绕接，避免导线穿过触点图形。

1/2脚接同一控制信号，3/4脚接公共地，按下时两组闭合；没有将同组常通端误当作按下才闭合的两端。R5/R6/R9及复位电容C7等保持型号和网络，按键动作及固件定义不变。

正式封装与旧TS-1187A模型不同；PCB同步时应更新焊盘并复核手册L/L1变型尺寸、朝向和外壳按压位置。本轮只完成原理图绑定与连接核对，不宣称已完成PCB机械验证。

- 全工程仍为138颗器件、411个逻辑引脚，原理图DRC为空数组。

- 正式供应料号、型号、实例ID、Unique ID核对通过；其余器件属性和几何不变，其他七页文件摘要不变。
- 新引线无异网交叉，原生图面已导出检查。
