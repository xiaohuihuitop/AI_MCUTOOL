# 五伏充电通路器件核验

> 2026-11-03更新：Q12/Q13已改为用户选定的AP60P20Q（C2828591），与主供电统一型号。原Q14三极管、10kΩ/100Ω/4.7kΩ/10kΩ驱动保持，5V/2A及充电互锁不变。当前连接和验证见[独立充电P-MOS统一型号核验](独立充电P-MOS统一型号核验.md)；下文保留CSD25402Q3A阶段的设计依据。

核验日期：2026-10-22。对象仅为独立 **5V 充电输入 → 受控开关 → 被测设备充电口**，保持仅切正极、共地、关闭时双向阻断、上电关闭、无主动放电；原设计目标为2A、板内总压降≤100mV、100ms量级动作。只有已确认的真实电池条件下才允许启用充电，控制不新增自动联动；开启状态不承诺主动逆流保护。

**建议原理样机：两颗 TI CSD25402Q3A 共源共栅 P-MOS＋onsemi MMBT3904LT1G 下拉栅极，RGS＝10kΩ、RG＝100Ω、RB＝4.7kΩ、RBE＝10kΩ。** GPIO13高有效。此方案利用5V通路自身提供栅源驱动，只适用于该充电通路，不替代0～15V、接近0V仍须受控的主供电开关。

TI官方产品页本轮显示“正在供货”；具体封装、引脚及参数已读取官方资料，仍需画图、样机及采购复核，没有报价或性能实测。

## 准确引脚和网络

**CSD25402Q3A：S＝5/6/7/8/9，G＝4，D＝1/2/3。** 2026-10-23按TI可见顶视图更正前轮错位的引脚记录，见 [MOS引脚图复核](MOS引脚图复核与连接更正.md)。封装为SON 3.3mm×3.3mm；第8页机械底视图明确大焊盘编号9，结合首页顶视图和第4页SOURCE散热铜区，9为Source。[S2] 两颗大焊盘均接SCOM_CHG，不能沿用主供电N-MOS CSD17577Q3A的Drain底盘映射。封装大焊盘须焊接，以满足官方热与机械要求。

| 网络/器件 | 逐引脚连接 |
| --- | --- |
| CHG_IN_P | 外接5V充电器正端，接Q1的D焊盘1/2/3 |
| DUT_CHG_P | 被测设备充电口正端，接Q2的D焊盘1/2/3 |
| SCOM_CHG | Q1和Q2的S焊盘5/6/7/8/9全部相连；接RGS一端 |
| GCOM_CHG | Q1和Q2的G焊盘4相连；接RGS另一端和RG一端 |
| RGS | **10kΩ/1%**，接GCOM_CHG与SCOM_CHG，驱动关闭时把VGS拉回0 |
| RG | **100Ω/1%**，GCOM_CHG → RG → MMBT3904 pin3(C) |
| GPIO13 / RB | GPIO13 → **4.7kΩ/1%** → MMBT3904 pin1(B) |
| RBE / NPN地 | **10kΩ/1%**接B与E；MMBT3904 pin2(E)接工具公共GND |
| 充电负端 | 外接充电器、工具和被测设备充电负端共地；不经P-MOS切换 |

P-MOS体二极管由各自Drain指向Source，因此两颗二极管都朝SCOM_CHG汇合，形成端口之间的反向串联。关闭时RGS使共栅跟随共源，正常正反向电压差不能通过完整通路；打开NPN后共栅被拉低，两个P-MOS都得到负VGS，沟道允许双向电流。[S2电气结构；电路分析]

SCOM_CHG会由较高电位端经过体二极管建立电位，不能把它当作工具3.3V或工具GND。端口电容也可能在关闭后保留电压；本方案不增加主动放电。

## 栅极驱动预算

NPN导通后，忽略瞬态的稳态关系为：

`|VGS|≈(VSCOM−VCE)×RGS/(RGS＋RG)`。

| RGS / RG | VSCOM＝5V、VCE预算0.3V时 | 静态从充电端取用的栅极偏置电流 | 取舍 |
| --- | ---: | ---: | --- |
| **10kΩ / 100Ω** | VGS幅值约4.653V | 约0.465mA | 首选样机初值，偏置负载较小 |
| 4.7kΩ / 100Ω | VGS幅值约4.602V | 约0.979mA | 被动关断的拉回电流更大，但偏置负载增加、稳态栅驱稍减小；实测需要时再调整 |

表内偏置电流在正常充电方向取自外接充电端，不计入工具3.3V供电预算。开启后若设备端反向供电，偏置电流来源应按实际路径核算；不能自动从电池读数扣除固定常数。开关关闭后，RGS两端接近等电位，不持续消耗该导通偏置电流。

以**4.75～5.25V作为5V适配器容差的计算示例**，并考虑输入侧MOS压降、VCE预算及电阻容差，低端|VGS|不一定仍≥4.5V，因此本轮按−2.5V处的最大RDS(on)保守核算。该电压示例不是新增已确认输入额定值，实际范围随适配器和输入设计核验。正常5V条件下|VGS|不应超过该输入电位量级，但仍需实测热插拔和米勒瞬态，不能把±12V绝对额定当作过压保护。

该NPN下拉结构不能覆盖接近0V时的低阻导通，也不能直接接入15V：低输入时缺乏栅驱，高输入时可能超过VGS额定。它只是已明确5V充电通路的简化驱动。

## NPN、门极动态与电阻功耗

MMBT3904LT1G引脚B1/E2/C3沿用此前已核官方资料。[S4] 工程预算取带载GPIO高电平≥2.4V、VBE≤0.95V、电阻1%，有：

`IB低端≈(2.4−0.95)/(4.7k×1.01) − 0.95/(10k×0.99)≈0.2095mA`。

按5.25V示例和最小电阻，RGS10k时稳态集电极电流粗上界约0.525mA，4.7k时约1.105mA，两个初值均有基极驱动余量。VCE≤0.3V仍是需实测的工程预算；手册的VCE(sat)值是在指定IC/IB、25℃脉冲条件下测得，不是任意长按/温度保证。GPIO的2.4V也不能用高阻VOH表格直接当带载保证。[S4、S5]

两颗TI MOS至−4.5V的Qg合计典型15nC、最大19.4nC。RGS10k关断时的拉回电流会随|VGS|减小而下降，Qg还含米勒过程；简单Qg/I或Ciss×RGS只能给量级直觉，不能当最大关断时长。RGS4.7k是否必要由实际关断、漏电和端口瞬态决定。

RG100Ω限制栅极下拉脉冲；5.25V/99Ω约53mA只是电路粗上界，实际电流还受基极驱动与NPN放大区限制。动态期间NPN的VCE可能高于稳态预算，不能拿手册纳秒级开关时间替代本电路波形。TI表列开关时间对应VDS＝−10V、VGS＝−4.5V、ID＝−10A、RG＝5Ω，与本项目不同。[S2第3页]

单路初始BOM：CSD25402Q3A×2、MMBT3904LT1G×1、10kΩ/100Ω/4.7kΩ/10kΩ各一颗，电阻1%、0603且额定≥0.1W作为样机起点。RG稳态耗散很小，但瞬态能力须结合实测脉宽及最终电阻脉冲曲线复核；RGS在5.25V示例下耗散仅数mW。连接器采用已确认2.54mm排针。

与复用主通路光伏驱动相比，此方案减少一颗VOM1271，电阻数量由三颗变为四颗；**不宣称元件总数或采购费用一定减少**。没有同口径报价，不能承诺具体节省金额。

## 压降和首要验证项

按CSD25402Q3A的−2.5V最大电阻15.9mΩ/颗、25℃条件估算：

- 两颗合计31.8mΩ；2A时压降 **63.6mV**、损耗约 **0.1272W**。
- 距整条充电通路100mV目标剩余约 **36.4mV**，用于温升、PCB走线及连接器；不能将全部余量视作线材预算，既定指标不包含外接线。
- 只有实测确保实际|VGS|≥4.5V并满足适用条件，才可采用8.9mΩ/颗的35.6mV估算。温升会增加RDS(on)，图8的温度曲线不是全温最大值替代品。
- TI表列IDSS幅值最大1µA@VDS＝−16V、VGS＝0；IGSS幅值最大100nA@VGS＝±12V，默认25℃。不据此宣称5V全温整机漏电已经达标。[S2第3、6页]

最先验证：

1. 外接5V电源先上电、工具先上电、工具断电、MCU复位及GPIO高阻时，两颗MOS是否都保持关闭。B-E下拉只能约束基极浮空，不能抵消GPIO主动高电平。
2. 充电器/设备端热插拔和残余电压引起的VGS/VDS瞬态，尤其共源跟随及米勒耦合是否造成短暂误导通；工具未供电时，NPN/保护/引线是否向GPIO或其他电源轨注入电流。
3. 在输入容差、工具3.0/3.3/3.6V及实际温度下验证GPIO带载电平、VCE、两颗VGS、导通压降、关断时间和双向漏电。
4. 对设备输入电容和线缆验证浪涌、线性区SOA及关断瞬态；TI第6页图10为规定条件的单脉冲SOA，**100ms动作预算不是允许MOS在线性区带大压降慢开100ms**。
5. 充电互锁和上电默认关闭由原有控制契约实现；电路打开后允许反向导通，不能把本方案当成主动逆流保护。无主动放电，关断动作完成不代表设备充电口电压已归零。
