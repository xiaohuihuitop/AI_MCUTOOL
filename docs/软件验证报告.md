## 6. 实物待验收项目

以下需要已装配工具板、被测负载和参考仪表，尚未执行。软件提供了对应操作和校准入口。

1. **启动与通信**：确认N16R8实际启动、原生USB枚举、Wi-Fi配网、设备身份一致性、重启行为及长时间运行；检查启动/复位全过程的按键、供电、充电和TX引脚状态。
2. **按键和供电**：用示波器或逻辑分析仪检查五路按下/释放及组合时序；测量MOS先断后通、反向阻断、压降、温升和带载切换。根据实测确定间隔，不能直接把100ms初值认作验收结论。
3. **测量和校准**：使用参考仪表进行电池接口电压、正负电流和四路外部电压校准，另取独立点验收；确定近零准确区间、温漂与测量接入自负载，不能只验证两点校准能保存。
4. **UART物理表现**：核对实际波特率、连续收发、禁TX等待完成、TX高阻、复位和不同上电顺序下的反灌情况。
5. **整机持续运行**：实板验证USB/Wi-Fi失联后保持输出、板上定时动作继续、缓存覆盖报告、重连数据边界以及电脑记录完整性。

开始实物验证时按照[使用说明](软件使用说明.md)确认端口和接线，USB供电时不同时接DC。尚未执行任何自动烧录或未知设备操作。
