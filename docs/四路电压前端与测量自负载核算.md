# 四路电压前端与测量自负载核算

日期：2026-10-16。本文依据 TI 官方数据手册核验原理候选，不代表最终原理图、已确认选型或样机性能。范围为四路共地 0～15V、1mV 分辨率电压输入，以及 INA228＋20mΩ 固定量程测流的自负载边界。保持小电流误差目标 ±100µA，本轮只做核算，未实现量程切换、自动断开探线、软件扣除或校准。

**2026-10-23后续更新**：本文件保留早期8:1分压、TLV9004及测量定义讨论。当前原理样机推荐10MΩ/1MΩ的11:1分压、OPA4391精密缓冲、LM7705内部小负轨及小幅正输出偏置，具体见 [ADC与分压核验](四路电压ADC与分压器件核验.md)、[缓冲与零点核验](四路电压缓冲与零点方案核验.md)和 [硬件方案](MCU开发辅助工具硬件方案.md)。电流读数已确认定义为分流器总电流，接入负载属于被测量，不能把下文对“设备未接工具时自身耗电”的比较直接当成当前读数误差；测点和误差目标以首版规格为准。

## 结论

- ADS1115＋独立缓冲＋分压具备实现 1mV 量化分辨率的条件；不能据此承诺 ±1mV 绝对误差，也尚未证明全输入范围内 1mV 变化都可可靠分辨。
- 1MΩ＋200kΩ 四路在 15V 合计取电 50µA。若 INA228 VBUS 也在分流器 DUT 侧，工作自负载最多约 68.75µA；叠加 INA228 的 50µA 最大失调折算就达到 118.75µA，尚未计算其他项。此接法不能直接承诺读数相对未接仪器 DUT 电流的 ±100µA。
- 7MΩ＋1MΩ 将四路取电降至 7.5µA，并可用 ADS1115 的 ±2.048V 档，折算 0.5mV/LSB；但高阻节点对偏置、保护漏电和污染更敏感。TLV9004 未给出输入偏置最大值，当前不能闭合最坏电压误差预算。
- 即使使用高阻分压，计入 VBUS 最大取电仍有 26.25µA 自负载，再考虑测流失调、温漂、共模影响与实际噪声，±100µA 的整机预算仍未闭合。这里必须先明确被测量定义，不能通过扣除名义常数掩盖。

## 分压候选计算

设上臂为 R上、下臂为 R下，比例 K＝1＋R上/R下；分压取电＝V输入/(R上＋R下)，源等效电阻＝R上∥R下。以下均为标称值，未计入保护和缓冲偏置。

| 项目 | 1MΩ＋200kΩ | 7MΩ＋1MΩ |
| --- | ---: | ---: |
| 分压比例 K | 6 | 8 |
| 15V 时缓冲输入 | 2.5V | 1.875V |
| 每路输入阻抗 | 1.2MΩ | 8MΩ |
| 15V 时单路/四路取电 | 12.5µA / 50µA | 1.875µA / 7.5µA |
| 分压节点源阻抗 | 166.7kΩ | 875kΩ |
| ADS1115 固定 PGA | ±4.096V | ±2.048V |
| ADC LSB / 折算输入端 | 125µV / 0.75mV | 62.5µV / 0.5mV |
| 节点额外漏电 1nA 的输入等效偏差 | 1mV | 7mV |

后一行来自 ΔV输入＝K×R等效×I漏＝R上×I漏。因此 7MΩ 方案若只给额外节点漏电分配 1mV，允许值约为 143pA；10mV 对应约 1.43nA。该值用于选型约束，不是已完成的指标。不能随意采用仅“典型低漏电”的钳位二极管或 TVS；必须核对实际反偏、温度、工具掉电等条件下的最大漏电和回灌。[S1 §7.3.1；S2 §10.1]

ADS1115 为有符号 ADC，单端正电压只使用正码范围。±2.048V 是 ADC 标度，3.3V 供电时引脚正常工作范围仍为 GND～VDD。7MΩ＋1MΩ 的 15V 输入有约 173mV ADC 标度余量，不应把余量当作新额定量程。[S1 §5.3、§7.3.3]

## TLV9004 的误差与零点限制

官方 SBOS833R 当前电气表位于 §7.10、p17～18，旧资料章节号可能不同。表头默认 25°C、RL＝10kΩ 接 VS/2、VCM＝VOUT＝VS/2，个别行另有条件。[S2]

| 参数 | 手册值与限定 | K＝8 的意义 |
| --- | --- | --- |
| 输入失调 | VS＝5V，25°C 典型 ±0.4mV、最大 ±1.6mV；−40～125°C 最大 ±2mV | 仅失调分别可达输入端 ±12.8mV、±16mV；3.3V 和不同共模还需计 PSRR/CMRR |
| 失调温漂 | ±0.6µV/°C，只有典型值 | 典型 4.8µV/°C，不能当作最大保证 |
| 输入偏置 | VS＝5V，典型 ±5pA；没有最大值 | 典型输入等效约 35µV；不能外推到全温最大误差 |
| 低频电压噪声 | 0.1～10Hz、5V，典型 4.7µVpp | 约 37.6µVpp 输入等效，未计电阻/ADC/板级噪声 |
| 建立时间 | 5V、2V 阶跃、单位增益、100pF，典型 3µs 到 0.01% | 不能当作高阻分压＋外部 RC 的系统建立时间 |
| 输出摆幅 | 5.5V、RL＝10kΩ 接 VS/2，离电源轨典型 10mV、最大 20mV | 不能证明单电源缓冲可准确输出 0V；也不能据此断言本电路固定存在 160mV 死区 |

0V 附近若跟随器需要负输出抵消失调，会受到负电源轨限制，产生非线性截断；ADC 的负码能力不能恢复被缓冲器截断的信息。实际负载比手册 10kΩ 更轻，但“轨到轨”仍不等于保证到零。需要实测 0、1、5、10、50、100mV 等输入阶跃，并以电路/器件方案解决，不能用软件强制归零掩盖，也未在本文新增负电源。

3.3V 下 1.875V 最大输入比 2.5V 更远离正轨。TLV9004 §8.3.2 提醒互补输入级交接区可能降低失调、CMRR 等性能；不能把中点和 5V 条件失调限值原样当成 3.3V 全输入的总误差。高阻节点须清洁、避开高压/高速铜箔，并核验湿度、阻焊与连接器表面漏电。5pA 典型值不构成对制造污染的保证。[S2 §8.3.2、§11]

## 电压误差、噪声与采样建立

ADS1115 在 ±2.048V、25°C 的最大增益误差为 0.15%，15V 处对应 22.5mV；表中已包括内部参考和 PGA，不能再次重复加参考误差。单端失调 ±3LSB 为典型项，不能当作最大保证；差分失调最大 ±3LSB 不应直接代替单端保证。增益温漂最大 40ppm/°C，温差 25°C 在 15V 处另对应 15mV。[S1 §5.5]

若上、下臂各采用独立 ±0.1% 电阻，K＝8 的最坏比例误差约 ±0.175%，15V 处约 ±26.3mV。仅把分压比例、ADC 增益和 TLV9004 的 5V/25°C 最大失调相加，已有约 61.6mV，尚未纳入共模、电源变化、单端 ADC 零点、温漂、漏电和近零输出；此数仅为说明误差规模的分项核算，不是整机最大误差保证。若每臂独立 ±25ppm/°C，最坏比值温漂约 43.75ppm/°C，温差 25°C 又约 16.4mV。具体电阻的容差、温漂匹配和电压系数仍待选型。

ADS1115 输入是 250kHz 开关电容结构，±2.048V 时差模输入阻抗典型 4.9MΩ、共模典型 6MΩ。875kΩ 分压不能直接视为无损驱动它；独立缓冲让 ADC 动态加载主要由运放承担。缓冲后 RC 需连同运放容性负载稳定性验证，不能把很大的电容直接接到跟随器输出。[S1 §7.3.2；S2 §3、§7.11 容性负载典型曲线]

举例在分压节点加 10nF，875kΩ 的时间常数约 8.75ms；15V 满阶跃到输入等效剩余 0.5mV 需约 10.31 个时间常数，即约 90ms。1MΩ＋200kΩ 同条件约 17ms。该例未选定电容，DUT 源阻抗、寄生、缓冲和滤波会改变结果。

ADS1115 自身数字滤波单周期建立不等于外部 RC 已建立。8SPS 四路轮询，理想最少约 0.5s，加数据率 −10% 约 0.556s，另加 I²C/启动与外部稳定时间；四路不是同时采样。适当配置具备约 1s 更新的可能性，但尚未定义最终刷新率。[S1 §5.5、§7.3.6]

TI 噪声表是 25°C 输入短接的典型数据：±2.048V 在 8～128SPS 为 62.5µV RMS、62.5µVpp（受量化限制），折算 K＝8 为 0.5mV；860SPS 为 62.5µV RMS、118.63µVpp，折算约 0.949mVpp。提高速度后几乎已用尽 1mV 的典型噪声空间，尚未计入前端与 Wi-Fi。[S1 §6.1 表6-1]

25°C 下 875kΩ 等效电阻的热噪声密度约 120nV/√Hz，乘 8 约 0.96µV/√Hz；此为 Johnson 噪声公式核算，不是实物噪声保证。Wi-Fi 发射和 DC/DC 耦合可能产生低频整流偏移，不能只看 RMS 白噪声；须覆盖持续 Wi-Fi 收发、继电器动作、电源不同输入和各通道串扰，不通过自动暂停 Wi-Fi 或丢弃异常值来替代验证。

## 电池电流的计量边界

定义源 → 分流器 → DUT，正电流为向 DUT 放电；充电时为负。工具自身逻辑电源由独立适配器提供，但从 DUT 引出的分压、VBUS、保护和 UART 仍可能改变 DUT 电流。

| 接法/数据 | 读数含义 | 必须披露的边界 |
| --- | --- | --- |
| VBUS 接分流器 DUT 侧 | DUT 侧电压 | VBUS 自负载流过分流器，计入测得电流 |
| VBUS 接源侧 | 分流器源侧电压 | VBUS 自负载不经过分流器，但不可命名为 DUT 端实际电压；尚有分流器、开关、线缆压降 |
| 四路探线接 DUT 电源/内部节点 | 该节点受加载后的电压 | 输入分压可能经分流器取电；内部升压节点的输入等效电流还受转换关系影响，不能直接把节点取电相加当电池电流 |
| UART 由工具驱动 DUT | 包含外部注入后的 DUT 状态 | TX 高电平可能反灌，也可能绕过分流器给 DUT 供电，读数未必等于原本 DUT 耗电 |

INA228 VBUS 活动模式阻抗 0.8～1.2MΩ，15V 对应 12.5～18.75µA；不能用固定 15µA 扣除。IN+/IN− 偏置最大 2.5nA 的条件为 VCM＝85V，不能与 VBUS 负载混淆。关闭 ADC 转换不等于已证明 VBUS 没有负载；本文不提出切模式避负载。[S3 §6.5]

四路 15V 且直接挂在 DUT 供电节点这一明确工况下：

| 输入配置 | 分压自负载 | DUT 侧 VBUS 最坏取电 | 自负载合计 | 再加 INA 最大失调折算 50µA |
| --- | ---: | ---: | ---: | ---: |
| 1MΩ＋200kΩ ×4 | 50µA | 18.75µA | 68.75µA | 118.75µA |
| 7MΩ＋1MΩ ×4 | 7.5µA | 18.75µA | 26.25µA | 76.25µA |

自负载是真实流过分流器的电流；若目标是“分流器总电流”，它属于被测量，并非 INA 测错。若对外声称“DUT 自身电流”，则必须计入接入扰动/解释偏差；不能混用两个定义来宣称达标。四路量测不同内部电压时须按实际连接核算，不能把全项目默认为某一个电池电压。

7MΩ 方案的 76.25µA 不代表还有可保证的 23.75µA 预算：INA 最大失调温漂 10nV/°C 经 20mΩ 折算 0.5µA/°C，25°C 温差就为 12.5µA；宽档原始步长 15.625µA；噪声表只有典型，约 1s 平均可估约 19µApp。最大共模抑制下限 154dB，把 0V 至15V 变化折算约 15µA；还需注意失调基准条件避免重复计算。以上项不能在未限定温度、共模、供电与滤波配置时宣称相加后仍满足 ±100µA。[S3 §6.5、§8.1.3]

分流器实际阻值及温漂、热电势、保护漏电、输入滤波增益影响和 UART 路径均未闭合。高电流误差也不同：3A 处 INA 增益 0.05% 已是 1.5mA，分流器误差另计；±100µA 只能是待明确条件的小电流目标。

## I²C 与基础连接核验

- INA228 A0＝GND、A1＝GND，7-bit 地址 0x40；ADS1115 ADDR＝GND，7-bit 地址 0x48，不冲突。[S3 §7.5.1 表7-2；S1 §7.5.1.1 表7-2]
- INA228 供电 2.7～5.5V，ADS1115 供电 2～5.5V，可同用 3.3V 及上拉至 3.3V 的 I²C。上拉电阻仍按总线电容、速率、低电平灌电流选定；不能把地址中的读写位加入驱动使用的 7-bit 值。[S1 §5.3、§5.6；S3 §6.3、§6.6]
- INA228 VS-GND、ADS1115 VDD-GND 各自就近放 0.1µF，噪声/高阻供电条件可需额外去耦。TLV9004 也按手册紧邻电源放 0.1µF。该布局用于基础供电完整性，不代表已经隔绝 Wi-Fi。[S3 §9；S1 §9.1、§11；S2 §10]
- INA228 官方差模滤波：IN+/IN− 分别串低阻、两输入之间放 0.1～1µF 陶瓷电容，每个串阻不大于 100Ω。其差模输入阻抗典型 92kΩ，两个100Ω会带来约 0.217% 量级加载比例，不能看作零误差。可从每路10Ω＋跨输入100nF 的原理候选开始验证，理论差模截止约79.6kHz，比例影响约0.0217%；这不是定版阻值。[S3 §6.5、§8.1.4、图8-1]

## 原理图前需要闭合的项目

1. 明确电流 API 指向分流器总电流，还是包含接入扰动约束的 DUT 自身电流；明确电压测量节点与命名。
2. 选择分压电阻/保护器件并给出最坏容差、温漂、电压系数和漏电；确认 7MΩ 的实现与采购成本。选择具备偏置最大保证的缓冲器，或承认 TLV9004 候选目前没有足够最坏限值。
3. 确定工具电压测量绝对误差及温度条件，验证 0V 邻域线性，保留 1mV 为分辨率而非精度。
4. 完整算入 INA 共模、电源变化、滤波、分流器和温漂；不能以典型噪声代替最大噪声限值。实测参考仪表的不确定度也应独立记录。
5. 覆盖四路全部连接、UART连接、不同上电顺序、DUT断电以及 Wi-Fi 持续流量下的零点、负载、噪声与串扰。

本文未实现校准、自动补偿或自动断开输入；当前只能推荐进一步验证的前端原理，尚未闭合整机误差预算。
