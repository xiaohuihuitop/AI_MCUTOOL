# 五伏双入口隔离器件核验

核验日期：2026-10-23。用户已将工具自身供电改为**DC和Type-C均只接受5V/2A适配器，后级使用3.3V LDO**，取消12V输入支持。每次人工只接一个入口；保留入口间防倒灌，不增加电源优先级、无缝切换或GPIO控制。被测设备的独立充电输入继续与工具供电正极分开。

**原理样机推荐每个入口一颗TI LM66100DCKR，各自CE接本颗VOUT；两个VOUT汇合至LDO输入。每入口VIN前保留4.7kΩ到地泄放及1µF本地电容。** 本轮只比较Vishay SS14和LM66100，两者均已读取厂商原始PDF；具体采购价格和样机表现尚未确认。

## 为什么不优先使用SS14

Vishay SS14属于SS12～SS16系列，官方Document88746、Revision23-Apr-2020，SMA（DO-214AC）封装，色带标记阴极，基础型号SS14在官方表中对应40V反向额定、1A平均整流电流。[S1第1～4页]

| 参数 | SS14官方值及限定 |
| --- | --- |
| 正向压降 | 最大0.50V@1A，默认25℃；300µs、1%占空比脉冲测试，不能直接当任意温度和浪涌保证 |
| 反向漏电 | 额定反压40V下，25℃最大0.2mA，100℃最大6mA；反向测试脉宽≤40ms |
| 热阻 | RθJA典型88℃/W、RθJL典型28℃/W，按5mm×5mm铜焊盘安装条件 |
| 封装 | SMA，不能将名称相近的SOD-123或其他封装库存当作同一物料 |

其正向压降方向可行：板端4.75V减0.50V约4.25V，能给低压差LDO留下余量。但单用二极管不能保证闲置端始终为0V，高温反向漏电会给悬空接口充电。

如按官方高反压的6mA上界作保守设计、期望闲置端约≤0.5V，则泄放电阻需约≤83Ω；选82Ω时，正常5V输入会持续消耗约61mA、0.305W，必须选相应功率电阻并核温升。若沿用4.7kΩ，按0.2mA的25℃上界就有约0.94V预算，高温上界则不能控制在所需低电位。实际仅5V反偏时漏电通常较低，但手册曲线是典型值，不能把典型曲线当作低反压全温最大保证。

因此本轮不通过增大泄放损耗来保留SS14，而选择低压降且有微安级反向漏电表的LM66100。SS14仅保留成本和电气对照，不设计运行时备用通路。

## LM66100参数与压降预算

LM66100DCKR为六脚SC-70（DCK），官方订购附录列Active/Production，并列有`.A`后缀，采购时复核实际包装和库存。工作输入1.5～5.5V、最大连续开关电流1.5A；本工具适配器5V/2A表示电源能力，**不代表板上隔离通路设计为可连续输出2A**。[S2第1、4页及订购附录]

| 参数 | 官方电气表 |
| --- | --- |
| RON，VIN=5V | 典型79mΩ；25℃最大95mΩ，−40～85℃最大110mΩ，−40～125℃最大120mΩ |
| RON，VIN=3.6V | 25℃最大110mΩ，−40～85℃最大125mΩ，−40～125℃最大140mΩ |
| RON测试电流 | IOUT=−200mA；不能把表格直接当作所有电流/温度下实测结果 |
| OUT→IN漏电，VOUT−VIN≤5.5V | 25℃最大0.5µA，−40～85℃最大2.7µA，−40～105℃最大8µA；CE>VIN+80mV |
| VIN静态/关闭电流 | 表列25℃及至105℃最大0.3µA，具体CE条件见手册 |
| CE漏电 | 开启条件下最大300nA，关闭条件下最大610nA，−40～125℃ |
| 热阻 | RθJA=192℃/W，按官方标准热测试板条件，非实际PCB保证 |

以0.75A工具工作电流为主要预算：

- 5V、95mΩ口径：压降约71mV，耗散约53mW。
- 5V、120mΩ口径：压降约90mV，耗散约67.5mW。
- 为覆盖4.75V附近输入，暂用较低3.6V表项的140mΩ作保守工程预算：压降约105mV、耗散约78.8mW，板端4.75V之后约4.645V，尚未扣除接点和走线压降。此取法有MOS导通电阻随驱动电压变化的工程依据，但不替代4.75V、0.75A整板实测。

78.8mW乘192℃/W约15℃温升只是标准热阻算例。闲置支路的反漏上界只明确到105℃，不能将8µA外推为125℃保证；需要让器件温度、LDO热源距离及布局满足实际验证条件。

低压降隔离提高了LDO的输入余量，但不会消除线性稳压总损耗。5V→3.3V、0.75A时，隔离与LDO合计约`(5−3.3)×0.75=1.275W`，未计静态和泄放。LM66100分担约0.05～0.08W，其余约1.20～1.23W主要由LDO承担；不能只看入口芯片低发热就宣称整机供电已经解决散热。

## 逐脚连接

两路完全相同，分别命名U_DC和U_C。以下为DCK六脚顶视图映射。[S2第3页]

| 引脚 | U_DC连接 | U_C连接 |
| --- | --- | --- |
| 1 VIN | DC_IN_5V | TYPEC_IN_5V |
| 2 GND | 工具GND | 工具GND |
| 3 CE | 接本颗6脚VOUT | 接本颗6脚VOUT |
| 4 N/C | 可接GND或悬空，初稿接GND | 同左 |
| 5 ST | 不使用状态输出，按手册接GND | 同左 |
| 6 VOUT | 接公共LDO_VIN | 接公共LDO_VIN |

每路1脚VIN附近对GND放1µF陶瓷电容；同时从该入口VIN网络接4.7kΩ/1%、≥0.1W到GND。泄放和输入电容都在芯片输入侧。两个VOUT汇合后接LDO输入电容及LDO，走线短且宽；最终陶瓷电容封装、介质、额定值和有效电容需核验，5V支路可优先比较≥10V的X7R器件。[S2第13～14页]

**CE必须接本颗VOUT才能采用手册的独立反向阻断接法，不能为了“常开”接GND。** 不把CE交叉接另一入口，不使用ST建立优先级，不连接MCU控制脚。手册另有双输入交叉控制与优先级示例，本工具不采用这些逻辑。[S2第9～12页]

这组器件只以本支路输入/输出电压比较实现已要求的防倒灌。仍按人工单入口使用，不将两适配器同时插入或无缝切换列为受支持功能；也不新增软件回退、自动换源或限流降级。

## 反向阻断和闲置电位

CE接VOUT后，VOUT高于VIN达到关闭阈值时，内部MOS关闭；输入重新高于输出达到开启阈值时，MOS开启。器件OFF状态仍有从IN到OUT方向的体二极管路径，因此它不是由软件控制的双向全断开开关。[S2第9～10页]

关键动态参数为：

- 关闭阈值`VCE−VIN`为0～80mV，典型35mV。
- 开启阈值`VCE−VIN`为−250～−80mV，典型−150mV，存在迟滞。
- 反向激活电流IRCB典型0.5A、最大1A；关闭时间约2µs是指定条件下典型值。
- 5V开启时间典型27µs，负载条件CL=100nF、RL=1kΩ，与本板LDO及电容不同。

因此只能说它会关闭以阻断持续反向电流，不能承诺拔插或输入快速塌陷时“瞬间零反向电流”。样机须验证实际输入断开、输出储能、线缆及供电上升沿；不把上述动态参数当成可任意承受输入短路的保护保证。

配4.7kΩ泄放，以5.5V压差漏电表预算闲置口：25℃约2.35mV，至85℃约12.69mV，至105℃约37.6mV；电阻+1%时最后一项约37.98mV。实际VIN=0V、VOUT约5V的状态、板级漏电和动态注入仍应实测。正常5V入口泄放约1.064mA、5.32mW；比SS14按高温漏电选择82Ω的方案显著减小持续耗电。

该电阻只控制**工具闲置电源口**的泄漏电位，不是用户已拒绝的DUT主动放电；没有新控制命令。

## Type-C与输入电容协同

Type-C的CC1、CC2继续各用5.1kΩ下拉；只接收5V，不做PD，电流能力沿用人工选择适配器和线材的约定。DC中心正极也只能接5V，丝印和说明应移除原12V支持。

每个LM66100前1µF是官方常用起点。若LDO输入再用1µF，Type-C可见的直接输入电容至少约2µF；若LDO输入为4.7µF，至少约5.7µF标称。再计各处旁路、正容差及寄生，沿用≤10µF的直接可见输入电容方向。不能把LM66100后侧输入电容当作在插入时完全隔离；内部体二极管、导通延迟及输出充电仍会产生浪涌。

LDO输出端的大电容不是简单与5V入口并联，但其启动充电和负载同样影响适配器浪涌，需联合测试。本文不新增输入浪涌控制器，也不宣称USB规范或任意USB端口兼容性已通过。Type-C规范依据见此前 [DC与Type-C供电入口器件核验](DC与TypeC供电入口器件核验.md)；其中12V、1N4007和降压器方案已被本次5V/LDO方向取代，仅保留历史研究证据。
