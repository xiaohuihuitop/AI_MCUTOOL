# 嘉立创 EDA 命令行能力评估

核对日期：2026-10-28。目标工程：`D:\LCEDA\projects\AI_TOOL\AI_TOOL.eprj3`。本次只核对资料和客户端帮助，未修改 EDA 工程或连接配置。

## 结论

官方 CLI 更适合作为本项目的主要自动化入口：可以直接调用编辑器 API、管理工程会话、查询 API 与文件格式，并返回结构化结果，减少对第三方插件封装及手工界面操作的依赖。[S1][S2]

本项目在 2026-10-26 的本地工程阶段已经采用官方 CLI：`probe_cli.py` 通过客户端 `invoke --code-file` 执行脚本；最近八页中文解析的保存、重开、原生图片导出和网表检查也是这条路径。因此建议继续沿用现有方式，不需要重新迁移工程。[L2][L3]

## 能力与实际价值

| 能力 | 官方支持及对本项目的意义 |
| --- | --- |
| 内置于桌面客户端 | 文档要求 V4.1.60 及以上，无需另装 CLI；浏览器版不支持这套会话和桥接机制。本机帮助显示 `4.1.78.34f5b8d9`。[S1][L1] |
| `doctor`、`session list` | 查询桥接连接、会话来源、工程路径和窗口信息，减少误操作其他工程的风险。[S1][L1] |
| `invoke` | 在指定编辑器会话内执行异步 JavaScript，调用原理图、PCB、库、DRC、导出等扩展 API；不需要为每项功能等待第三方插件增加专用命令。[S1] |
| `doc api`、`doc format` | 查询方法签名、枚举和原生记录字段；可减少猜测接口、坐标及文件格式。`doc external` 则查询扩展注入的 API。[S1][L1] |
| `.eprj3` 双向同步 | 官方支持编辑器保存到本地，以及磁盘修改后编辑器重载；适合批量排版、注释生成和文本差异核查。[S1] |
| `open --headless true` | 打开不显示窗口的编辑器会话，帮助文本明确称为 `hidden render`；可以减少窗口干扰，但仍依赖客户端及其渲染进程，不能视为独立的命令行解析器。[S1][L1] |
| `--mcp stdio` / `--mcp http` | 客户端可直接作为 MCP 服务，让支持 MCP 的 AI 工具调用同一套能力。它是连接方式的改进，不会额外提升编辑器自身的布线或渲染能力。[S1][S2] |

官方命令总览没有独立的 `render` 子命令。图片、BOM、网表、Gerber、STEP 等操作通过 `invoke` 调用相应导出 API 完成；文件可写入允许访问的工程目录，或转换后通过结果回传。[S1]

## 关于之前的截图问题

官方 CLI 可以直接调用原生导出，许多检查无需人工把窗口切到前台。我们已成功用这条路径导出八页原理图，且逐页检查了图面。[L3][L4]

2026-10-26 的独立简单 PCB 样例还实际验证了隐藏会话截图：文字及坐标从 A 改为 B 后图片同步变化，磁盘改为 C 并关闭重开后截图也正确，全程无需用户切前台。这证明有实际可用的后台出图路径；样例结论不外推为所有渲染接口都适用。[L5]

但文档没有承诺所有截图接口都能在任何后台状态下工作。当前视口截图与整图导出是不同操作；`--headless` 也仍然运行编辑器。若具体接口依赖活动文档或画布刷新，CLI 不会自动消除该依赖。应优先用已验证的导出接口，并校验实际图片，而不是只依据命令成功返回。[S1][L1][L3]

## 已知限制与核验原则

- 本机 `invoke --help` 明确说明：`ok:true` 只表示脚本执行，不能证明业务操作成功。需要检查 `save()`、DRC、导出文件及回读结果；网页中“只检查外层 ok”的概括不能替代这些检查。[L1][S1]
- 本地 `.eprj3` 同步后，本项目遇到旧图页继续返回缓存几何的情况；重要修改采用保存、关闭图页、重开后回读，并比对网表与图面。[L4]
- 本项目 4.1.78 实测中，`startAutoRouting` 返回空任务 ID，普通 `autoRouting` 才有实际实现。CLI 是调用通道，不能补齐具体 API 的占位实现；自动布线结果仍要检查。[L4]
- 本机支持 `--code-file`，可避免长脚本经过 Shell 多层转义；本机帮助还标明 PowerShell 直接捕获该可执行文件 stdout 的限制。项目现有 Python `subprocess` 封装已经处理了这一点。[L1][L2]
- 官方网页与本机帮助存在版本差异：网页 `invoke` 示例未列出 `--code-file`，且超时上限示例为 1800000ms；本机帮助为 86400000ms。执行时应以当前安装版本的帮助与方法返回值为准，不能仅照抄网页示例。[S1][L1]

本项目适合继续采用：官方 CLI 管理会话和调用 API；本地 `.eprj3` 文件用于受控批量修改；编辑器负责重新加载、网表检查、DRC 和原生出图。官方内置 MCP 可作为后续连接选项，目前不必为此修改现有可用配置。[S1][L2][L3]
