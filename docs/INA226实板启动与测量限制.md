## 原因与修改

首块工具板的16MB Flash原先全部为`0xFF`，没有可启动固件。首次业务握手时Windows报告串口读取错误；进入ROM下载模式后识别正常，写入固件后USB握手通过。

原BOM和0.1.0固件按INA228设计；实板返回厂商ID`0x5449`和芯片ID`0x2260`，用户进一步确认实际装配INA226。旧固件拒绝按INA228解释该芯片，所以电池测量显示读取失败。0.1.1的改动包括：

- 固定采用INA226的`0xFE/0xFF`身份寄存器，接受手册定义的`0x2260/0x2261`；不自动选择其他芯片驱动。
- 使用`0x01`的16位有符号分流电压和`0x02`的16位总线电压，直接按20mΩ换算双向电流；不依赖未配置芯片CAL时为零的CURRENT寄存器。
- 配置`0x496F`，双通道连续采样、每通道2116µs、128次平均，并回读配置确认。名义内部更新周期约0.542秒，后台约每秒获得一组读数；数据窗口按手册最大转换时间的两轮约1.192秒估计。
- 能力查询和网页说明明确披露芯片、读数步进及未验收状态。电池通道校准记录升级为版本2，旧INA228记录判为无效；ADS1115四路记录格式保持。
- 临时诊断代码已移除，新增正式换算测试覆盖正负3A、手册负80mV例子、正负一个码、零值、4V和15V，以及身份拒绝。

本次没有修改原理图、PCB或历史BOM归档。历史资料的INA228条目不再代表本板U12实装型号。

## 测量能力应如何理解

| 项目 | INA226＋20mΩ实板的软件定义 | 实际限制 |
| --- | --- | --- |
| 电流名义步进 | 125µA/码，即0.125mA/码 | 来自2.5µV分流电压LSB除以20mΩ；增加显示小数位不能提高分辨率 |
| 电池接口电压名义步进 | 1.25mV/码 | 原方案的1mV显示/分辨率目标不能作为该芯片的原生步进 |
| 未校准分流输入失调 | 手册规定条件下上限±10µV，折合±500µA | 不是校准后整机误差；还需考虑噪声、增益、温度、分流器和接线影响 |
| 原小电流目标 | 原INA228方案为0～10mA误差±100µA | 不能直接沿用为本板能力承诺；完成校准后用独立点和温度条件重新评估 |
| 电流范围 | 工具仍以双向3A为设计范围；3A在20mΩ上为60mV | 在INA226分流输入量程内，不证明开关、连接器、压降或温升合格 |
| 测量速度 | 约1Hz对外更新，四路ADS1115顺序采样 | 不适合尖峰捕获或严格同步波形；平均结果可能含操作前数据 |
| 近零显示 | 保留实际名义码和质量标识 | 负一个码可能显示超出0～15V的范围，不静默置零；近零准确下限仍需实测 |

本次仅接USB、业务输出关闭时，观察到电流名义读数约`-0.125mA`，外部电压读数在零附近。这些是**未校准样本**，不能据此判定真实反向电流、休眠电流或精度达标；也没有据此写入零点补偿。

参考：TI [INA226官方手册](https://www.ti.com/lit/ds/symlink/ina226.pdf)，本次获取版本SBOS547C，2026-08修订；第5页电气参数，第22页寄存器和身份，第23～24页平均、转换时间、工作模式及补码换算。读取与图表核对均已完成。
