# MCU 开发辅助工具验收边界草案

状态：验收入口及范围已确认。本文定义正式规格的测试入口及可观察结果，不代表已经完成实现或测试。

## 主验收入口

通过电脑端 MCP 服务调用工具，经局域网 HTTP API 驱动真实硬件。用实际端口状态、参考仪表读数及串口对端收发结果判断行为。

API 返回成功代表命令执行结果的一部分，物理动作和测量精度通过外部仪表单独核验。

| 供电选择与通断 | 背靠背 MOS 选择真实电池或外部可控电源，目标为 0～15V、双向 3A；两路互斥、先断后通，允许设备断电；3A 时板内总压降目标不超过 150mV，本地切换按 100ms 量级设计 | 检查实际支路通断、低电压导通、压降与温升；压降包含开关、分流、走线及板载端子，不含外接线，温度条件待补齐；动作时间不含网络、设备电容放空或重启时间 |

## 测试分层建议

1. 电路验证：先用参考仪表验证测量精度、输入负载、通路压降、接点行为及串口引线对设备供电的影响。
2. 设备 API 验证：测试合法和冲突命令、状态查询及网络中断行为。
3. MCP 端到端验收：以主验收入口覆盖已确认能力，结合外部电气证据检查实际结果。

当前工程尚无产品源码或既有测试框架。测试实现方式、参考仪表、夹具及未确定的数值指标在电路和固件方案中继续细化。

## 责任边界

- 不配置供电输出主动放电功能，不验收关闭通路后在固定时间内降至零电压；关闭通路与设备端残余电压分别检查。
- 验收对象是工具通用能力，不依赖特定被测设备型号、电池类型、休眠策略、日志格式或项目通过阈值。
- 适配以工具电气额定值和接口能力为准；主通路 0～15V/双向 3A 与四路电压输入 0～15V 分别定义并验收，不能用其中一项的测试结果替代另一项。
- 外部可控电源的驱动及调压由 AI 通过该电源自身接口完成，本工具验收其接入、切换及测量能力。
- 项目测试流程、设备状态解释及通过条件由项目侧 AI 和具体固件定义。
- 首版不验收波形采集、逻辑分析、USB 通信、内置模拟电池电源或内置充电电源变换器。
