# 双路供电开关单路器件核验

> 2026-11-02更新：本文保留早期N-MOS与VOM选型依据。用户随后确认C2828591后，当前原理图已改为AP60P20Q背靠背P-MOS、AO3400A下拉及栅源限压，VOM1271T已移除；工作目标为2.8～12V/3A，不保证接近0V时充分导通。当前以[AP60P20Q主供电原理图改版核验](AP60P20Q主供电原理图改版核验.md)为准。

核验日期：2026-10-22。仅细化真实电池/外部可控电源两路主供电开关，保持背靠背 MOS、各路独立关闭、两路互斥、先断后通、0～15V 双向通路、原 3A 设计上限及 100ms 量级动作目标。实际用途以小电流调试为主；本轮不扩大额定值，不增加主动放电、自动过流、恢复或换源功能。充电通路下一轮单独处理。

**单路原理样机建议：VOM1271T＋两颗 CSD17577Q3A＋MMBT3904LT1G，LED 限流100Ω、基极330Ω、B-E下拉10kΩ（均1%）。** 光伏输出直接驱动共栅/共源，不加普通100kΩ栅源下拉。此为画图和单路样机起点，未完成原理图、BOM采购、样机或全温验证。

## 单路逐网络连接

| 网络 | 接入点 |
| --- | --- |
| PATH_IN_P | 本路电源正端；接Q1的D焊盘5/6/7/8/9 |
| VSEL_P | 两路开关后的公共正端，后接已有20mΩ分流；接Q2的D焊盘5/6/7/8/9 |
| SCOM | Q1和Q2的全部S焊盘1/2/3相连；接VOM1271 pin3 |
| GCOM | Q1和Q2的G焊盘4相连；接VOM1271 pin4 |
| LED_A | 工具3V3经100Ω接VOM1271 pin1 |
| LED_K | VOM1271 pin2接MMBT3904 pin3(C) |
| CTRL_B | GPIO经330Ω接MMBT3904 pin1(B)；B经10kΩ接E/GND |
| 工具GND | MMBT3904 pin2(E)及10kΩ下端；不直接连接SCOM/GCOM |

Q1/Q2两颗体二极管都从SCOM朝各自Drain方向，形成端口之间的反向串联关系。关闭时阻断正常正反向电压差，导通后沟道支持两个方向电流。光伏驱动由工具侧LED获得能量，不依赖PATH_IN_P最低电压；0V端口不代表可在0V下输出功率。[S1第4页图9；S2电气结构]

真实电池支路复制一套，CTRL由GPIO11驱动；外部电源支路再复制一套，由GPIO12驱动。两套分别拥有SCOM_BAT/GCOM_BAT和SCOM_EXT/GCOM_EXT，只有输出VSEL_P汇合。每路两颗MOS必须完整保留，不能共用一颗后声称两路均可双向关断。

## 输入驱动及电阻计算

工程低端预算：工具电源3.0V、VOM LED VF≤1.6V、NPN VCE≤0.3V，电阻1%。这些压降必须在实际电流、温度下验证；VF表列1.6V只对应10mA/25℃，不是额外全温保证。

| R_LED | 低端IF预算 `(3.0−1.6−0.3)/(1.01R)` | 3.3V、VF1.4V/VCE0.1V示例 | 零压降粗上界 `3.6/(0.99R)` |
| --- | ---: | ---: | ---: |
| **100Ω** | **10.891mA** | 18mA | 36.364mA |
| 120Ω | 9.076mA | 15mA | 30.303mA |

因此100Ω更符合本轮低端预算≥10mA的要求；120Ω虽有更低功耗，但在相同假设下达不到该预算。粗上界仅用正常正向通路VF/VCE≥0，没有将IF＝10mA条件的VF最小值强行套用到其他电流。

100Ω的最保守电阻耗散上界为`3.6²/99≈130.9mW`。**建议R_LED采用1206、额定≥0.25W、1%**，再按具体料号和板温降额；普通0.125W电阻不能按这个上界直接认定足够。标称算例18mA时损耗约32.4mW，不能以标称算例替代上界核算。

NPN沿用onsemi MMBT3904LT1G：IC＝50mA/IB＝5mA时VCE(sat)≤0.3V、VBE(sat)≤0.95V，25℃脉冲测试条件见[S3]。采用待验证的**带载GPIO高电平≥2.4V、VBE≤0.95V**预算：

`IB低端＝(2.4−0.95)/(1.01×RB) − 0.95/(0.99×10kΩ)`。

| R_B / R_BE | 基极电流低端预算 | 对IF粗上界36.364mA的IC/IB | 判断 |
| --- | ---: | ---: | --- |
| **330Ω / 10kΩ** | **4.254mA** | ≤8.55 | 建议样机初值，接近且强于手册IC/IB＝10的驱动比例；仍需验证实际VCE/VBE |
| 680Ω / 10kΩ | 2.015mA | ≤18.05 | 标称电流附近可能可用，但不足以支撑本次宽松上界所需的同等饱和驱动余量 |

330Ω基极电阻的GPIO电流粗上界约11.02mA/路，耗散粗上界约39.7mW，可从0603/≥0.1W起步；R_BE为10kΩ/1%、0603/≥0.1W。一路驱动LED与GPIO增量的粗电流预算约47.4mA，实际通常较低。正常两路主供电互斥，不因功耗预算而允许同时导通。

ESP32-S3的VOH高阻负载测试不能证明此基极负载下VOH≥2.4V，GPIO典型源电流也不是任意工况保证。[S4] 应先实测GPIO与NPN压降，必要时按实测调整驱动，不把工程预算当成厂商额外承诺。10kΩ B-E下拉保证GPIO高阻时不浮空，不能阻止GPIO主动高电平误动作。

## 栅极网络与MOS导通损耗

单路原理样机可以按Vishay图9先用**直接共栅、直接共源、无外加栅源电阻、无外加栅极串阻或钳位**的最小连接，用受限能量输入并监测VGS验证。此处“先不装”仅针对原理验证，不代表定型无需最大电压、漏电或瞬态约束。

- 普通100kΩ栅源下拉在8V时消耗80µA，已超过VOM1271在IF＝20mA时30µA的典型短路输出；会明显削弱甚至阻止栅极充电。1MΩ在8V时也消耗8µA，不能随意增加。
- 任何栅源稳压管/TVS必须核验实际电压和温度下的泄漏；微安级漏电已经可能影响驱动。VOM没有VOC最大保证，MOS的±20V栅源绝对额定也不能替代最大VGS闭合；定型前仍需明确最大光伏输出、线缆瞬态与米勒注入。
- 外加栅极串阻用于抑制振铃是否必要，需看实际门极走线与关断波形；当前按官方直接连接进行原理验证，避免以未验证网络降低驱动。

CSD17577Q3A参数以电气特性表为准：[S2第1、3页]

| 参数 | 核验值与含义 |
| --- | --- |
| VDS / VGS绝对额定 | 30V / ±20V；不等于通路热插拔已经受保护 |
| RDS(on)@4.5V | 最大6.4mΩ/颗，ID＝10A、25℃ |
| RDS(on)@10V | 最大4.8mΩ/颗，ID＝16A、25℃；当前不能假定光伏驱动达到10V |
| Qg至4.5V | 电气表典型13nC、最大17nC；首页摘要写12nC，计算统一采用详细电气表 |
| 漏电 | IDSS最大1µA@VDS24V/VGS0；IGSS最大100nA@VGS20V，默认25℃ |

在**实际VGS达到4.5V、25℃手册条件可适用**的估算中，两颗总RDS为12.8mΩ，3A压降38.4mV、损耗0.1152W。加既有20mΩ分流的60mV后，共98.4mV，距板内150mV目标还剩约51.6mV给走线和连接器。温升后RDS增加，最终预算不能只按25℃值；原理样机也应先按实际小电流用途测试，再逐步扩展至设计上限。

## 动作时间与验证边界

两颗MOS至4.5V的门极电荷典型合计26nC、表列最大合计34nC。将34nC除以短路电流6µA得到约5.7ms，**仅是量级算式，不是最坏开通时长保证**：输出电流随门极电压变化，MOS实际负载及米勒过程也与手册条件不同。VOM的53/65µs典型值对应200pF，不能替代两颗功率MOS的实测开关时间。

100ms是完成命令动作的量级目标，**不代表允许MOS在大VDS、大电流的线性区缓慢导通100ms**。需要根据实际负载电容、线缆、输入电压及S2的SOA图核验开通过渡和关断瞬态。先断后通的互锁间隔由实际最慢关断确定，不从典型65µs直接编造固定延时。

单路初始BOM：VOM1271T×1、CSD17577Q3A×2、MMBT3904LT1G×1、100Ω/1%/1206/≥0.25W×1、330Ω/1%/0603/≥0.1W×1、10kΩ/1%/0603/≥0.1W×1。主供电两路乘二；这不包含分流器、工具稳压、连接器及其他模块，也不是完整采购BOM。

样机验证至少包括：3.0/3.3/3.6V工具供电下LED电流和GPIO/NPN压降；近零端口及不同输入电压下VGS、正反导通/关断；冷启动、复位、工具失电及输入先上电时默认关闭；LED关闭后的门极释放、关断漏电、容性浪涌和VGS/VDS瞬态；实际温度下压降和温升；最后验证两路互斥及先断后通。电流/能量受限的台架验证不等于产品新增自动限流功能。
