# 用户布局重新布线核验

日期：2026-11-05。主工程：`D:\LCEDA\projects\AI_TOOL\AI_TOOL.eprj3`。

用户手工调整了主控、Type-C、部分供电端子和外围的位置，并锁定30颗器件；开始时旧铜线、过孔已清空。以这次实际布局为基准，完成整板重新布线。全部140颗器件的位置、朝向与锁定状态保持，28个独立焊线孔、可见丝印、完整415脚网络及器件身份保持。

## 线路处理

- 主供电采用2.5mm主干，分流器附近局部1.2mm，MOS并联脚短支路0.3mm；充电通路2mm。五个供电大焊线孔按对应主通路线宽接入。三条宽铜在大焊盘内部将末端向板内收0.1mm，满足现行0.3mm板边净距。
- Kelvin采样从分流器独立采样脚引出，保留滤波后短连接；四路运放反馈及输出线路按实际实铜核对。
- USB主段保留0.30mm线宽、名义0.18mm间距的成对路径。为避让用户下移的R7/R8，下侧绕行段成对下让0.30mm，并按主控新位置调整串阻后的短线。主段中心及边缘投影的L2地参考缺口均为0；该几何检查不替代制造阻抗和通信实测。
- 重新建立地/3.3V平面的接入及LDO散热铜。LDO散热铜属于**LDO_VIN输入网络**，两面散热区及过孔均按此网络连接。
- 原生自动布线后，按实际数据修复三处跨网交叉并补齐UART发送线路。清理两段被宽铜完全覆盖的冗余LDO短线，再保存重开验证。四处继电器输入转角向外让位，并按覆盖证明清理六处自动布线重叠段。
