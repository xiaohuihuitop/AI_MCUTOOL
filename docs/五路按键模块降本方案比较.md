# 五路按键模块降本方案比较

调研日期：2026-10-17。本轮只比较五路按键，不改变电源通路等其他模块。已确认每路触点差分电压不超过 6V、电流不超过 20mA、无极性、五路各自独立浮动两端，10ms 级动作速度足够。本文没有修改原电路方向，没有器件采购价格或样机验证结果。

## 结论

**优先在相同独立浮动触点能力下比较更便宜的 PhotoMOS；其次核价 3V 非保持式信号继电器的完整五路方案。** 普通模拟开关或 GPIO 参考工具地的背靠 MOS 不能无条件替代浮动两端触点。

20mA 比当前 TLP176AM 的额定输出电流低很多，可以寻找小电流、低压 PhotoMOS 减少过度选型，但不能只看 6V/20mA：导通电阻、关断漏电、输出电容、LED 电流、动作时间和产品状态也要匹配。价格由另一路核价，本文件不把“换国产”或“机械通常便宜”当作已证实的降本结果。

机械信号继电器在功能拓扑上保留浮动和无极性，但会新增线圈功耗、驱动/续流器件、动作弹跳及接触可靠性验证。G5V-1 的低负载参考条件弱于 G6K，不能因20mA是允许最大电流，就假定实际按键电流必然足够湿润触点。

省去五颗 LED 驱动 NPN 可以研究，**收益仅是外围小器件，不会消除五颗 PhotoMOS 的主要成本**。直接由 ESP32-S3 驱动必须闭合最低 LED 电流和复位默认关闭，不应在未验证前直接删管。

## 功能等价性必须保持的条件

1. 每路输出只有两个外部触点端子，不强制其中一端连接工具地。
2. 五路可独立控制，支持多键同时闭合；不能用一颗双刀继电器的两组联动触点代替两路独立按键。
3. 正反方向均能导通并关闭，不依赖实际按键的高低端接法。
4. 额定差分 6V 不表示端子相对工具地只会在 0～6V。浮动能力还涉及触点相对工具地的共模电位，不能把两者混为一谈。
5. 上电、复位及固件尚未初始化时，触点保持断开。
6. 10ms 级速度要求应按外部触点的实际闭合/释放与稳定时间验证，而不是只检查控制 GPIO 的时间。

## 方向 A：PhotoMOS 的等价降本

### 当前 TLP176AM 的基准

本次实际取得 Toshiba TLP176AM Rev.7.0.A、2026-04-07 官方数据手册。[S1]

| 参数 | 官方数据及条件 | 对当前需求的意义 |
| --- | --- | --- |
| 输出 | 常开 1-Form-A，两端为 MOS 漏极 | 无极性浮动触点，不需共地 |
| 关断端电压 | 60V | 远高于当前每路 6V 差分目标，可比较更低压型号 |
| 输出电流 | 700mA 绝对额定 | 不能由额定冗余推导某个替代器件必然便宜 |
| RON | 最大 2Ω，IF=5mA、ION=700mA、25°C | 20mA 时按 2Ω 计算压降 40mV、发热 0.8mW；实际低电流/温度条件仍应验证 |
| IOFF | 最大 1µA，VOFF=60V、25°C | 不等于 6V 条件下已有更小最大漏电保证；高阻按键须核查 |
| COFF | 典型 100pF | 矩阵扫描或高阻检测可能受影响，不能仅看直流额定 |
| LED 推荐电流 | 最小 5mA，典型 7.5mA | 最大触发电流 3mA 不是推荐工作电流的替代值 |
| 动作时间 | 最大开通 3ms、关断 0.5ms | 条件为 IF=5mA、VDD=20V、RL=200Ω；符合10ms量级的候选，实际负载还需验证 |

源自 S1 第 1～5 页。TLP176AM 的 LED 和输出相隔离，不代表整台工具已经与被测设备隔离；UART 和测量地仍按原方案共地。

### 比较更便宜 PhotoMOS 时的筛选表

采购比价至少应同时给出：完整料号/封装/包装、五颗含税单价与运费口径、现货/生命周期；电气上核对以下内容：

- 常开 AC/DC 或双向 MOS 输出，逐路控制，关断额定差分电压覆盖 6V。
- 连续电流覆盖 20mA，并按温度降额，不能只拿脉冲额定值。
- 实际 LED 电流下的 RON 与最大动作时间，关断漏电及输出电容。
- 是否能够以现有工具 3.3V 驱动，是否因为 LED 电流不同反而增加外围。
- 封装和触点隔离结构是否满足端子布局，不为了省钱擅自把五路合成共地。

不要求它保持 60V/700mA 这种未被用户需要的冗余，但削减冗余后仍需完整满足已确认的触点能力。未经官方资料核验的国产型号暂不写入定型推荐。

## 方向 B：机械信号继电器与干簧继电器

以下两个例子用于给出可实证的电气/尺寸基准，不代表其价格低于 PhotoMOS。

| 项目 | Omron G5V-1 DC3 | Omron G6K-2F DC3，非保持型 |
| --- | --- | --- |
| 触点 | SPDT，取 COM/NO 为常开一组 | DPDT，每路取一组 COM/NO，另一组不能算作独立通道 |
| 接触材料 | Au-alloy＋Ag，single crossbar | Ag（Au-alloy contact），bifurcated crossbar |
| 初始接触电阻 | 最大 100mΩ | 最大 100mΩ |
| 接触电阻测量条件 | 1V/10mA | 1V/10mA |
| 动作/释放 | 各最大 5ms | 各最大 3ms |
| 低负载参考条件 | 1mA/5V | 10µA/10mV |
| 低负载参考失效判据 | 100Ω | 50Ω |
| 3V 线圈 | 60Ω、50mA，约150mW | 91Ω、33mA，约100mW |
| 常温吸合条件 | 额定电压的80%最大 | 额定电压的80%最大 |
| 本体尺寸 | 最大12.5×7.5×10mm | 约10×6.5×5.2mm，选定封装还需核图 |

来源：S2 第 1～4 页；S3 第 1～3 页。线圈电阻公差为 ±10%，参考温度23°C。低负载参考值不是绝对最小可通过电流，也不是“全寿命低负载下始终100mΩ”的保证；手册明确要求在实际环境验证。

### 低负载与弹跳

当前规定的是**最大20mA**，没有规定实际按键最小电流。有些高阻按键可能只有几十微安，G5V-1 的1mA/5V参考不能直接覆盖；G6K 的低信号参考更接近此类应用，但仍需结合实际接触电阻容忍度和环境测试。不能为了迁就继电器要求被测设备加大上拉电流，除非用户另行确认这种接口约束。

机械动作时间不等于触点稳定时间。G5V-1 第4页和G6K第5页均另外给出弹跳时间分布；这些是样本曲线，不能把曲线最大观察值当成全批次保证。普通续流二极管还可能延长线圈退磁和释放时间，10ms动作目标必须在所用线圈驱动/续流电路下实测。

不能声称机械继电器“一定更像真实按键，所以不需要处理弹跳”。项目侧是否对真实按键去抖不改变本工具需要说明实际动作行为的职责。

### 现有3.3V供电能否使用3V线圈

3V 版本有机会复用现有3.3V电源，不一定需要新增5V轨，但必须核对驱动压降、3.3V轨上下限、线圈温度、允许连续施压与最高温吸合电压。手册的最大线圈电压不能不加条件地解释为长期允许过压。

忽略驱动压降、按23°C名义电阻估算五路同时吸合：

| 方案 | 单路线圈电流@3.3V | 五路总电流 | 五路线圈总耗电 |
| --- | --- | --- | --- |
| G5V-1 DC3，60Ω | 55mA | 275mA | 约0.91W |
| G6K DC3，91Ω | 36.3mA | 181mA | 约0.60W |

电阻公差、低温等会增大电流；还要计入驱动和电源损耗。这明显高于五路 PhotoMOS 按每路5mA驱动时约25mA、3.3V侧约82.5mW的电流/功耗量级。不能沿用此前电源余量而不重新核算Wi-Fi峰值和五键同时按下。

**线圈不能直接由 ESP32-S3 GPIO 驱动。** 每路需NPN/MOS或驱动阵列、默认关断偏置及续流网络；继电器掉电保持型/磁保持型还会改变复位默认释放的实现，本轮不选这种省电方式替代非保持触点。

若改用5V线圈，应把5V轨及驱动一并计价。工具输入可以是5V或12V，当前内部已规划的3.3V降压并不自动提供受控5V电源；也不能把被测设备外接充电器5V当工具必然存在的辅助轨。

### Hongfa HFD23、干簧方向的核验边界

本轮未取得可确认版本的 Hongfa HFD23 官方PDF，因此不写其线圈电阻、触点材料、寿命或所谓最小负载数值。可以继续按完整3V/5V料号查官方手册和采购价，但不能用电商标题补齐参数。

干簧继电器能提供独立浮动无极性触点，也可研究；需要逐型号核验最小适用负载、接触电阻、弹跳、线圈功耗、封装、磁场干扰和续流。没有官方手册前，不声称“干簧一定更便宜/无弹跳/零漏电”。

## 方向 C：共地模拟开关或离散MOS为何不直接等价

### 普通双向模拟开关

以 TI CD4066B 为可核实例子，其双向开关信号必须处于 VSS～VDD 内，供电范围3～18V；5V供电时控制高电平门限为3.5V，不能保证由3.3V MCU直接识别。现行手册推荐连续信号电流为±10mA，也没有覆盖当前20mA目标。[S5 §5.3～5.5]

这不是说所有模拟开关都不合适，而是说明“它能双向导通”不足以证明可替代：

- 3.3V供电的器件不一定允许6V信号，许多器件还会通过保护结构向电源轨灌电。
- 即使信号差分只有6V，两端相对工具地的共模也可能超出其信号轨范围。
- 扩大模拟开关电源电压可能需要额外电源和逻辑电平转换，不能只计开关芯片价格。
- 共地接口要求改变了五路浮动触点能力，只有用户确认改变接线边界后才能采用；本轮不作此变更。

### GPIO直接控制背靠MOS

两颗背靠MOS可以阻断两方向体二极管，但栅极仍需相对共源节点获得足够驱动。GPIO只能相对工具地输出0/3.3V；触点整体浮动或共源电位升高时，无法保证VGS，低压MOS阈值也不等于20mA下所需的导通电阻保证。

补上浮动光伏驱动可以恢复这类能力，但每路需要驱动器＋双MOS及外围，已经接近离散实现PhotoMOS，当前20mA按键应用不应未经核价就认定它更便宜。[S6 官方双向驱动应用；电路分析]

## TLP176AM能否省去五颗NPN

**有直接驱动的研究空间，但不能只用“GPIO能出40mA”和“触发3mA”作为结论。** TLP176AM推荐IF≥5mA；ESP32-S3模组表列VOH≥0.8×VDD，但相关脚注说明VOH/VOL为高阻负载测量，40mA源电流值也是规定条件下的典型值，不是任意GPIO负载下的完整保证。[S1 第3、5页；S4 第27～28页]

若采用高电平点亮：`GPIO → 限流电阻 → LED → 工具地`，必须满足：

- 最低供电、实际负载VOH和最高VF组合下，IF仍符合选定温度/动作要求。
- 最高供电、最低VF和电阻公差组合下，不过度消耗GPIO/总供电电流。
- GPIO高阻、复位、工具上电和初始化期间不误点亮；外部默认下拉与真实启动波形必须检查。

一个只用于说明余量问题的计算：假设最低VDD=3.0V，取0.8×VDD=2.4V、VF=1.4V，330Ω电阻只能得到约3.0mA，未达到5mA推荐值。约180Ω可把该假设下电流提高至5.6mA，但最高3.6V、VF=1.1V时约13.9mA/路，五路可接近70mA；且**2.4V本身还不是该带载条件下已保证的VOH**。因此该算例不是可投板阻值。

若采用低电平吸电流点亮，则默认状态需外部上拉；不能把高电平有效方案的下拉原封不动照搬。也须核验VOL、总灌电流及上电期间状态。

保留NPN方案可把LED电流从GPIO直接负担中分离，驱动和默认状态更容易闭合。省NPN方案预计只减少5颗三极管及相应部分阻容，PhotoMOS和端子仍保留；应在确定PhotoMOS单价后再判断是否值得，不应把它当作按键模块大幅降本的核心手段。本文未更改原驱动方案。

## 完整成本比较口径与建议

五路总成本应按以下口径比较：

- **PhotoMOS**：5颗开关＋5路限流/驱动/默认状态阻容＋端子与贴装成本。
- **机械3V**：5颗非保持继电器＋5路驱动/默认状态/续流＋增加的3.3V供电余量、PCB面积和装配成本。
- **机械5V**：在机械3V口径基础上核实是否新增5V稳压与相关外围，不能漏算。
- **模拟开关**：只有已确认信号范围、共模、逻辑和共地能力允许时再比较总价；本轮不能作为同能力低价替代。

建议先拿到一至两款较小电流 PhotoMOS 的官方手册与五颗实际报价，再与3V非保持式信号继电器整套核价。机械方案如明显便宜，先用高阻微小电流按键和10ms动作做台架比较，再决定是否替换。当前不承诺节省金额，也不改变五路独立浮动的能力。
