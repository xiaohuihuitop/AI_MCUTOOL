## 为什么现有焊盘可以装 AO3400A

MMBT3904LT1G 的顶视脚位为1=B、2=E、3=C；AO3400A 顶视为对应位置的 G、S、D。现电路的控制输入、工具地、负载分别能够映射到1=G、2=S、3=D，不需要调脚或飞线。[S1，S2]

不能只按“SOT-23”名称推定足印相同：当前 PCB 上，Q1～Q5/Q14 使用 `SOT-23-3_L2.9-W1.6-P1.90-LS2.8-BR`，Q6/Q7 则引用另一份 `LS2.4/W1.3` 库足印。实际核对如下。[P1，P2]

| 参数 | Q1～Q5/Q14现有铜盘 | AOS官方SOT23机械图/建议焊盘 |
| --- | ---: | ---: |
| 同侧1、2脚中心距 | 1.89992mm | e1=1.90mm |
| 相对两侧焊盘中心距 | 2.47015mm | 推荐焊盘中心距2.40mm |
| 单铜盘大小 | 约1.070×0.600mm | 推荐0.80×0.80mm |
| 器件名义本体 | 库名称2.9×1.6mm | D=2.90mm、E1=1.60mm |
| 器件引脚总跨距 | 库名称2.8mm | E=2.60～3.00mm，名义2.80mm |
| 金属引脚宽度 | 现有横向铜盘0.600mm | b=0.30～0.50mm |

现有三块铜盘与 AO3400A 的三个引脚位置及机械范围相容，支持原位装配。现板铜盘不是 AOS 推荐焊盘的逐尺寸复制，以上结论不冒充贴装良率实测。[P2，S3]

装配资料应保留**已制造 PCB 的旧焊盘、位号、贴片中心及1脚方向**，只将对应 BOM 行改成 AO3400A；不要为了统一型号，使用新器件库足印覆盖旧 PCB 后重新输出一套不同的坐标。换符号及名称也不构成修改既有铜盘的理由。

## 驱动电压和输入串阻的判断

AO3400A 的官方导通电阻保证点最低为 VGS=2.5V：RDS(on)最大48mΩ，25℃、ID=3A测试条件。VGS(th)=0.65～1.45V是在250µA测试点定义的阈值，不能用来宣称 MOS 已充分导通。[S2第2页]

在满足2.5V栅源驱动的前提下，五路光继电器的几毫安输入负载以及 Q14 的约0.5mA稳态下拉负载，远小于功率型 AO3400A 的导通电阻测试电流。Q14不承载2A充电主电流；真正载流的是 Q12/Q13。[P1，S2]

保留10kΩ栅源下拉时，稳态栅压近似为 `VGS=VGPIO×10k/(R串+10k)`。表内瞬态峰值忽略 GPIO 输出电阻，仅用于比较，不是实测波形。

| GPIO串阻 | 3.3V下名义栅压 | 稳态GPIO电流 | 初始充电电流算例 | 计两电阻1%容差，VGS≥2.5V所需GPIO高电平 |
| --- | ---: | ---: | ---: | ---: |
| 100Ω | 3.267V | 0.327mA | 33.0mA | ≥2.526V |
| **240Ω** | **3.223V** | **0.322mA** | **13.75mA** | **≥2.562V** |
| 330Ω | 3.195V | 0.319mA | 10.0mA | ≥2.585V |
| 680Ω | 3.090V | 0.309mA | 4.85mA | ≥2.674V |
| 4.7kΩ | 2.245V | 0.224mA | 0.70mA | ≥3.699V |

因此 **Q14不能只把三极管换成 MOS，仍保留 R35=4.7kΩ**：正常3.3V下分压也达不到2.5V保证点。240Ω比330Ω稍有栅压余量，并能合并到既有 LED 限流电阻料号；比100Ω减小瞬态 GPIO 充电电流，是本次优先建议。[计算，S2]

ESP32-S3-WROOM-1/1U v1.8 的 VOH≥0.8×VDD 有“高阻负载测量”脚注；40mA源电流一项是典型值。不能把这些直接当成约0.32mA负载及全部温度下的无条件保证。240Ω方案首板上电时应测 GPIO 高电平≥2.562V及实际 VGS≥2.5V，并检查单路、五路同时按下与充电开关动作。AO3400A 的栅极电荷表列约6nC典型/7nC最大，但测试电压不同，不能直接将其换成未经测量的实际开关时间。[S2，S4]

这是一项装配兼容且有电路依据的候选统一方案，不代表已经完成样机全条件验证。不会新增自动调压、自动旁路或其他软件行为。

## 光继电器、功率 MOS、二极管与指示灯

- **AP60P20Q：**六颗均为 C2828591/PDFN3×3-8L，已是一种料。它是 P 沟道功率 MOS，不能用 AO3400A 的 N 沟道/SOT-23替代。[P1，S5]
- **GAQY221S：**五颗均为 C7435105/SOP-4，已是一种料。制造商建议输入 LED 电流5～30mA；原来的五颗240Ω LED限流电阻应保持。换低压降 N-MOS 后，以3.0V、VF预算1.4V及电阻+1%估算，LED约6.6mA；3.6V按仅电阻限流的宽松上界约15.15mA。VF和驱动压降的温度边界仍需样机核对。把 LED 限流增至330Ω，在旧预算3.0V/1.4V/0.3V下仅约3.9mA，不适合作为合并料号的替代。[S6，计算]
- **独立光伏驱动/普通光耦：**当前140颗清单中没有 VOM1271T、PC817 或普通光敏三极管光耦；不应按旧设计另备料。GAQY221S本身仍通过光隔离工作，不能将“没有独立光耦料号”理解为没有光隔离。[P1]
- **D1/D2：**均为 SS34/C8678/SMA，已统一，用于两路工具5V输入的隔离。**D3/D4**均为 BZT52C6V2/C707135/SOD-123，已统一，用于 MOS 栅源限压；**D5**为 USBLC6-2SC6/C2687116/SOT-23-6，用于 USB 静电保护。三类功能与封装均不同，不应为了减少种类互换。[P1]
- **LED1/LED2：**现清单分别为 LTST-C190KRKT/C94869红灯和 LTST-C190KGKT/C125094黄绿色灯。当前 PCB 都使用0603双焊盘，现有库极性映射一致；统一同一颜色可减少一种料，但改变原电源灯/状态灯的颜色区分，不列入保留现行为的推荐清单。本轮未取得其最新原厂 LED 手册，商城资料页返回验证页面，不将库信息单独当作最终替料保证。[P1，P2]

INA228→INA226属于测量芯片的性能取舍，不是把整板已有两个型号合并；当前实际清单仍为 INA228AIDGSR。该讨论不自动计入本次统一建议。[P1]
