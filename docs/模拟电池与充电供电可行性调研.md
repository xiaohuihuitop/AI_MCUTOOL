# 模拟电池与充电供电可行性调研

调研日期：2026-10-15。本文是初步选型证据与工程核算，不是已确认原理图，也不代表器件已通过样机验证。依据项目需求记录和本轮已确认的成本、尺寸边界：元器件 BOM 目标不超过 200 元，不含 PCB、焊接、外壳、适配器和线材；整机包含固定接插件不超过 100mm × 100mm × 100mm。

适用性更新：模拟电池电源和充电用 5V 电源均已确定外置，本文相关内置电源选型不属于当前集成范围。文中的单节电池电压、功率和“充电时设备不工作”仅为原始设备算例，不限制工具调用；当前工具额定能力以 [需求记录](MCU开发辅助工具需求记录.md) 为准，供电通路额定电压仍待选型确定。

## 结论

- 模拟电池采用可控同步降压电源，比从 12V 直接线性降压更符合体积与散热目标；DAC 经电阻注入反馈节点是可以进一步设计的调压方法。
- 2.8V 输出持续 10W 对应 3.57A。3A 额定降压器不能据此宣称满足全范围持续 10W；4A 器件可以进入候选，但仍需核算热、纹波、限流和压降。
- TPS564252/257 的 3～17V 输入、4A 输出和大占空比特性值得优先评估；TPS564201 也可比较，但 5V 输入、4.3V 输出端点的压差更紧。
- 5V 充电输出若要求在 5V 和 12V 两种适配器下均稳压，宜评估升降压电源；仅靠降压器或输入直通不能保证 5V 输入时端口仍为 5V。
- 真实电池承担充电，模拟电池只承担供电。真实电池通路必须允许双向电流；普通只允许单向供电的电源复用方案不能直接套用。
- 五路按键用光耦 MOS 触点有实现依据，但漏电、导通电阻和开关延迟需要核验。它们不能兼任约 4A 的主供电选择开关。

以上是候选方向。尚未查询可采购单价，因此不能宣称整机 BOM 已满足 200 元。

## 原始算例条件及功率核算

模拟电池设定 2.8～4.3V，暂按持续 10W 评估；真实电池与模拟电源切换允许设备断电。充电输入 5V、最大 2A，充电时设备不工作；模拟电池模式不进行充电验证。使用 12V/2A 或 5V/2A 独立适配器，由人工选择，不引入供电预算识别、自动调低输出或备用供电逻辑。

下表均为功率公式估算，不是实测能力：

| 工况 | 核算 |
| --- | --- |
| 模拟电池 2.8V、10W | 输出电流约 3.57A |
| 模拟电池 4.3V、10W | 输出电流约 2.33A |
| 模拟电池输出 10W，假设转换效率 90% | 变换器输入约 11.11W，自身耗散约 1.11W，未含工具其他电路 |
| 12V 输入、上述 10W 工况 | 变换器输入约 0.93A，未含工具其他电路 |
| 5V 输入、上述 10W 工况 | 变换器输入约 2.22A，已超过 5V/2A 适配器能力 |
| 5V 充电输出 2A，假设效率 90% | 同样约需 11.11W 输入，另加工具耗电 |

因此 5V/2A 是小功率使用条件，并不承诺完整 10W 输出或完整 5V/2A 充电输出；这属于人工选用适配器的物理约束。充电与模拟电池满负载无需相加，但每种模式都需要计入 Wi-Fi 主控、测量及继电器等自身功耗。

### 纹波与低电压端点

对同步降压器，理想电感纹波可先按 `ΔIL≈Vout×(1−Vout/Vin)/(L×fs)` 估算。以 12V 输入、2.8V 输出、600kHz、4.7µH 为纯计算示例，纹波约 0.76A 峰峰值；3.57A 负载下峰值约 3.95A。电感必须按温升、直流偏置与饱和余量选择；4.7µH 不是已选参数，应检查器件允许的 LC 范围。

12V→2.8V 的占空比较低，而 5V→4.3V 的占空比较高；需分别检查最小导通时间和最小关断时间。后者还要计入适配器容差、输入线损、FET 与电感压降、通路选择开关和测流分流器压降。

TPS564252 的 Eco 模式会在轻载进入间歇开关；TPS564257 在轻载保持 FCCM，厂商明确称其有更低输出纹波，见首页及 §7.3.2 p13。[S5] 仍需用示波器验证空载、微安负载、休眠到启动阶跃和调压期间的纹波；本工具首版不提供波形采集，并不妨碍研发时使用外部示波器。

### DAC 注入反馈调压

在上拉电阻 Rt、下拉电阻 Rb 之外，经 Ri 将 DAC 电压注入 FB。按节点电流方程，稳态有：

`Vout = Vref × (1 + Rt/Rb + Rt/Ri) − Vdac × Rt/Ri`

这是工程推导，并非厂商现成验证电路。DAC 电压越高，输出越低；需计算整个码值范围、DAC 断电时引脚状态、上电复位值、输出驱动阻抗及注入对控制环路的影响。DAC 更新与输出接通顺序必须进入设计，不可假定 MCU 上电即已写好正确码值。

DAC60501 是核验过的 12 位 DAC 示例，2.7～5.5V 供电，具有内部参考和零码/中码上电复位选项，见首页与 §8.6 p29。[S6] 若使用 2.5V DAC 满量程、反馈比例 Rt/Ri=0.6，理论输出调节步长约 0.366mV；这是量化步长，不是输出精度。该型号尚未查价，不代表低成本最终推荐。

直接以 12V 线性降到 2.8V、输出 10W 时，串联调整管耗散约 `(12−2.8)×3.57=32.9W`，输入约 42.9W，已超过 12V/2A 适配器功率，且不适合当前体积与成本目标。降压预调节加低压差线性后级是另一种架构，但目前没有证据表明有必要引入，应先测开关方案纹波。

## 可控 5V 充电电源

TPS63070 是 2～16V 输入、2.5～9V 输出的同步升降压候选。首页给出降压模式 2A、4V→5V 升压模式 2A 的能力，§7.3 p4、§7.5 p6～7 给出工作条件与限流参数。[S7]

它可覆盖 5V 与 12V 两种输入下的稳压拓扑需求，但“3.6A 开关电流”不能写成“3.6A 输出”。具体输入、输出关系下还需核算效率、输出电流、热和电感电流。5V 输入时即便变换器本身支持 2A，5V/2A 适配器也不能同时承担转换损耗及工具自身功耗。

TPS63070 的强制 PWM 模式标称直流精度 ±1%，PFM 为 −1%/+3%；其 §8.5.1 p14 描述低功耗模式的典型 50mV 峰峰值纹波，且条件为 22µF 有效电容。[S7] 模式与输出电容需根据最终充电端允许误差和热测试决定，不能把典型效率或典型纹波作为整板保证值。

充电口“断开”需要检查输出电容残压和 DUT 充电芯片的反向漏电。TPS63070 具有关闭时负载断开特性；带输出放电的是 TPS630702 变体，不能混用型号特性，见 §8.5.3 p15。[S7] 是否需要主动放电、断开后降到何种电压及多快，仍待确定，本文不新增主动放电功能。

## 通路切换与按键触点

### 电池功率通路

真实电池与模拟电池切换需要比较功率继电器与背靠背 MOSFET，不在此直接定型。

| 方案 | 优点 | 要核验的条件 |
| --- | --- | --- |
| 功率继电器 | 接点可双向导通；断开隔离直观；满足允许断电的使用场景 | 在实际电压下的直流开断额定、至少覆盖约 3.6A 的载流、触点电阻、接点抖动、线圈功耗、尺寸和寿命；不能拿信号继电器额定代替功率额定 |
| 背靠背 MOSFET | 小体积、低导通压降、无机械磨损 | 两个相反体二极管用于关断双向隔离，导通时通道允许双向电流；栅极驱动必须覆盖 2.8V 低端，并核验断电状态、漏电及热。真实电池导通期间必须允许充电电流反向流过 |
| 集成负载开关 | 集成时序或关断隔离，外围较少 | 需要逐型号确认反向电流逻辑，不能仅凭“反向阻断”几个字选型；部分器件会破坏真实电池充电通路 |

TI SLVA139 p2 说明单 MOSFET 的体二极管及 `I×Rds(on)` 压降原理。[S8] 相反体二极管背靠连接和通路双向性的分析属于据此进行的工程推导，最终应按所选 MOSFET 和驱动的实际电路验证。

TPS22953 可作为资料对照：0.7～5.7V、5A，关闭时具反向电流阻断；§9.3.7 p26 明确其阻断发生于关闭状态，§10.1.6 p32 给出先断后接电源选择电路。[S9] 该芯片不是当前已选通路器件，真实电池充电导通条件下的反向工作能力仍必须单独确认。

模拟源不需要吸收充电电流的前提是：模拟源与真实电池不发生直接并联，且模拟源接入 DUT 时不能启用充电输入。建议把先断后接及充电模式互锁提交为待确认的硬件/固件约束；不能只依赖 AI 正常调用顺序。这里没有把互锁擅自记为用户已确认功能。

### 五路独立按键触点

Panasonic AQY212GS 官方规格页可验证这类 PhotoMOS 的 AC/DC 常开触点原理：导通电阻典型 0.34Ω、最大 0.7Ω，关断漏电最大 1µA，导通时间最大 5ms、关断最大 0.5ms；推荐 LED 电流至少 5mA。[S10] 该型号官网标注将停产，只用于可行性举证，不推荐作为新设计定型。

这些数据说明五路彼此独立、每路两个接线端的按键短接可行，也说明它不是理想无损接点。高阻上拉按键的 1µA 漏电、矩阵扫描延迟、电阻编码按键的串联电阻都需要实测；毫秒级 PhotoMOS 不能承担高频数字时序功能。主电池通路约 3.6A，不应复用该按键触点器件。

## 下一步验证与待决定项

1. 确认充电输入与模拟电池通路互锁，以及先断后接约束；确定输出关闭和向下调压的时间要求。非吸收型降压器的下降速度可能主要取决于输出电容和负载，微安负载下尤其明显。
2. 确定模拟电池输出设定误差、线端电压定义及允许纹波；现有 1mV 指标属于四路电压采集分辨率，不能自动转为模拟电池输出精度。
3. 用候选 4A 降压方案验证 12V→2.8V/3.57A 持续热稳态，以及 5V→4.3V 在小功率工况下的压差。12V/2A 满能力与 5V/2A 小功率能力分别报告。
4. 核验真实电池充放电的通路压降、隔离漏电、切换抖动及充电反灌；随后与微安测流电路一起验证，避免仅对电源模块空载测量。
5. 按实际采购渠道和数量核价，统计电源 IC、DAC、电感、功率器件、五路光继电器和接插件，再判断是否达到 200 元 BOM 目标。
