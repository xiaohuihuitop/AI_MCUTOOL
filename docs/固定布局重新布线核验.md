# 固定布局重新布线核验

日期：2026-11-05。主工程：`D:\LCEDA\projects\AI_TOOL\AI_TOOL.eprj3`。

以用户15:18保存的最新布局为基准，仅重新处理铜线、过孔和覆铜。全部140颗器件的位置、实际朝向、14颗锁定状态保持；423个器件焊盘、28个独立焊线孔、415个逻辑引脚及器件身份均核对一致。原理图所有文件的SHA256保持，文字、板框、规则、层叠及天线禁布区保持。

## 布线结果

- 主供电采用2.5mm主干，分流器附近局部1.2mm；充电通路采用2mm主干，共源汇流1.2mm，MOS并联脚以0.3mm短支路汇流。五个供电焊线孔按对应宽铜接入。
- 四端分流器的Kelvin采样、滤波后线路、四路高阻输入及运放反馈优先顶层布线；采样与反馈路径核对为无过孔。
- USB主段采用0.30mm线宽、名义0.18mm间距，按当前ESD、串阻和主控位置连接。实际L2公共地覆铜在主段中心和边缘投影下的缺口均为0。该检查不代表制造阻抗或通信性能已实测。
- 重建地与3.3V平面接入及LDO散热铜。U3中间大焊盘、两面散热区和散热过孔均属于LDO_VIN输入网。
- 修复原生布线器造成的5V支线与USB交叉、充电控制线及过孔与供电粗铜相碰；清理USB_DP上的额外悬空支线和冗余铜尾。全程未移动元件或调整其朝向。

- 剩余25处“悬空端点”提示，实际端点均接触同网焊盘、铜线或覆铜。
- U13“过孔压焊盘”提示经实际旋转焊盘形状复核，铜边间距约0.361mm，无相交。

- 公共地“线宽不足”提示指向R63.2的0.25mm局部小信号接地支路；主公共地平面存在。
- 两处丝印压焊盘提示（R33/Q12、R37）来自既有文字布局，本轮只布线，保持原样。其余转角、非正交、小支线和平行走线等经验提示保留，详见机器摘要。

原生布线器将两对继电器输入近共线段合并，最大中心线偏差低于5µm，端点、线宽和完整铜宽净距已复核。保存重载也会合并图元：第一次核验的947条变为922条；随后清理4条多余USB铜线，最终为918条。关键铜几何始终另行核验，不用图元数量代替检查。

客户端将270°表示为−90°，实际朝向相同。少量可见文字坐标被保存为0.0001mil精度，最大量化约1.27nm；隐藏库属性坐标归零的项目单独记录。元件和实际焊盘仍按1e-6mil容差与原布局比较。
