# 首版外围器件候选评估

**当前电源方案更新**：用户于2026-10-23确认工具DC与Type-C均只接受5V，内部改用3.3V LDO。下文工具5V/12V及开关降压分析保留为历史候选；当前连接以 [硬件方案](MCU开发辅助工具硬件方案.md)及 [首版规格](../.scratch/mcu-assistant/spec.md)为准。被测设备通路和电压检测的0～15V目标不受工具供电变更影响。

日期：2026-10-16。依据 `.scratch/mcu-assistant/spec.md`，主控按用户指定的 ESP32-S3 N16R8 配置考虑。本文只筛选外围候选，不代表原理图、物料价格或测量误差已验证。

当前范围：外部电源自行调压、充电器外置，工具仅选择和开关通路；电流固定 ±3A、小电流误差目标 ±100µA；四路 0～15V、1mV 分辨率；一路 3.3V UART；五路独立按键触点。元件 BOM 目标不超过 200 元，整机 100mm × 100mm × 100mm。供电通路的额定电压尚未确定，不能从四路电压采集量程推定为 15V。

后续确认：用户已单独认可主通路 0～15V、双向 3A 设计目标及独立充电通路 5V/2A；本文原始候选分析不等于这些额定目标已经实测通过。

## 可进入电路设计的候选清单

| 模块 | 候选 | 初步判断 |
| --- | --- | --- |
| 电池端双向测流及电压 | INA228 + 20mΩ 四端分流器 | 优先验证；全程用宽档，理论小电流误差有希望，仍需校准与噪声验证 |
| 四路电压采集 | ADS1115 + 四组高阻分压 + 低偏置四路缓冲 | 可实现 1mV 量化分辨率；缓冲是为减小高阻分压的 ADC 加载影响 |
| 电压缓冲器 | TLV9004；需要更低失调时比较两颗 OPA2333 | TLV9004 成本导向，但绝对误差不能按 1mV 承诺；OPA2333 也需处理近零输出 |
| 五路按键 | 五颗 Toshiba TLP176AM | 正常可订购候选，官网未标 NRND；仍需实际采购报价及高阻按键漏电影响验证 |
| 电源/充电通路 | 三路常开功率继电器，例如 G5Q-1A4 DC5；或三组背靠背 MOSFET | 两种方案均保留；机械触点的微小负载可靠性和压降是重点，MOS 的栅极驱动与漏电是重点 |
| 工具 3.3V 工作电源 | TPS56339 同步降压 + 配套电感/电容 | 4.5～24V 输入覆盖名义 5V/12V，3A 等级有主控瞬态余量；此处不向 DUT 提供模拟电源 |
| UART 接线缓冲 | SN74LVC2G125 等带 Ioff 的三态缓冲器作为比较对象 | 只能解决对应断电条件，不能把工具供电时的高电平对 DUT 反灌也自动消除 |

本表不是确定 BOM；无需内置模拟电池变换器、充电变换器或 DAC 调压电路。

## INA228 与固定 20mΩ 分流器

INA228 官方数据手册给出双向分流电压宽档 ±163.84mV、窄档 ±40.96mV，宽档量化步长 312.5nV，最大失调 ±1µV、最大增益误差 ±0.05%，最大失调漂移 ±10nV/°C。失调指标对应转换时间大于 280µs 的条件，不能套用在最短转换设置。[S1，首页及 §6.5 p5]

20mΩ 的工程核算如下：

| 项目 | 估算结果与含义 |
| --- | --- |
| ±3A 满使用量程 | 分流电压 ±60mV；窄档会超量程，固定使用宽档 |
| 3A 分流耗散 | 0.18W；器件额定功率仍需按温升、降额和 PCB 散热选择，建议先比较不低于 1W 的四端低温漂型号 |
| 3A 分流压降 | 60mV；还需叠加继电器/MOS、接插件和走线压降 |
| 原始 ADC 量化步长 | 312.5nV / 20mΩ = 15.625µA；不是 1µA 原始分辨率，也不是最终误差 |
| 最大失调折算 | 1µV / 20mΩ = 50µA；只占误差预算的一部分 |
| 失调温漂折算 | 最大 0.5µA/°C；相对校准温度变化 25°C 对应约 12.5µA |
| 3A 处芯片增益误差 | 0.05% 对应 1.5mA，尚未计入分流器误差；不能承诺全量程 ±100µA |
| 示例 0.1% 分流器初始误差 | 3A 处再贡献 3mA，温漂和自热另外计算；该精度仅是采购比较条件，未选定具体分流器 |

四线开尔文布线用于分离载流铜箔压降与电压采样路径；低热电势连接、焊点温度梯度、供电噪声和磁场耦合也可能产生微伏级干扰。不能把 50µA 的芯片失调折算直接写成整机精度。

### 约一秒读数与噪声

INA228 §8.1.3 表 8-2 p32～33 给出典型噪声表现：宽档下，2.074ms × 256 次平均约 530.944ms、4.12ms × 256 次平均约 1054.72ms，均列出 19.7 位 noise-free ENOB。[S1] 按满差分跨度 327.68mV 反推，对应典型噪声峰峰值约 0.385µV，即 20mΩ 上约 19µA 峰峰值。这是由典型表格推导的估算，不能作为整机最大噪声保证。

还需注意，表格中的周期针对相关 ADC 转换设置；若同时平均分流、电压、温度转换，更新时间会相加。要在约 1 秒内获得电流稳定值，应先设计通道调度，再在 Wi-Fi 发射、继电器动作前后和温度变化时实测。零点校准可以成为测量设计的一部分，但何时校准、是否允许自动校准须单独定义，不能默认扣除正在流动的 DUT 电流。

### 测量电路自身的负载

INA228 的 IN+/IN− 输入偏置最大 2.5nA，但 VBUS 输入在工作模式下阻抗为 0.8～1.2MΩ；它并非纳安级电压测量负载。[S1，§6.5 p5] 例如 4V 时，VBUS 约取 3.3～5µA；15V 时约取 12.5～18.75µA。

VBUS 接在分流器 DUT 侧时，该支路电流会与 DUT 电流一起被测量；接在源侧可以避开这一测流偏置，但读到的是源侧电压，并不等于 DUT 端电压。应在原理图中明确测量定义，而不是未经说明地软件减去一个名义固定值。

## 四路 ADS1115 电压输入

ADS1115 支持四路单端复用采集、8～860SPS，单端正电压只使用有符号编码的正半区，不是 65536 个正电压码。[S2，首页、§5.5、ADC 转换说明]

可用的分压计算示例：上臂 1MΩ、下臂 200kΩ，比例为 6，15V 输入变为 2.5V。采用 3.3V 供电和 ±4.096V PGA 设置时，125µV ADC 步长折算输入端为 0.75mV，满足 1mV 分辨率的量化前提。±4.096V 是 ADC 标度，并不允许在 3.3V 供电时把 4.096V 接到引脚；模拟输入仍必须满足实际供电轨限制。[S2，§5.5 p5～6]

### 为什么需要缓冲

上述分压等效输出电阻约 166.7kΩ。ADS1115 的输入是开关电容结构；±4.096V 档列出的典型共模输入阻抗为 6MΩ、差分输入阻抗为 15MΩ，不能当作无负载理想电压表。[S2，§5.5 p5] 将高阻分压直接接入会有增益偏差和通道切换建立时间影响，不能只用一个固定输入电阻精确校正。

分压后加低偏置电压跟随器，再匹配 ADC 输入 RC，可减小此问题。TLV9004 支持 1.8～5.5V、轨到轨输入输出、单位增益稳定，典型输入偏置 5pA；其失调典型 ±0.4mV、25°C 最大 ±1.6mV，在该分压比例下仅缓冲器就可能贡献输入端约 9.6mV 最大失调。[S3，首页、§6.7 p17] 因而它适合“1mV 分辨率、绝对误差另定”的当前要求，不能冒称 ±1mV 精度。

更低失调候选是两颗 OPA2333：最大失调 10µV、25°C 输入偏置最大 200pA，1.8～5.5V 供电。[S4，首页、§6.6 p7] 但轨到轨输出仍不等于真正到 0V，近零测量需要实际核验；两颗精密运放的成本也要比较，当前不新增负电源来解决近零问题。

### 输入负载必须一起验收

1MΩ+200kΩ 分压在 15V 时每路吸取 12.5µA，在 4V 时每路约 3.33µA。若四路都接 DUT 的 4V 电源，合计约 13.3µA，尚未计入 VBUS、输入保护和 UART 接线影响。缓冲器并不能消除这组分压电流。

对 ±100µA 的工具误差目标，这些负载不能忽略；对原本只有几微安的 DUT，它们甚至可能超过 DUT 本身。提高分压电阻可降低取电，但会放大板面漏电、保护器件漏电、湿度及污染影响，需在成本与建立时间间取舍。实际测量应分别报告工具接入前后 DUT 的变化，避免把工具负载解释为设备固件功耗。

ADS1115 是一组复用 ADC；860SPS 不是四路各 860SPS，也不是四路同时采样。当前不做波形功能，顺序慢速采集可行，但最终每路刷新率仍待确定。

## 五路 PhotoMOS 按键

推荐继续比较 Toshiba TLP176AM。其官方页面提供现行可订购型号 TLP176AM(TPL,E，且没有 TLP175A 页面上的 Not Recommended for New Design 标识；2026-04-07 Rev.7.0.A 数据手册仍有更新。[S5、S6] 这支持列入正常产品候选，实际库存与报价还需采购核实，不能据此保证现货或低价。

已核验条件：[S5，§7 p3、§10～13 p5]

- 常开 AC/DC 独立两端输出，适合每路两个独立端子、不共地。
- 推荐 LED 电流 5～25mA，典型推荐 7.5mA；五路同时驱动时按该条件核算，不以 3mA 最大触发电流代替完整性能测试条件。
- 导通电阻典型 0.15Ω、最大 2Ω，条件为 IF=5mA、ION=700mA。
- 关断漏电最大 1µA，条件 VOFF=60V、25°C；不能据典型 0.002µA 承诺全温漏电。
- 导通延迟最大 3ms、关断最大 0.5ms，条件 RL=200Ω、VDD=20V、IF=5mA；真实按键条件下需复核。
- 推荐工作电压上限 48V；这不是已经为本工具确认的按键额定电压。

高阻上拉、矩阵扫描与电阻编码按键都要验证串联电阻及漏电是否改变识别结果。单击/组合按键的本地时序应考虑毫秒级器件延迟；它不适用于首版之外的高速数字采集。按键器件不可兼作 ±3A 功率通路开关。

TLP175A 官网已标 NRND，早前 AQY212GS 官网标将停产，均不作为新设计优先候选。没有授权分销报价，因此本次只能推荐可核验的型号，不能宣称五路 PhotoMOS 已达到某个人民币价格。

## 三路功率开关：机械继电器与背靠 MOS

三路对应真实电池、外部可控电源、外接 5V 充电器。供电通路需要接通时双向导通、关闭时阻断回灌；真实电池必须允许充放电。上电、重启默认关闭及真实/外部源互斥、仅真实电池模式可开充电，均来自现行规格。

| 项目 | 三路常开功率继电器 | 三组背靠背 MOSFET |
| --- | --- | --- |
| 默认关闭 | 常开触点配驱动下拉，未吸合即断开 | 栅源偏置令关闭，需核验外源存在而工具断电的情况 |
| 接通双向 | 机械接点本身双向 | 导通沟道双向，两个体二极管相反安排才能在关断时双向隔离 |
| 互锁 | 等待真实释放、抖动结束，再吸合另一路 | 要核验栅极放电时间及驱动时序，不能只看软件逻辑值 |
| 小电流测量 | 关断漏电小，但大功率接点在微安负载下的长期可靠性不当然成立 | 避免接点湿润问题，但漏电随温度增大，需加入误差与断电预算 |
| 输出压降 | 接点与老化电阻可能明显大于 20mΩ 分流器 | 取决于实际 VGS 下两颗导通电阻，不可拿阈值电压代表完全导通 |
| 自身功耗/布局 | 线圈持续耗电，占 PCB 面积，有动作噪声 | 无持续线圈功耗，驱动较复杂，高侧低电压能力要确认 |

### 机械候选的实际问题

Omron G5Q-1A4 DC5 为密封常开、5V 线圈候选。官方表列标准 NO 接点 5A/30VDC 电阻性负载，线圈 40mA、约 200mW；这足以进入 ±3A 通路比较。[S7，p1～2] 但它需要 5V 线圈轨：工具输入含 12V 和 5V 两种条件，不能把线圈直接接适配器，也不能默认 3.3V 一定吸合。若最终使用机械继电器，需要一并选择线圈供电方案，不能漏计电源成本。

5V 线圈不代表电源必须精确稳压到 5.000V：G5Q 表列 23°C 条件下吸合电压最大为额定值 75%，即 3.75V。[S7，p2] 因此可以核算低压差稳压轨在 5V 输入下的实际输出是否仍满足全温吸合和保持条件，12V 输入下再检查热耗；不能未经核算就默认增加升降压电路，也不能用 23°C 指标直接保证全温可靠性。

较大的 G5LE-1A4 DC5 也有官方证据：8A/30VDC 电阻性负载，接点电阻最大 100mΩ、吸合最大 10ms、释放最大 5ms，机械体积最大约 22.5mm×16.5mm×19mm。[S8，p1～3] 接点最大 100mΩ 若按 3A 计算就有 0.3V 压降；不是所有实物都会到最大值，但不能据“8A”认为它适合精密低压供电。

G5LE 官方失效率参考测试负载为 5V/100mA。[S8，p2] 这不是低于 100mA 必然失效的硬门槛，却说明不能用该测试直接证明微安休眠工况的触点可靠性。功率继电器方案要以通路压降、微小负载重复接通、浪涌、接点老化和实际 DC 开断测试筛选。

### MOS 方案不得草率定型

以 15V 作为待讨论通路额定电压时，需要相应耐压余量及合适高侧驱动，但 15V 不是已确认工具额定。对低端电池电压，P-MOS 必须有足够低 VGS 下的 RDS(on) 规格，或者使用适当驱动的 N-MOS 对。

例如 AO4407A 虽然是 30V P-MOS，但当前官网 Rev.11.1 手册只给出 −6V/−10V/−20V 栅压下的导通电阻保证。[S9，p1～2] 不能拿其漂亮的毫欧数直接用于约 2.8～4.3V 电池、栅极拉地的电路，故不把它直接推荐为最终器件。

现阶段不额外批准过流断电、自动换源、自动放电或任何新保护动作。器件本身的工作条件与最终通路额定值、浪涌条件、短路行为应在原理图前另行确认。

## 工具工作电源及 UART 反灌

TPS56339 的 4.5～24V 输入、0.8～16V 输出、3A 最大连续输出和 500kHz 开关频率，可用于内部固定 3.3V，覆盖名义 5V/12V 适配器。[S10，首页] 外围包括按手册选定电感、输入/输出电容、自举及反馈元件。5V 输入线损后的最低值、ESP32-S3 Wi-Fi 电流脉冲及继电器动作扰动需实测，模拟测量电源/地布局需控制噪声；芯片额定 3A 不等于工具一定需要 3A。

12V 直接用线性稳压器生成 3.3V，若负载为 0.5A，耗散约 4.35W，作为此工具主供电不合适。该数值是示例核算，不是 ESP32-S3 已实测电流。

UART 的 TX 闲置高电平可能通过未上电 DUT 的输入保护结构反灌，使“关闭电源”后 DUT 仍局部带电；串联电阻只能限流，不能证明完全消除反灌。

SN74LVC2G125 支持三态输出和 Ioff，官方说明 OE 上拉可保证上电/掉电时高阻，Ioff 用于芯片自身断电时的反向驱动防护。[S11，首页、§8.3.4 p11] 但工具仍供电、缓冲仍使能而 DUT 已断电时，Ioff 不会自动替工具关闭 TX。因此应明确 UART 接线隔离/输出使能与 DUT 供电之间的关系；如引入自动使能条件，需先确认行为，不能写成已经批准的功能。UART 也可能连接由其他工具独立供电的 DUT，不能把它的启用强制绑定到本工具供电通路是否接通。

Ioff 和三态漏电本身也有微安级最大值，不能把“高阻”解释为绝对零电流。验收应覆盖双方不同上电顺序，以及 DUT 主电源关闭但 UART 和四路电压探线仍连接的情形。

## 成本与验证优先级

本次未取得可靠的官方或授权分销单价；没有生成人民币成本估算，也没有证明 BOM ≤200 元。优先核价项为 INA228、ADS1115、五颗 TLP176AM、主控模组、三路功率开关、缓冲器及接插件；机械方案还要计入线圈供电与驱动。

建议先验证固定 20mΩ + INA228 的低电流误差和约一秒噪声，再验证接入四路电压及 UART 后的真实负载影响，同时比较机械与 MOS 通路的压降和关闭漏电。原理图前尚需确定通路电压、电流采样与误差的温度条件、四路电压绝对误差、按键允许漏电与动作时长，以及 UART 掉电行为。
