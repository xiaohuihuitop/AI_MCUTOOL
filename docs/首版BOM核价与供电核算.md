## 三、历史TPS56339参考与早期功耗预算

本节保留2026-10-16参考设计及后续分模块负载核算。当前工具电源连接、输入损耗及有效电容取值以本文顶部2026-10-23工具电源更新和新器件核验为准；各负载预算仍用于整机汇总。

TI 数据手册 SLVSEI2A 给出 4.5～24V 输入、3A 额定输出、500kHz 开关频率。[S1，首页] 这里只给 ESP32-S3 与工具外围供电，不能把 3A 额定输出写成内部 DUT 供电能力。

官方 §8.2.2.4 表 2（p17）明确推荐 3.3V 输出组合：

| 元件/条件 | 初稿参数 | 证据或核算 |
| --- | --- | --- |

| FB 下臂 R7 | 10.0kΩ，1% 或更好 | 官方表 2；名义 `0.8×(1+31.6/10)=3.328V`，这是表格取值，不是精确 3.300V |

电感不能只按工具平均负载挑一个小电流型号。官方 §8.2.2.3 p16 提醒，启动或故障瞬态可能达到开关限流，保守选型需考虑限流对应的饱和电流。实际峰值、RMS 温升及 PCB 散热须与候选电感一起核验。

例如 12V→3.3V、4.7µH、500kHz 时，理想电感纹波约 1.02A 峰峰值；5V→3.3V 时约 0.48A 峰峰值。此处是连续导通公式估算，不表示轻载 PFM 实际波形；主控电流阶跃及轻载测量干扰仍需实测。

### 5V/2A 输入是否够用

Espressif 官方模组手册 v1.8 表 6-4（p28）列出 3.3V、25°C、802.11b 1Mbps、20.5dBm 时 Wi-Fi TX 峰值 355mA。[S2] 这是特定 RF 条件下的数据，不是所有固件、Flash/PSRAM 活动和外设组合的保证最大值。

| 3.3V 侧负载 | 初步预算 |
| --- | ---: |
| 模组 RF 峰值参考 | 355mA |
| 五路按键加三路光伏驱动 LED，按 5～10mA/路统一预留 | 40～80mA；真实驱动需求以各器件数据手册为准 |
| INA228、ADS1115、TLV9004、UART 缓冲等 | 预留 10mA，属于预算；INA228 典型 640µA，ADS1115 典型 150µA，TLV9004 典型 60µA/通道 |
| 八路 NPN 基极、指示及其他小负载 | 预留 15mA，属于预算 |
| 未纳入 RF 表格的活动与设计余量 | 增加后按总计 750mA 规划验证 |

3.3V×0.75A=2.475W；假设降压效率只有 80%，输入功率约 3.09W。5V 侧约 0.62A，12V 侧约 0.26A，均低于 2A 适配器额定。效率 80% 是保守核算假设，不是样机实测值。接插件、输入线压降、启动浪涌、局部去耦与 Wi-Fi 发射瞬态仍需要验证。

本架构没有内部 DUT 电源和机械继电器线圈，因此不会把外部 3A 负载电流或 5V/2A 充电电流计入工具适配器。三路光伏驱动 LED 预算可按互锁允许的同时开启数进一步核算，本文先按八路全开的保守值预留。

**2026-10-22 按键驱动细化更新**：[五路按键驱动器件核验](五路按键驱动器件核验.md)推荐240Ω LED限流及680Ω基极电阻。按3.0～3.6V计算包络，五路LED电流粗上界约75.8mA、GPIO驱动粗上界约26.7mA，合计约103mA。后续整机预算应以这项替换原表中的五路按键LED及其基极部分，不能再重复计入相同基极负载；三路光伏驱动及其基极单独核算。原0.75A总预算仍是待整机复核的规划值，不是已验证的最大耗电。

**2026-10-22 主供电开关细化更新**：[双路供电开关单路器件核验](双路供电开关单路器件核验.md)推荐每路VOM1271T输入LED限流100Ω、NPN基极330Ω，单路名义LED电流约18mA；粗上界为LED约36.4mA加GPIO约11.0mA，合计约47.4mA。两路主供电互斥，正常最多开启一路；这些项目应替换原表对应LED和基极预算，不能沿用每路5～10mA统一值。充电驱动后续另行细化与汇总，完整人民币成本尚未核齐。

**2026-10-22 充电开关细化更新**：[五伏充电通路器件核验](五伏充电通路器件核验.md)推荐两颗CSD25402Q3A、MMBT3904LT1G一颗和四颗电阻（10kΩ栅源上拉、100Ω栅极串阻、4.7kΩ基极、10kΩ B-E下拉）。本路取消原历史预算中的光伏驱动及其输入LED；工具3.3V侧仅计GPIO基极网络，按3.6V及4.7kΩ负容差1%作粗上界约0.774mA。正常充电方向的栅极偏置约0.5mA由外接充电源提供，不重复计入工具3.3V预算；开启后若存在反向供电，应按实际路径核算，不能自动从电池读数扣除固定常数。

按当前各模块计算口径，五路按键、一路允许开启的主供电驱动及充电GPIO合计粗预算约为103＋47.4＋0.774＝151.2mA，已含对应GPIO基极网络，不能再重复叠加旧表相同负载。器件数量为五路按键NPN、两路主供电NPN及一路充电NPN，共8颗，但驱动结构不再是八路LED。原3.3V/0.75A整机预算仍须与主控、测量、UART和其他负载汇总验证，不能据此宣称启动或峰值耗电已通过。

## 四、20mΩ 分流器的采购与热误差

**2026-10-22 更新**：依据Vishay官方WSK2512资料，推荐原理样机采用 **WSK2512R0200BEA**：20mΩ、0.1%、真正四端、1W@70℃，该阻值档整件TCR为±35ppm/℃。完整料号按官方编码表核对，具体库存、订购条件及人民币报价仍待采购复核；不把合金材料温漂“<20ppm/℃”当作整件指标。官方证据见 [电池端电流采样器件核验](电池端电流采样器件核验.md)。前文2026-10-16的未核价表为历史记录，不代表本轮仍未找到器件参数。

电流采样初始物料为INA228AIDGSR一颗、上述分流器一颗、两颗10Ω、跨输入100nF及电源去耦100nF。总线共享上拉与ALERT上拉按实际连接计入外围，不能重复统计。INA228历史美元单价仍不能代替当前含税采购成本；完整采样模块人民币报价尚未核齐。

INA228手册条件下工作电流典型640µA、最大750µA，由工具3.3V供电，替换第三节测量IC预留中对应的一项，不额外重复叠加。ALERT的10kΩ上拉在低电平时另消耗约0.33mA（3.3V名义值）；I²C共享上拉按总线实际占空核算。分流器3A时0.18W来自被测供电通路，不计入工具适配器功率，也不把INA228的VS电流加入电池端读数。

| 因素 | 对 20mΩ、3A 的影响 |
| --- | --- |
| 压降与耗散 | 60mV、0.18W；1W 额定只是起点，不代表实际 PCB 上没有温升 |
| 0.1% 初始阻差 | 3A 处为 3mA；可标定初始比例误差，但不消除后续热漂移 |
| 假设 TCR 25ppm/°C，电阻体升温 25°C | 比例变化约 0.0625%，3A 处约 1.875mA |
| 假设 TCR 50ppm/°C，升温 25°C | 约 0.125%，3A 处约 3.75mA |
| 当前候选整件 TCR ±35ppm/°C，假设电阻体升温25°C | 比例变化约±0.0875%，3A处约±2.625mA；25°C升温为算例，非样机实测 |
| INA228 最大增益误差 0.05% | 3A 处约 1.5mA，尚未计分流器、连接及热电势 |
| INA228 最大输入失调 1µV | 折算 50µA；有转换时间等测试条件，见前期评估 |

25ppm/°C、50ppm/°C和25°C温升保留为比较算例；当前推荐器件的整件TCR为±35ppm/°C，实际温升待测。初始阻差可通过每台增益校准减小，但温漂、自热和参考仪表误差仍需计入。当前已确认电流绝对值0～10mA误差目标±100µA，超过10mA至3A为±读数1%，两方向相同；不能仅凭芯片20位分辨率宣称达标。

| 电池电压 | INA228 VBUS 接指定电池侧测量点 | 源侧还是 DUT 侧需定义；VBUS 工作输入约 0.8～1.2MΩ，存在自身取电 |

串口缓冲的 Ioff 只在规定断电条件下起作用，工具和缓冲都上电时对未上电 DUT 输出高电平仍可能反灌。输入保护元件、过压/短路行为和 UART 禁用策略不在本轮自动批准，须根据已确认的电气边界设计。
