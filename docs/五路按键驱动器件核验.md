# 五路按键驱动器件核验

核验日期：2026-10-22。范围仅为已确认的五路 PhotoMOS＋NPN 低侧驱动架构。每路外部触点差分≤6V、电流≤20mA、无极性、独立浮动，目标为 10ms 级动作；工具电源按 3.0～3.6V 包络核算，GPIO4～8 控制，外部为 2.54mm 排针。

**建议单路原理样机初值：TLP176AM＋onsemi MMBT3904LT1G，LED 限流 240Ω、基极 680Ω、B-E 下拉 10kΩ，电阻均 1%。** 五路复制相同电路。此为有官方参数依据的样机方案，不代表器件已定型或全温、上电及动作精度已经验证；本轮没有查价、采购或修改固件。

## 引脚与封装

| 器件 | 完整封装/编号 | 实际连接 |
| --- | --- | --- |
| Toshiba TLP176AM | **4-pin SO6，厂商封装 11-4M1S**；1＝LED阳极、3＝LED阴极、4/6＝输出Drain；2/5没有引脚 | 1 接 LED 限流电阻；3 接 NPN 集电极；4/6 各接一个外部按键触点端 |
| onsemi MMBT3904LT1G | SOT-23（TO-236），CASE 318、STYLE 6；**1＝B、2＝E、3＝C** | B 经680Ω接GPIO，并以10kΩ接E；E接工具GND；C接PhotoMOS阴极 |

来源：S1第2页；S2第1页。**TLP176AM虽只有四个物理引脚，焊盘编号不是连续1、2、3、4**，必须用1、3、4、6的符号与封装对应，不能套用普通DIP4光耦封装。

## 一路可复制连接

```text
工具3V3 ── R_LED 240Ω ── TLP176AM pin1(A)
                         TLP176AM pin3(K) ── Q pin3(C)
GPIOx ── R_B 680Ω ── Q pin1(B)              Q pin2(E) ── 工具GND
                     │
                  R_BE 10kΩ
                     │
                  工具GND

按键端A ── TLP176AM pin4       TLP176AM pin6 ── 按键端B
```

GPIO高电平为按下、低电平为释放；GPIO高阻时由B-E下拉抑制基极浮空。输出4/6不与工具地相连，也不在五路之间共用某个触点端。控制侧隔离不表示接了UART及电压地线的整台工具具有电气隔离。

MMBT3904的放大区hFE与饱和压降测试条件不同，不能只按hFE典型值计算很小的基极电流。下文以较充足的基极驱动建立工程余量，再对实际电路验证。

## LED限流电阻比较

以下为**明确假设下的工程预算**：VDD低端3.0V、VF预算上限1.4V、NPN导通压降预算上限0.3V、电阻容差±1%。VF/VCE预算须用最终器件、工作电流及温度验证，不冒充厂商额外保证。

`IF低端预算＝(3.0−1.4−0.3)/(R标称×1.01)`。

| R_LED | IF低端预算 | IF粗保守上界 | 判断 |
| --- | ---: | ---: | --- |
| 240Ω | 5.363mA | 15.152mA | 推荐样机初值，低端预算相对5mA有余量 |
| 249Ω | 5.169mA | 14.604mA | 可比较，低端余量比240Ω小 |
| 270Ω | 4.767mA | 13.468mA | 在此预算下低于5mA，不作为首选 |

上界用 `IF≤3.6/(R标称×0.99)`，只假设正常正向通路中VF和VCE不为负；没有借用IF＝10mA、25℃条件的VF最小值去外推其他工作点。这是较宽松的电路上界，不是实际最大工作电流预测。240Ω时，以VDD＝3.3V、VF＝1.27V、VCE＝0.1V为示例，IF约8.04mA；后两个压降只是此算例假设。

240Ω限流电阻最保守耗散上界为 `3.6²/(240×0.99)≈54.55mW`。初始BOM可用额定功率≥0.1W的0603，仍按实际料号和板温降额核验。LED/NPN不能因某个绝对最大额定更大而取消限流。

## 基极电阻与GPIO负载

B-E下拉会分走一部分基极支路电流：

`IB＝(VGPIO−VBE)/RB − VBE/RBE`。

以下比较假设**带载GPIO高电平≥2.4V、VBE≤0.95V**，RB/RBE均1%；这是需要实测闭合的驱动预算。ESP32-S3模组表中的VOH＝0.8×VDD是高阻负载测试，不能据此宣称本基极负载下已保证2.4V；GPIO源电流典型值也不能替代该验证。[S3第27～28页]

| RB / RBE | IB低端预算 | 配合IF粗上界15.152mA时IC/IB | 判断 |
| --- | ---: | ---: | --- |
| 680Ω / 10kΩ | 2.015mA | ≤7.52 | 推荐；与手册饱和测试采用的IC/IB＝10相比有驱动余量，但不是新的饱和压降保证 |
| 1kΩ / 10kΩ | 1.339mA | ≤11.32 | 对实际约8mA可能足够，但在本次宽松电流上界下余量较小 |

680Ω方案每路GPIO输出电流的粗上界为 `3.6/(680×0.99)≈5.35mA`，五路约26.7mA；实际还受B-E压降影响，通常更低。五路LED电流粗上界约75.8mA，连同GPIO驱动，工具电源可按约103mA增量作保守预算；不包含MCU其余耗电。基极电阻耗散粗上界约19.3mW，0603额定≥0.1W有核算空间。

## 初始BOM与实测入口

单路：TLP176AM一颗、MMBT3904LT1G一颗、240Ω/680Ω/10kΩ各一颗，电阻1%、0603且额定≥0.1W；外部触点接两个2.54mm排针触点。五路为上述数量乘五，GPIO依次为4～8。光继电器输出不增加对工具地的电阻或电容。

需要在原理样机完成以下验证后才能固定该BOM：

1. 3.0V、3.3V、3.6V，分别单路和五路按下，测IF、带载GPIO电压、VBE、VCE；尤其验证低端IF达到5mA、驱动余量及连续长按温升。
2. 工具冷上电、重启、下载模式和固件初始化期间测GPIO、基极和实际触点。**10kΩ B-E下拉仅解决GPIO高阻时浮空，不能抵消GPIO被主动驱高**；不以“非绑带引脚”直接证明全过程无误动作。
3. 在实际≤6V/20mA按键负载下验证导通压降、关断漏电、开关延迟、10ms按下/释放与组合按键；高阻上拉及电阻编码按键单独检查加载影响。
4. 对最终明确的工具工作温度与PCB条件验证上述压降预算。1.4V/0.3V/0.95V不是脱离条件的全温保证；发生偏差时按实测和手册修订器件值，而非宣布已有全温结论。
