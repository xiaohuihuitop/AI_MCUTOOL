# 0.4.1发布与验证说明

日期：2026-11-14。桌面、后台、网页、MCP与Skill为0.4.1；工具板沿用已实测的0.1.2，固定每路10Hz。

## 用户反馈与修复

用户反馈滚动时间轴后看不到新曲线。浏览器回归准确复现：样本已增长到121秒，图表右边界仍停在92.93秒。根因是滚轮写入固定`view`后，后续渲染一直复用该范围，未区分缩放跨度与跟随最新采样。

修复后实时缩放只改变跨度，右边界随新采样推进。拖动回看历史时显示“回到实时”，恢复时保留跨度、纵轴与A/B区间；暂停后开始也恢复跟随。两组波形独立。

四路通道参数标签紧邻输入框，颜色选择靠近通道名称。读数与质量并排，统计表采用有限列宽，时长与净电量紧邻排列。移除图表操作、统计、测量及通道长说明，保留必要字段、数据质量和实际错误。

## 安装与AI接入

`scripts/setup-desktop.ps1`支持Windows自带PowerShell5.1和PowerShell7，读取固定发布描述，验证仓库SHA256、随包摘要和实际安装器后静默安装。桌面安装器已包含后台运行环境与WebView2离线安装程序，普通使用不要求Python、Node、Rust或ESP-IDF。

安装脚本复用相同版本，保护运行中的旧版，沿用已有桌面数据目录；生成MCP配置、安装Skill，并用真实stdio `initialize`与`ping`检查版本与27个工具。可使用官方Codex CLI登记mcutool，备份原配置、保留其他服务。只读自检不连接硬件、不申请操作权。

Windows5.1从AI子进程启动时可能继承其他PowerShell版本的模块搜索路径；脚本显式加载当前引擎自带模块。源码为UTF-8无BOM，中文说明采用块注释，避免旧引擎默认ANSI解析使行尾注释吞并下一行。

## 验证与边界

- Vue类型检查与生产构建；浏览器测试包括两图滚轮后实时推进、历史恢复、暂停恢复、紧凑布局、无说明元素、独立导出和3小时以上数据。
- Python后台、下载摘要防替换、安装版MCP只读探测、冻结程序与实际桌面原生保存流程分别验证。
- 固件未在0.4.1再次改变，编译、写后校验和六路32秒实板10Hz证据见[0.4.0验证报告](固定10Hz与长时间波形验证报告.md)。长时容量为测试样本验证，不冒充3小时实板运行或精度验收。
- GitHub发布保持原私有仓库可见性。安装器未配置代码签名；摘要用于检查下载与仓库声明一致。

本轮最终结果与界面截图保存在[发布-0.4.1](软件验证证据/发布-0.4.1/)。

本机已通过自动安装脚本从0.4.0更新为0.4.1，并登记Codex的`mcutool`服务。原有客户端设置和其他MCP行为保持；官方CLI仅把其他服务的空`args=[]`规范化为省略字段。Skill副本和只读MCP版本/27个工具检查通过。安装版已连接原COM40工具板，实际滚轮缩放后右边界从3815.537327秒推进到3816.337326秒，窗口保持打开。

验证结果：18项前端测试、41项Python后台/安装入口/冻结程序测试、11项Windows桌面检查通过。安装检查期间只读观察，未执行供电、充电、按键或串口发送。
