# 五路按键模块成本核价

核验日期：2026-10-17。本轮仅分析五路按键，不扩大到其他模块，也不将候选料直接视为已确定 BOM。

## 本轮结论

**已核实 TLP176AM(TPL,E 的一次公开展示价：1 件档含税 4.9267 元/颗，五颗合计 24.6335 元，约 24.63 元。** 此数不含运费、驱动阻容和接插件；五路模块完整成本仍需补齐这些项目。原先“35 元”是设计预算，不是实时报价。AQY212EH 的规格可作替代比较，但尚无同口径价格，不能证明它更便宜。没有为降低价格改成共地开关或单光耦。

价格结构可以明确：五路总成本为 `5×触点器件单价 + 五路驱动及阻容 + 十个触点接线位`。触点器件每颗便宜 1 元，五路就省 5 元；删减一个廉价电阻不能产生同等规模的节省。应先获得五颗光继电器的实际价格，再决定是否值得换型。

## 已确认的按键电气边界

- 每路触点两端电压差不超过 6V，通过电流不超过 20mA。
- 无极性，每路两个独立接线端，五路彼此不强制共地。
- 10ms 级按下/释放足够；1ms 是命令设定步进，不承诺 1ms 物理动作精度。
- 按键时序本地执行，支持单击、长按、连击及组合按键。

这里的“6V”是每个触点两端的差分电压，不能据此假定触点相对工具地的共模电压，也不把光继电器的实验室隔离额定直接写成整机可用隔离额定。

## 3.3V 驱动和降本方向

五路保持同一结构即可：`3.3V → LED 限流电阻 → 光继电器 LED → NPN 低侧开关 → GND`。每路 NPN 由 GPIO 经基极电阻驱动，基极下拉确保复位期间释放；输出触点与这个控制侧电路隔离。

按 LED 电流约 5～10mA 设计，可兼顾两种已核验候选的推荐区间。电阻不能只按典型 VF 计算：例如以供电低端 3.0V、LED VF=1.5V、NPN 饱和压降=0.2V 作为设计假设，249Ω 对应约 5.2mA；以 3.3V、VF=1.3V、VCE=0.1V 则约 7.6mA。这只是初步计算，供电容差、器件 VF 条件、温度与阻值误差需要设计时再核验。3.3V 并不需要升压才能驱动这些 LED。

实际降本顺序：

1. 先比较两种光继电器在 **5 件、10 件、20 件** 数量下的实际报价，并核对剪带/管装和运费。不能用 1000 件价代表做一台的价格。
2. 优先选普通非特殊认证后缀、常见封装和现货来源，但必须保持 AC/DC 双向浮动触点、足够低的导通电阻、漏电和毫秒动作能力。特殊认证是否需要应由项目决定，不把不同后缀默认等价。
3. 五路 NPN、阻容使用一致型号和标准值，减少采购行及装配差异。小批端子、运费也要独立核价，不能假定一定可忽略。
4. GPIO 直接驱动 LED 可以少五颗 NPN 及相应电阻，但需要重新核验 GPIO 总电流、驱动压降、上电默认状态；在没有实际差价前，不值得直接认定这种改法更划算。本轮不修改驱动架构。

不采用“共地模拟开关”“单只光耦直接跨按键”来换取便宜，它们不能自动保留当前已确认的独立、无极性两端触点能力。

## 用实价检查设计预算

如果仍以五路按键元件合计 35 元作设计目标，需要满足：`5×继电器单价 + 驱动阻容 + 按键端子 ≤35元`。按已核实 1+ 档展示价计算，五颗光继电器占 24.6335 元，尚余约 **10.37 元** 用于驱动阻容及端子。驱动、端子尚未取得报价，因此这里只能说预算有继续核算的空间，不能宣称完整模块一定低于 35 元；运费与采购附加费另行核算。

更换供应商或采购数量时，按原始币种、数量档、税费、剪带及运费口径重算。当前可明确的结论是：五路无需 60V/700mA 的全部能力，但降低额定值是否能便宜，必须有满足参数的型号和同口径报价证明，不能只凭额定数值判断。
