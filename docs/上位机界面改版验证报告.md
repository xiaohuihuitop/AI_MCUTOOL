# 上位机界面改版验证报告

日期：2026-11-13。版本：桌面、共享后台、MCP、网页 0.3.0；工具板固件保持 0.1.1。

## 已完成

已将用户确认的浅色预览接入正式软件真实数据链路，完成供电与测量、四路电压、串口与记录、操作记录及设备设置五个页面。连接成功后收起连接设置，操作权仍按既有规则管理。

电池电压、电流数值位于双轴图内；A/B 游标与区间统计由一个默认关闭的开关控制。统计包含两时刻读数、最大/最小/时间加权平均值、带符号净电量 mAh。关闭开关保留区间，缩放不改变统计范围。

四路电压共用时间轴，各路具有独立比例、偏移和颜色。零偏移时 0 V 居中；通道名称单选并控制 Y 轴刻度，所选实线、其余虚线。曲线显隐按钮不影响读数或名称选择。

数据按设备和启动隔离，重连历史按游标去重。无效点、明确丢样和超过既有 2.5 秒阈值的间隔断开，不跨缺口积分。缓存滚动导致选区过期时明确提示，由用户重选当前历史。MCP 版本改为读取统一版本定义，避免单独版本字符串滞后。
