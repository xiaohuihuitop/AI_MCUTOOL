> 2026-11-03更新：本文保留原器件方案的研究依据。当前原理图已按用户要求改为四颗TLV9001、每路单颗10MΩ上臂及1.5kΩ/100kΩ反馈；当前参数以[降本改版核验](四路电压降本改版核验.md)为准，原OPA4391误差预算不再直接适用。

日期：2026-10-23。范围为ADS1115、四路高阻分压、滤波和顺序采样；缓冲器选型及其供电由独立核验负责。沿用四路共地正电压0～15V、1mV分辨率、误差目标±（读数0.2%＋5mV）、15～35℃且每路零点/增益校准、输入阻抗≥5MΩ、15V实际取电≤3µA/路、约1秒四路一轮、2.54mm排针的已确认要求。

**ADS1115IDGSR可继续作为原理样机ADC，建议固定±2.048V、8SPS、四路单次转换轮询。** 主推荐11:1分压用于给缓冲器输入范围留余量，8:1保留比较；两者均满足1mV量化分辨率的数值条件。联合方案的缓冲不再严格为单位增益，采用约1.00499倍和约1.158mV正偏置的接口预算，详细偏置电路及供电由缓冲器核验负责。器件及配置核验不代表已闭合整机精度。本轮最多核验Vishay TNPW e3、TNPV e3两个电阻系列，没有查询报价或现货。

| 2 | ALERT/RDY | 本轮采用OS轮询，可不连接；不用时官方允许悬空或弱上拉至VDD，不新增报警或自动关断 |
| 3 | GND | 工具公共地；模拟回流避开开关电源与大电流回路 |

| 5 | AIN1 | 外部检测通道2的缓冲后RC输出 |
| 6 | AIN2 | 外部检测通道3的缓冲后RC输出 |
| 7 | AIN3 | 外部检测通道4的缓冲后RC输出 |
| 8 | VDD | 工具3.3V，近端100nF对GND去耦 |
| 9 | SDA | 既有GPIO9，和INA228共用I²C及3.3V上拉 |
| 10 | SCL | 既有GPIO10，和INA228共用I²C及3.3V上拉 |

ADS1115工作电源为2.0～5.5V，模拟输入正常工作范围为**GND～VDD**，绝对额定为GND−0.3V～VDD＋0.3V；持续引脚电流绝对额定±10mA。±2.048V是差分量化标度，不是允许输入负压的依据，也不允许把15V直接接到AIN。[S1第4、13、15页]

芯片内部有输入至电源轨的ESD二极管。工具掉电时VDD可能接近0V，外部被测电压经分压、缓冲或保护器件仍可能向ADC及工具电源注入电流。高阻分压限制电流不等于已解决掉电反灌，±10mA绝对额定也不是可长期采用的工作点。任意一路输入过驱还可能影响其他通道。[S1第13、29页] 最终缓冲器、保护和电源先后顺序必须共同核验；本报告不擅自增加掉电自动断开、负轨或钳位方案。

## 8:1与11:1分压比较

每路结构为`输入排针 → 上臂 → 分压节点 → 独立缓冲 → ADC侧RC → AINx`，下臂由分压节点接公共地。各通道均有独立前端，ADC内部MUX轮流选通。

| 项目 | 8:1候选 | 11:1候选 |
| --- | ---: | ---: |
| 上臂/下臂标称值 | 7MΩ / 1MΩ | 10MΩ / 1MΩ |
| 本轮可编码的组合 | 上臂7颗1MΩ，下臂1颗1MΩ | 上臂5颗2MΩ，下臂1颗1MΩ |
| 单路/四路电阻数量 | 8 / 32颗 | 6 / 24颗 |
| 标称输入阻抗 | 8MΩ | 11MΩ |
| 15V时每路取电 | 1.875µA | 1.364µA |
| 15V时分压节点电压 | 1.875V | 1.364V |
| 距ADC正满量程2.048V的标称余量 | 173mV | 684mV |
| 分压节点戴维南等效电阻 | 875kΩ | 909.1kΩ |
| ±2.048V档ADC步长 | 62.5µV | 62.5µV |
| 折算原输入步长，暂按单位增益比较 | 0.5mV/LSB | 0.6875mV/LSB |
| 节点额外1nA漏电的输入等效误差 | 7mV | 10mV |
| 各电阻均为0.1%时，比例误差一阶上界 | 约±0.175% | 约±0.182% |
| 各电阻独立±25ppm/℃时，比值温漂一阶上界 | 43.75ppm/℃ | 45.45ppm/℃ |

表中为标称计算或有明确假设的一阶预算，不含保护、缓冲器及PCB漏电。所有电阻同向取−0.1%时，单看分压电流分别约1.877µA和1.365µA，仍低于3µA；但实际输入阻抗/取电必须包含全部接入路径，不能据分压值直接宣称整机达标。

联合方案采用11:1、缓冲增益约1.00499及约1.158mV正偏置时，名义关系为`VADC≈1.00499×V输入/11＋1.158mV`。对应原输入量化步长为`11/1.00499×62.5µV≈0.6841mV`；15V输入时ADC端约1.3716V，仍低于2.048V。ADC端的正偏置用于给近零输出留余量，不能在软件中继续按无偏置、单位增益关系直接乘11；最终使用每路校准系数，偏置漂移及最坏输入范围随缓冲器共同验证。

11:1在15V时的1.364V给单电源缓冲器留下更多共模余量，同时保持原始步长小于1mV。代价是相同节点漏电产生更大的输入等效误差，且2MΩ需使用已核准的1206尺寸。因此不能仅以电阻颗数判断面积或成本，也不能只看ADC满量程来决定比例。

通用漏电关系为`ΔV输入＝R上×I节点`。如果暂给节点附加漏电分配1mV误差，8:1约允许143pA，11:1约允许100pA；这只是误差预算示例，不新增验收目标。输入端总取电低于3µA，并不意味着分压节点允许出现µA级漏电。

**不能把这些1MΩ料号写成0603。** TNPW e3当前官方表中0603最高332kΩ；0805最高1MΩ、1206最高2MΩ，并且所列0.1%/25ppm档支持本表阻值。TNPW0805/1206最大工作电压分别150V/200V，TNPV对应450V/700V；本工具每颗只承担数伏，无需按其高压额定扩展工具输入范围。[S2第1、3页；S3第1～2页]

TNPW官方本轮资料未给出可直接用于预算的ppm/V电压系数上限，不能把薄膜、非线性曲线或低噪声措辞当作零电压系数保证。TNPV明确列出`|c|<1ppm/V`，但其高压定位和此项指标不能证明它更便宜或更有库存。最终采购可按报价决定是否为该明确指标付出成本，不把两个系列设计成运行时备用路径。

两颗分压电阻的结构能减少焊点和面积，但本轮两个系列没有核准单颗7MΩ或10MΩ的0.1%/≤25ppm型号，也没有核准3MΩ＋4MΩ组合，故不生成这些阻值的完整料号。8:1可用2MΩ×3＋1MΩ作上臂、1MΩ作下臂，共5颗/路，代价为三颗1206；7颗1MΩ方案则统一阻值、尺寸与单颗电压应力。本文保留这些结构比较，不宣称串联多颗后容差或TCR自动改善。

在温度相同的假设下，串联上臂TCR是各电阻按阻值加权的平均，最坏值仍可到±25ppm/℃；下臂可能取相反符号。比例温漂近似为`(1−1/K)×(TCR上−TCR下)`，因此8:1与11:1的一阶上界分别为43.75、45.45ppm/℃。若25℃校准、环境到15℃或35℃，单看这项在15V处约6.56mV、6.82mV。不能假设同系列、同批或相邻摆放就获得未列明的匹配保证；温度梯度、老化和电压系数仍需实测。

## 单次轮询配置与首个有效结果

| Config字段 | 样机初值 | 含义 |
| --- | --- | --- |
| OS，bit15 | 写1启动；读0转换中，读1空闲/完成 | 以成功触发的本次转换为对象等待完成，不把上电空闲状态当作新样本 |
| MUX，bits14:12 | 100、101、110、111依次 | AIN0/1/2/3分别对内部GND测量 |
| PGA，bits11:9 | 010 | 固定±2.048V，不自动换档 |
| MODE，bit8 | 1 | 单次转换，完成后回到内部power-down状态 |
| DR，bits7:5 | **000：8SPS** | 主推荐；001为16SPS比较配置 |
| COMP_QUE，bits1:0 | 11 | 禁用比较器，ALERT/RDY为高阻 |
| COMP_MODE/POL/LAT | 保留默认0 | 比较器禁用，本轮不引入阈值行为 |

配置寄存器指针为0x01，转换结果为0x00；结果MSB先读、16位二进制补码。单端输入使用正码范围，0V附近仍可能因偏移读到负码，不能把有符号数误解为很大的正电压，亦不在本报告新增强制归零逻辑。[S1第23～26、32页]

顺序为：上一通道完成并读取 → 写下一通道MUX、PGA、MODE、DR并以OS=1启动 → 等待本次转换完成 → 读对应转换结果。转换进行中再写OS=1不会重新启动；连续模式中改配置则要等旧转换完成后才使用新配置，所以本轮以单次模式明确结果归属。[S1第18页]

ADS1115具有单周期数字滤波建立。**当前通道模拟前端已稳定时，切MUX后启动的首个完整单次转换即可使用，不要求再做一次空转换或自动丢首样。** 这不意味着输入刚发生阶跃时，分压电容、缓冲器及外部RC也已稳定。初次上电转换寄存器为0，只能在第一次有效转换完成后解释为测量结果。[S1第15、18、24页]

| 数据率 | 单通道名义转换时间 | 四路名义转换时间合计 | 按数据率−10%计算的四路转换时间 |
| --- | ---: | ---: | ---: |
| **8SPS** | 125ms | 500ms | 约555.6ms |
| 16SPS | 62.5ms | 250ms | 约277.8ms |

另有每次约25µs的内部唤醒时间、I²C事务和任务调度延迟；约25µs是手册近似值，不是最大保证。以上允许安排约每秒一轮四路扫描，但四路不同时采样，各自读数对应不同时间窗口。8SPS优先的理由是有足够扫描时间，且官方主要误差表、INL条件与此匹配；16SPS只作为比较，不设计自动提速、自动降速或自动重采。[S1第5、15、18页]

## 输入采样加载与滤波初值

ADS1115输入是250kHz开关电容采样；±2.048V档共模输入阻抗约6MΩ、差模约4.9MΩ，均为典型值且随时钟和条件变化。875kΩ或909kΩ的分压源阻抗不能无损直接驱动它，也不能用一个典型阻抗常数校正全部动态加载，因此每路仍保留独立缓冲。[S1第5、14页]

建议将两处RC的作用区分：

| 位置及样机初值 | 计算与用途 | 尚待核验 |
| --- | --- | --- |
| 分压节点对公共地10nF | 8:1时τ≈8.75ms、fc≈18.2Hz；11:1时τ≈9.09ms、fc≈17.5Hz，作为低频前置滤波候选 | 电容绝缘电阻/漏电必须进入节点误差预算，另核介质吸收、DUT源阻抗及寄生；优先核验C0G/NP0，但具体型号尚未确定 |
| 缓冲输出串100Ω，ADC侧10nF对地，每路独立 | τ≈1µs、fc≈159kHz；隔离ADC采样回冲及电容负载、储存瞬态电荷 | 运放闭环稳定性、隔离电阻后建立、ADC动态加载和实际串扰；不能把10nF直接挂在运放输出视作已保证稳定 |

TI给出的抗混叠起点是RC截止频率约为输出数据率到其10倍；因此18Hz左右的节点RC适合作为8/16SPS的候选，而159kHz的缓冲后RC不能单独称为已经满足低频抗混叠。100Ω/10nF为工程初值，并非厂商对本电路的定版推荐。不能只按耐压就在高阻节点接入通用TVS或钳位二极管；其实际反偏及温度下漏电必须满足节点预算，本报告不擅自选定此类保护器件。[S1第30页；电路计算]

按单极点、低阻理想DUT源估算，15V满阶跃衰减到原输入等效0.5mV需约10.31τ，8:1约90ms、11:1约94ms。该时间不是每次切MUX必须另加的固定延时，因为四路分压及缓冲持续连接；只有相应外部输入变化等条件才有新的模拟建立过程，实际建立与转换窗口需一起验证。这里不增加自动延时策略或丢样策略。

100Ω串阻也会产生加载误差。只用典型差模4.9MΩ作简化比例估计，约20.4ppm、15V输入处约0.306mV；这仅是差模部分，真实输入还有共模充放电，不能把该算例当作全条件最大误差。滤波、缓冲器输出阻抗及器件偏差都应包含在每路校准与温度验证中。

官方电气表默认VDD3.3V、8SPS、±2.048V；除另有说明，最大/最小值适用于−40～125℃，典型值为25℃。已目视核对列位置，以下不把典型项当作最大保证。表内K8/K11折算沿用单位缓冲增益以便比较；联合方案需再除以1.00499，并另计偏置链误差。[S1第5～6页]

| ADC项目 | 官方数据 | 对原输入端的含义 |
| --- | --- | --- |
| INL | 最大1LSB，8SPS/±2.048V，best-fit且覆盖99%满量程 | K8为0.5mV，K11为0.6875mV；不能直接扩展成贴零端点全链路线性保证 |
| 单端失调 | ±3LSB，**仅典型** | K8约±1.5mV，K11约±2.06mV；差分最大±3LSB不能替代单端最大值 |

ADS1115增益与增益漂移表已包含内部参考及PGA误差，不能再把同一参考误差重复相加。未经校准时，电阻比例误差和ADC0.15%增益误差相加已可超过15V处35mV目标，因此每路校准确有必要；校准后仍需考虑温漂、漏电、非线性、近零行为和参考仪表不确定度。[S1第6、11、15页]

优先实测0V及近零小电压、各路0～15V扫点、15/25/35℃、四路一高一低交替输入时的串扰、持续Wi-Fi收发、工具与被测设备不同上电顺序。对每个结果记录所属通道和实际完成时间；本轮仅记录验证入口，不编写固件或改变测量API。

## ADS1119内置缓冲替代方案的限量核验

按本轮补充研究范围，仅检查了ADS1119一种带内部缓冲ADC，**不推荐据此取消外部缓冲**。该器件确有四路单端，输入缓冲推荐范围AGND−0.1V～AVDD＋0.1V；内部2.048V参考、增益1时LSB为62.5µV，数值量程可以配合8:1或11:1分压。[S4第1、4、17页]

但其输入绝对/差分电流±5nA为**典型值，没有最大保证**，且有VIN=0V、VCM=AVDD/2等各自条件；第17页明确提醒高阻源仍可能需要外部缓冲。10MΩ上臂下，5nA已对应输入等效50mV，超过15V处35mV误差目标。零点校准不能证明其共模和温度变化后的残差满足要求。因此停止进一步选型，不把“内置缓冲”视为可直接驱动本项目高阻分压的充分条件，也未扩展搜索其他ADC。[S4第5、17页]
