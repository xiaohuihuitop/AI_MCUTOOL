# 三点三伏UART接口器件核验

> 2026-11-03更新：用户确认取消TX缓冲U16及其R76/R77/C26，GPIO14经100Ω直接发送，GPIO38释放；禁TX改为GPIO14输入、无上下拉，硬件掉电隔离减弱。RX保留。当前以[串口发送直连改版核验](串口发送直连改版核验.md)为准；下文发送缓冲和独立使能条目属于历史方案。

日期：2026-10-23。范围仅为目标设备3.3V UART接口原理样机，不涉及工具下载串口。沿用GPIO14发送、GPIO15接收、GPIO38发送使能；外接仅2.54mm三针TX/RX/GND，工具独立供电。支持9600～921600常用波特率、默认115200/8N1、全双工原始字节透传、无RTS/CTS。启动/复位后发送默认高阻，由AI显式启用；禁发送仍可接收，关闭DUT前由AI禁发送，不关联工具供电通路、不增加自动上电检测或自动恢复。

**主推荐：TI SN74AUP1G125DBVR用于TX三态控制，Nexperia 74LVC1G17GV,125用于RX施密特整形。** TX使能10kΩ上拉、工具侧TX输入100kΩ上拉；外部RX在接收器输入侧470kΩ下拉，两个外部信号各串100Ω，每颗芯片近端100nF去耦。外部TX引脚不接工具3.3V上拉。当前为可画图的样机初值，尚无线缆、反灌、复位或921600波特率实测结果。

## 选型依据

两芯片方案分别解决TX独立高阻与RX慢边沿。单芯片SN74LVC2G125的普通CMOS输入在3.3V±0.3V时要求≤10ns/V，下拉不能解决拔线或DUT慢掉电时的边沿问题；低漏电SN74AUP1G17的阈值表又不足以直接证明整个3.0～3.6V电源预算下的TTL兼容。本轮因此选择有明确TTL兼容及慢边沿声明的Nexperia接收器，不保留运行时备用方案。[S3第6、10页；S4第5～7页]

## 接收电平兼容与470kΩ下拉

Nexperia官方明确写出“Direct interface with TTL levels”“Unlimited rise and fall times”，并声明符合**JESD8C（2.7～3.6V）**。本轮以该厂商声明作为3.0～3.6V工具电源预算下的TTL接口兼容依据；工程检查使用DUT发送高电平≥2.4V、低电平≤0.4V，对照TTL输入2.0V/0.8V门槛，不把“3.3V供电”本身当作任意GPIO带载电平的保证。[S2第1页]

官方表8仍按离散VCC给出施密特阈值：VCC=3.0V时VT+最大1.71V、VT−最小0.88V；4.5V时VT+最大2.36V。**这些数值不是3.0～3.6V全区间的阈值表。** 本报告不靠插值生成新的保证值；样机应在3.0V、实际稳压点及3.6V分别用2.4V高、0.4V低输入核验，并检查噪声和地电位差余量。[S2第6页]

Nexperia II最大±1µA适用−40～125℃，表列测试条件为VI=5.5V或GND、VCC=0～5.5V。用其最大值对下拉作工程预算：[S2第5～6页]

| 下拉情况 | 计算及含义 |
| --- | --- |
| 470kΩ/1%，仅1µA输入漏电预算 | 最大电阻474.7kΩ，节点最高约0.4747V，低于TTL低门槛0.8V |
| 再分配0.5µA板级附加漏电 | 1.5µA×474.7kΩ≈0.7121V，仍低于0.8V；这是工程分配，不是已经证明的保护/PCB漏电上限 |
| DUT TX=3.3V时 | 标称下拉取电约7.02µA，电阻取−1%时约7.09µA，接收器输入漏电另计 |
| 对照100kΩ | 3.3V时约33µA；静态偏置余量更大，但真实加载明显增加 |

1MΩ下拉在1µA最大漏电预算下已可能超过0.8V，不作为本轮初值。不能用典型漏电替代最大值以证明它可靠。

470kΩ是接收端的真实负载，可能经DUT电池及电流分流器取电，不能自动从电流测量值扣除常数。100Ω输入串阻在约7µA下的压降不到1mV量级，仍须连同DUT输出阻抗及输入漏电检查有效电平。施密特输入允许慢边沿，不意味着中间电平下功耗与轨到轨稳定电平相同，也不意味着能把真实电源抖动自动识别为有效UART帧。

**RX未接、DUT输出高阻或掉电时，下拉最终使RX为低。** 这是无有效信号状态，UART硬件可能产生持续break或帧错误，不能把它称为“空闲高”，也不能静默丢弃这些信息假装串口正常。break、错误和字节缓存的接口语义留给后续固件设计，本轮不增加自动过滤或自动恢复。

## 发送默认状态与使能

SN74AUP1G125在/OE高时输出高阻，低时Y跟随A。官方要求为了在上/掉电过程中保持高阻，/OE应通过电阻上拉到其VCC；本方案10kΩ采用该接法。GPIO38在高阻或主动高时禁用，AI显式启用对应GPIO38拉低。[S1第15～16页]

100kΩ只上拉**GPIO14至缓冲器A的工具内部节点**。外部TX排针没有工具电源上拉，因此禁用后不主动维持DUT RX高电平；该线路电位由DUT接收端及实际漏电决定。若在DUT断电前仍保持发送启用，工具TX高电平仍可通过DUT输入保护形成寄生供电；芯片Ioff无法解决“工具有电、输出主动驱动、DUT没电”的情形。

AUP输入II最大0.5µA时，100kΩ/1%静态上拉的最大压降预算约50.5mV，10kΩ/1%的/OE上拉约5.05mV，不含ESP32引脚或板级附加漏电。按3.0V最低供电，静态高电平有余量；这不代表任何缓慢输入变化均合格。

AUP1G125是普通CMOS输入，允许转换时间为**200ns/V**。100kΩ用于静态偏置，不能靠它保证带GPIO、布线电容的TX输入边沿速度。使能前应已由UART外设主动驱动GPIO14并处于稳定高电平；正常字节由推挽驱动产生边沿。/OE同样不能随意加大电容，复位后的释放边沿须按真实电容核验。手册列有/OE=VCC时的input-disable功能电流条件，但不应据此取消输入偏置或边沿验证。[S1第5～7页]

上拉不能覆盖GPIO主动拉低，也不能替代对GPIO保持状态的检查。冷启动、EN复位、软件重启、看门狗及工具电源跌落均需实测外部TX是否保持高阻。此处没有增加与DUT供电选择绑定的自动使能策略。

| Nexperia RX IOFF | 最大±2µA，−40～125℃；VCC=0V、VI或VO=5.5V | 对照工具关机、DUT有电的路径；此处为官方测试条件，不宣称整机总漏电一定≤2µA |

AUP工作电源上限为3.6V，外部TX正常信号也保持既定3.3V接口。Nexperia单颗输入虽容许更高电压，**整条UART没有因此变为5V兼容接口**。[S1第4～7页；S2第4～6页]

工具有电而DUT断电时，由AI先禁用发送；工具掉电而DUT有电时，接收端470kΩ仍对DUT形成负载，芯片掉电漏电还需核验。两侧接地先后、残余电源、缓冲器及GPIO路径均可能影响结果；本报告不增加TVS、钳位、自动检测或运行时补偿。

## 921600波特率、串阻与负载

921600波特率的位时间约1.085µs。AUP1G125在VCC=3.3V±0.3V、CL=30pF、−40～85℃下，传播延迟最大7ns，启用最大8.3ns、禁用最大10.8ns。Nexperia RX在VCC=3.0～3.6V、CL=50pF、手册对应负载下传播延迟最大5.5ns（−40～85℃）或7ns（−40～125℃）。这些指标说明器件速度不是当前的首要瓶颈，不能替代长线、接地、实际负载或UART时钟误差验证。[S1第11、13～14页；S2第8～9页]

两路串阻均以100Ω/1%为样机初值，可根据波形在33～100Ω范围内定型，不设计运行时自动调整。其作用是减轻边沿振铃及瞬态电流，不承担电平转换，也不能作为短接或误接电源的完整保护。

仅考虑串阻与100pF负载，100Ω贡献约22ns的10%～90%上升时间，33Ω约7.3ns；这是`2.2RC`算例，未计芯片输出电阻、线缆分布参数和探头，不能直接当实际边沿保证。

TX静态负载若不超过20µA，AUP在相应测试条件下VOH≥VCC−0.1V、VOL≤0.1V，100Ω附加压降≤2mV；按3.0V供电估算，接口约≥2.898V高、≤0.102V低。该算例不能覆盖任意DUT内部上拉/下拉：例如手册4mA条件的VOL上限可达0.45V，且串阻另有压降，因此最终必须按实际接收负载核算，不能只宣称“驱动4mA所以所有TTL负载均满足”。[S1第7页]

RX输出仅驱动工具GPIO15，GPIO15保持输入模式；不通过其上拉向外部DUT节点供电。两颗器件均由工具电源承担自身工作电流。
