# 固定10Hz与长时间波形验证报告

日期：2026-11-14。桌面、共享后台、MCP和网页0.4.0；工具板固件0.1.2。

## 改动与使用

- 六路固定每100ms采集一轮。INA226保持每通道2116µs，平均从128次改为16次，内部名义更新周期67.712ms；保留125µA电流、1.25mV电池电压名义步进。ADS1115固定128SPS、四路单次转换轮询，每路对外10Hz；四路不是同时采样。
- 板上测量缓存8192条，约136秒；电脑端原始文件记录没有固定时长上限。网页每组用紧凑环形存储保留最近4小时，长期显示不会无限增长。
- 电池独立一组开始/暂停、清空、导出；四路电压共用另一组。暂停冻结该图，恢复包含暂停期间的历史；清空重建该图时间起点和游标，数值、后台采集和文件记录继续。
- CSV导出对应组全部保留原始采样，含隐藏通道；电流单位A，含设备/启动、时间、质量和缺口。桌面使用原生保存对话框，写入完整后替换目标文件。
- 长时间绘图每像素保留首尾及极值；统计和导出仍使用完整原始采样。10Hz数据间隔超过0.25秒或出现无效值/明确丢样时断开，禁止跨缺口积分。
- 显示历史属于本页面，刷新后重新建立。跨页面会话或超过4小时保存仍需提前开启持续记录。
