## 两种功率MOS的底部焊盘不同

| 器件 | D | G | S | 底部大焊盘9 |
| --- | --- | --- | --- | --- |
| CSD17577Q3A，主通路N-MOS | 5、6、7、8、9 | 4 | 1、2、3 | **Drain**，输入MOS接本路输入正端，输出MOS接VSEL_P |
| CSD25402Q3A，充电P-MOS | 1、2、3 | 4 | 5、6、7、8、9 | **Source**，两颗均接SCOM_CHG |

2026-10-23补充复核：此前本表继承了旧资料错误的1～8脚关联，现已直接依据TI可见顶视图更正，两款Gate均为4脚；参见 [原图证据与更正范围](MOS引脚图复核与连接更正.md)。

两者虽然都称Q3A/SON 3.3mm×3.3mm，电气映射不可互换。N-MOS主通路中大焊盘不属于共源铜；P-MOS充电通路中大焊盘属于共源。两路主供电的SCOM_BAT/GCOM_BAT和SCOM_EXT/GCOM_EXT分别独立；VOM1271的4脚接本路GCOM、3脚接本路SCOM，3脚不接公共地。[P3；P4]

## WSK2512四端分流器

Vishay官方示意使用I1/E1/I2/E2名称，没有提供数字焊盘号。I1与E1属于同一端，I2与E2属于另一端；两块较小的采样触片呈对角分布，不能假设“上排是采样、下排是载流”。[P5]

| 官方端子 | 网络角色 |
| --- | --- |
| I1 | 载流输入，VSEL_P |
| E1 | 正端独立Kelvin采样，经10Ω到INA228 IN+ |
| I2 | 载流输出，DUT_PWR_P |
| E2 | 负端独立Kelvin采样，经10Ω到INA228 IN− |

工程数据可先保留I1/E1/I2/E2四个明确端子；若EDA器件库要求数字编号，必须同时记录“本项目数字编号→厂商端子名→具体几何焊盘”的一一映射，并以机械图复核。该数字是工程约定，不能写成厂商官方编号。禁止用普通两端2512封装代替，也不能在分流器之外先将E1/I1或E2/I2短接而丢失Kelvin采样。[P5]

## OPA4391与LM7705的电源网络

| 器件/脚 | 应连接网络 | 容易误接之处 |
| --- | --- | --- |
| OPA4391 pin4，V+ | TOOL_3V3 | 正电源 |
| OPA4391 pin11，V− | VNEG | **不接COMMON_GND** |
| OPA4391 A：+、−、OUT | 3、2、1 | 正输入接DIV1，负输入接反馈节点 |
| OPA4391 B：+、−、OUT | 5、6、7 | 正输入接DIV2，负输入接反馈节点 |
| OPA4391 C：+、−、OUT | 10、9、8 | 正输入接DIV3，负输入接反馈节点 |
| OPA4391 D：+、−、OUT | 12、13、14 | 正输入接DIV4，负输入接反馈节点 |
| LM7705 pin4，VDD | TOOL_3V3 | 就近输入去耦 |
| LM7705 pin2/5，VSS | COMMON_GND | 两脚都接地 |
| LM7705 pin3，SD | COMMON_GND | 低电平开启，现有方案常开 |
| LM7705 pin1/8，CF+/CF− | 分别接飞跨电容两端 | 两端均不直接接地 |
| LM7705 pin7，CRES | 独立储能电容到COMMON_GND | **不能直接短到pin6** |
| LM7705 pin6，VOUT | VNEG，输出电容到COMMON_GND | 给OPA4391负电源及四路100kΩ反馈下端供电 |

499Ω反馈从运放输出、即100Ω隔离电阻之前取样。ADS1115 GND仍接公共地，不能把其GND改到VNEG。内部负轨用于处理运放输出接近0V的裕量，外部四路仍按共地0～15V设计。[P2；P6]
