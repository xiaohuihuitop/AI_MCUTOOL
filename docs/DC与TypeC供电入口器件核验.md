# DC与Type-C供电入口器件核验

**历史方案，已被替代。** 用户随后确认工具DC和Type-C均只接5V，并采用LDO。当前入口方案见 [五伏双入口隔离器件核验](五伏双入口隔离器件核验.md)；下文12V与1N4007仅保留研究经过，不作为当前输入额定或BOM。

核验日期：2026-10-23。范围仅为工具自身DC和Type-C入口，后级3.3V稳压器另行核验；设备独立5V充电输入不与工具电源正极混接。用户每次人工只接一路，不设计双电源优先级、无缝切换或新增自动电源策略。

**本轮原理样机推荐两颗Vishay 1N4007普通整流二极管，各入口配4.7kΩ泄放电阻。** 普通二极管的漏电和闲置电位容易控制，但约0.85A输入算例损耗接近0.93W，5V低端稳压及热余量仍须与后级联合核验。该方案用于低成本原理样机，具体器件可按核价及验证结果调整，尚非最终投板依据；不加入自动电源策略。

## 入口连接

| 网络/器件 | 初稿连接 |
| --- | --- |
| DC插座 | 5.5×2.1mm，中心正端接DC_IN_P、外套接工具GND；名义5V或12V。若插座带第三个插入检测/切换脚，不用于电源优先级，按具体器件定义留空 |
| DC隔离二极管D_DC | 阳极接DC_IN_P，阴极接TOOL_VIN |
| Type-C VBUS | 接口A4/A9/B4/B9全部接TYPEC_IN_P，具体连接器引脚以最终封装资料复核 |
| Type-C地 | A1/A12/B1/B12接工具公共GND；金属外壳焊盘的接地和机械处理随布局确定 |
| Type-C隔离二极管D_C | 阳极接TYPEC_IN_P，阴极接TOOL_VIN |
| CC1/CC2 | A5和B5各自经一颗5.1kΩ/1%接GND，不能把两根CC短接后共用一颗电阻 |
| 未用Type-C信号 | USB数据及SBU信号不接业务电路；本口仅受电，无PD及USB业务通信 |
| 输入泄放R_DC/R_C | 各4.7kΩ/1%、额定≥0.1W作为初值，分别从DC_IN_P、TYPEC_IN_P接GND，位于隔离二极管之前 |
| 后级输入 | 两颗二极管阴极汇合为TOOL_VIN，接降压器及其输入去耦；输入电容按下文总量核算 |

二极管色带为阴极标记。二极管限制各入口正极的反向电流，但不能把它描述为整机所有接线情况下的全面反接保护。实际器件型号、布局和瞬态仍须验证。

输入泄放仅用于控制**闲置工具电源口**的泄漏电位，不是被测设备供电输出的主动放电电路，不增加任何控制命令，也不改变已确认的DUT不主动放电约定。

## 普通二极管的官方证据与计算

Vishay 1N4001～1N4007手册为Document88503、2020-04-29；本轮选1N4007基础型号，采用DO-41轴向封装。官方以1N4004-E3/54和1N4004-E3/73列出包装订购例；1N4007的实际可购包装后缀及库存须采购复核，不把不同系列的小封装器件作为同型号替换。[S1第1～2页]

| 参数 | 官方值及条件 |
| --- | --- |
| 1N4007反向额定 | VRRM/VDC为1000V，远高于本工具名义12V输入；这不扩大工具入口额定值 |
| 平均整流电流 | 1A，TA=75℃、引线长度9.5mm等指定条件 |
| 最大正向压降 | 1.1V@1A，表默认TA=25℃；不能当任意温度/浪涌下的最大值 |
| 最大反向直流电流 | 在额定反向电压下，25℃为5µA、125℃为50µA |
| 典型热阻 | RθJA=50℃/W、RθJL=25℃/W，指定引线和PCB安装条件；非任意布局保证 |
| 标识 | 色带为阴极，未使用未经核验的数字焊盘编号 |

以3.3V/0.75A、降压效率80%作为规划算例，后级输入所需功率约3.094W。假设隔离二极管压降按1.1V预算：

| 入口电压算例 | 后级可得电压，尚未计线缆/接点压降 | 后级平均输入电流估算 | 二极管耗散估算 |
| --- | ---: | ---: | ---: |
| 5.00V | 3.90V | 约0.793A | 约0.873W |
| 4.75V | 3.65V | 约0.848A | 约0.932W |
| 12.00V | 10.90V | 约0.284A | 约0.312W |

4.75V是低端计算示例，不是新确认的适配器额定范围。该计算尚未计入口泄放、降压器静态电流和实际效率变化；更低输入时电流还会增大。因此不能继续沿用未计二极管时的“5V输入约0.62A”作为完整入口预算。

0.93W乘典型50℃/W约为47℃结温升，说明需要实际散热面积、安装方式及环境温度核验；不是样机温升结论。5V低端后级约3.65V时，是否能保持3.3V/0.75A输出，要由降压器导通电阻、最大占空比、压差和启动条件共同决定，仅满足芯片最低工作电压不够。

本轮配合另项研究的TPS62130ARGTR低输入电压降压器作为低成本原理样机。若后级或温升验证不满足，应在定版前重新选择已经核验的低压降隔离器件，不以自动降负载或自动降低3.3V输出作为处理方式。

## 闲置端漏电与泄放

DC供电时，D_C承受反偏；若TYPEC_IN_P完全悬空，微小反向漏电也可能给接口寄生电容充电，不能仅凭二极管存在就声称闲置VBUS一直为0V。反向给闲置DC口供电时同理。

R_C/R_DC为漏电提供静态回路，近似关系为`V闲置≈I反漏×R泄放`。按官方额定反压下的漏电值作保守预算，并假设本项目较低反压下不超过该值：

- 25℃、5µA、4.7kΩ：约23.5mV。
- 125℃、50µA、4.7kΩ：约235mV；加电阻+1%为约237mV。
- 接口还有PCB漏电或其他注入时须一并计入，实际12V反偏、温度及热插拔电位必须实测，不把此预算当作零电压保证。

泄放在正常供电入口也持续耗电：5V时约1.064mA/5.32mW，12V时约2.553mA/30.6mW。以1%负容差估算12V功耗约30.95mW，≥0.1W电阻可作为初值；实际适配器上限、板温和电阻降额仍须核验。4.7kΩ不是基于某个被测设备负载设定的通路。

## Type-C连接识别与电流能力

已从USB-IF官方文档页取得 **USB Type-C Cable and Connector Specification Release2.5，2026-03**。[S2]

第245页表4-28明确规定Sink的Rd：5.1kΩ；±20%电阻实现用于连接识别，表中标注不能检测功率能力；±10%电阻实现才具备检测功率能力所需的精度条件。本板用1%电阻，但**两颗电阻本身仍不完成源端电流声明识别**，不能说接上Rd就获得2A授权。

无PD仍可在5V工作；Type-C源端通过CC上的Rp声明默认USB电流、1.5A或3A能力。标称“5V/2A适配器”与CC电流声明不是同一概念，不能将本方案说成能从任意电脑USB端口取得所需电流。继续沿用用户人工选择足够5V输出能力的适配器和线材这一约定，本轮不增加PD控制器、BC协议识别、自动限流降级或CC能力识别固件。

## VBUS输入电容与插入瞬态

Release2.5第153页表4-3规定Sink在**不处于Attached.SNK**时，VBUS到GND的电容最大10µF。[S2] 这是电容边界的官方依据，不能把别处针对Source、DRP或线缆VCONN的电容数值混用。

本方案没有受控输入开关，隔离二极管后的降压器输入电容在插入时仍能通过二极管充电，因此应与Type-C口前端电容、器件寄生等一起评估端口看到的等效电容和浪涌。不能因为电容位于二极管后就将其排除。

本轮与后级联合的样机初值为 **CIN=4.7µF/35V/X7R＋AVIN旁路100nF**，不再增加其他入口大电容。若两者均按±20%容差预算，标称电容正偏差上界合计约5.76µF，连接器和器件寄生另计；仍须核对实际型号及端口测量。降压器手册中的10µF为参考推荐，不能误写为已明确的最小输入电容要求。

后级暂以4.7µF器件的有效电容≥2.2µF作为待验证预算；在0.75A、2.5MHz连续导通算例下，理想输入纹波最坏量级约34mV，输入线缆、ESR/ESL、启动及轻载脉冲模式另外验证。有效电容须由具体器件的偏压曲线和样机确认，不能把4.7µF标称当作有效值。该调整没有增加浪涌控制模块，也不构成USB规范或任意线缆兼容性已通过的结论。

样机需覆盖5V/12V单入口启动、输入线压降、工具Wi-Fi负载阶跃、拔插、闲置端电位及二极管结温；仅用稳态万用表读数不能证明插入尖峰和回灌已通过。
