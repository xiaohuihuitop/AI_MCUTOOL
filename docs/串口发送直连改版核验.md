# 串口发送直连改版核验

日期：2026-11-03。用户确认取消发送缓冲以降低成本，仅修改嘉立创专业版本地工程原理图，PCB仍留到最后统一同步。

## 当前连接

- 第8页移除U16（SN74AUP1G125DBVR）、使能上拉R76（10kΩ）、发送输入上拉R77（100kΩ）和U16去耦C26（100nF）。
- GPIO14／DUT_UART_TX直接通过原R79（100Ω）接TOOL_TX，再到J18的1脚；发送线没有接工具3.3V的外部上拉。
- U17（74LVC1G17GV,125）、R78/R80、C27及J18保持原型号、属性与位置，接收通路保持原样。
- 第2页移除原UART_TX_NOE引线，GPIO38（模组31脚）释放为预留，并按既有格式加未连接标记；U4其他引脚连接不变。
- 第2、8页解析同步更新，保持接口为3.3V逻辑、TX/RX/GND三针，无供电针。

## 后续固件要求与能力取舍

发送启用仍由AI显式控制。禁用时需要解除UART外设对GPIO14的输出驱动，将该引脚配置为输入，并关闭内部上下拉；保留RX工作。具体UART外设和GPIO操作顺序及正在发送帧的处理留给固件实现，不能仅以停止写入字节代替释放发送脚。

被测设备掉电前，AI先禁用发送。工具启动和重启的固件初始化也应建立该状态；从实际上电到初始化之前，以及复位、看门狗或保持状态下的引脚表现须样机核验。GPIO38不再参与发送使能。

直接连接后不再具有独立发送缓冲的硬件禁用及其Ioff边界。100Ω用于边沿调试和缓和瞬态，不构成掉电隔离或完整短路保护；工具掉电时无法靠固件配置来处理反向驱动。用户已在上述取舍下授权修改，不增加新的隔离器件、自动供电检测或自动恢复策略。

原9600～921600常用波特率、默认115200/8N1、全双工原始字节透传的功能目标保留，实际速率、电平和线缆条件须验证。RX的470kΩ下拉及漏电仍影响设备负载，不作固定扣除。

## 完成的验证

- 两页均在用户客户端保存关闭后编辑，再由用户客户端重新打开保存关闭，最后用全新后台会话明确打开本地工程读取磁盘网表、DRC及两页原生PNG。
- 全工程由142颗器件、422个逻辑引脚减为138颗、411脚，原理图DRC为空数组。
- 按批准的TX直连、器件移除和GPIO38未连接，对全工程引脚网络逐组比较通过；没有残留UART_TX_NOE网络。
- GPIO14→R79→J18的1脚、GPIO15接收通路、GPIO38未连接标记及保留器件属性、身份和串口页几何核对通过。
- 不同网络导线几何交叉为零，原生图面已导出核对；其余六页文件摘要保持原样。
