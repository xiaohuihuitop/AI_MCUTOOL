# 立创 EDA 与华秋 KiCad 阶段对比

## 2026-10-26 客户端能力补充

后续已完成[客户端样例实测](嘉立创本地客户端实测.md)：官方隐藏会话可生成实时 PCB 截图，文字和位置修改正确反映到新图；本地文件双向同步与关闭重开通过。用户提供的 `AI_TOOL` 目前是空模板，真实设计尚未迁移，单条直线创建接口的异常仍需后续核查。

下文的立创自动化体验来自网页编辑器与第三方 easyeda-agent，不能直接代表专业版桌面客户端。新核对的[官方 CLI 文档](https://prodocs.lceda.cn/cn/api/guide/cli.html)明确说明 V4.1.60 及以上客户端内置 CLI、本地桥接及 MCP，支持 `open --headless true` 隐藏渲染；`.eprj3` 文件夹工程支持 `.esch2` / `.epcb2` 文本文件与编辑器双向同步。因此，原先“KiCad 可本地自动处理、立创依赖前台网页”的概括不完整。

对于用户熟悉立创、希望工程保存在本地的需求，专业版客户端值得优先评估，尤其是半离线模式与官方 CLI。本次仅核实官方资料，尚未在本机定位并运行专业版客户端，也未实测隐藏渲染下本项目的 PCB 截图。此前第三方插件的多单元、属性写入和快照契约缺陷仍是该插件的缺陷，迁移客户端本身不会自动修好。详见[客户端调研](嘉立创EDA本地客户端调研.md)。

当前两份工程均为布局比较稿，尚未布线。立创侧已完成 J18 正式模型替换和 PCB 位号整理，原理图只完成电源页重排；其余七页仍需继续。

## 本次已经核对的结果

- J18：`PZ254V-11-03P` / C2937625，1=TOOL_TX、2=TOOL_RX、3=COMMON_GND，跨原理图与 PCB 的唯一关联 ID 不变。
- 原理图全工程原生 DRC：0 错误、0 告警。这仅证明电气检查结果，不证明八页图面都已整理。
- PCB：164 个位号统一 0.8mm 字高及 0.15mm 线宽，按原生回读包围框放置。两轮回读无连接、位置、角度、丝印或禁铜区域漂移。
- 两轮数据检查均未发现器件包围框重叠、丝印压器件/焊盘、文字越界；全部 516 个铜盘纳入保守几何检查，未发现小于 0.2mm 的板边距或小于 0.15mm 的异网铜盘包围框间距。
- 2026-10-25 已补齐第二轮官方画布截图，并再次回读全部布局数据，与第一轮无差异，两轮间没有修改布局。两轮图面核对完成；截图中的黄色交叉标记对应未布线 DRC 显示，不能据此把当前比较稿称为制造版。

## 实际使用差异

立创正式器件把料号、符号、封装和 3D 模型组合在一起，采购关联直接；仅给通用排针填料号不能代表正式模型已绑定，本次 J18 就需要真正换模型。KiCad 的符号、封装与采购料号可以独立管理，项目内封装的来源和尺寸需要单独保存依据。

此次自动化中，KiCad 文件及 `pcbnew` 便于离线提取几何；立创官方接口可以直接操作在线工程，但需要处理文档焦点、保存重载、原生实例 ID 和库 ID 的区别。easyeda-agent 1.14.0 在此工程暴露了快照契约及多单元支持缺陷，已做本地修复；这属于插件实现问题，不能据此推断 EDA 自身不支持这些电路。

## 尚未闭合

U4 天线端外伸约 6.144mm，当前整体纵向约 96.144mm；15mm 外壳净空与整机 100mm 上限仍需机械方案确认。插件另有 7 项按估算插头护套尺寸产生的间距告警，尚无实际配套插头包络证据，不能当作已证实碰撞或已证实安全。生产定位点、布线、回流、热设计及制造检查均尚未完成。

插件完整连接器测试为 1189 项通过；Go 定向测试通过，全量 Go 未全通过。当前仅本地开发验证版，无提交、推送或公开发布。
