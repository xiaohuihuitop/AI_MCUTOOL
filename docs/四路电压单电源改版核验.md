# 四路电压单电源改版核验

日期：2026-11-03。用户明确不需要接近0V时的高精度，并要求降低成本，因此取消LM7705负电源及零点偏置电路。修改限于嘉立创专业版本地工程第7页原理图，PCB仍待最后统一同步。

## 当前电路

- 移除U15（LM7705MM/NOPB）及其C20～C24五颗电容。
- 移除四路反馈/偏置电阻R46/R47、R55/R56、R64/R65、R73/R74，共八颗。
- U14/U18/U19/U20保留TLV9001IDBVR（C398363），5脚接TOOL_3V3，2脚改接COMMON_GND，1脚OUT直接连接4脚IN−。
- C19/C28/C29/C30各跨本路3.3V与公共地，保留100nF去耦。
- 保留每路单颗10MΩ上臂、1MΩ下臂、分压节点10nF、输出100Ω/10nF及ADS1115。没有新增其他负电源或补偿器件。
- 移除空的负电源分区框，图上解析更新为单电源电压跟随器。

在线性工作区，名义关系为 `VADC = VIN / 11`，不再有原1.015倍增益和约3.48mV人为偏置。软件后续仍须用实测校准系数，不能沿用旧公式。ADS1115固定±2.048V时为62.5µV/LSB，对应原输入0.6875mV/LSB；1mV读数分辨率目标保持。

## 用户确认的取舍

标称外部输入范围仍为共地正电压0～15V，无负压需求。用户接受接近0V时的偏差，不再要求该区间满足原±（读数0.2%＋5mV）精度目标。运放输出无法无限接近电源下限，失调也会影响低端读数，因此近零可能出现偏差、死区或非线性。

本轮不虚定某个电压为准确下限，也不把近零读数强制归零。离开近零区仍以原校准精度为设计目标；准确区间、校准点和温漂通过样机确定，校准点应避开饱和区。该取舍仅适用于四路外部电压检测，不改动INA228电池接口电压或电流测量要求。

TLV9001在3.3V单电源下属于其1.8～5.5V工作范围，15V/11≈1.364V的输入节点落在轨到轨输入范围内。输出100Ω继续隔离ADC及10nF负载；实际稳定性、输入漏电、Wi-Fi干扰、掉电加载和测量误差仍需样机验证。器件依据沿用[前次核验中的TI手册](四路电压降本改版核验.md)。
