# 电池端电流采样器件核验

核验日期：2026-10-22。范围仅为公共供电通路的双向电流及工具输出端电压采样。推荐原理样机采用 **TI INA228AIDGSR＋Vishay WSK2512R0200BEA**，20mΩ真正四端分流，固定宽量程；分流、VBUS各2074µs、128次平均作为初始配置。器件资料支持继续画原理图，尚无整机精度、温升或采购报价结论。

沿用已确认要求：正电压0～15V通路、双向电流幅值≤3A；电流绝对值0～10mA误差目标±100µA，超过10mA至3A为±读数1%；15～35℃、每台一次零点与增益校准、约每秒输出一组读数。电流指实际经过分流器的总电流，包含经过该通路的测量接入负载，不自动扣除固定常数。充电器5V输入总电流不属于该测点。

## INA228准确引脚与连接

INA228AIDGSR采用DGS十脚VSSOP封装。以下编号依据官方第3页**顶视图**，不得按底视封装图左右直接照抄。[S1第3页]

| 脚号 | 信号 | 本项目原理样机连接 |
| --- | --- | --- |
| 1 | A1 | 接工具GND |
| 2 | A0 | 接工具GND；A1/A0均为低时7-bit地址0x40 |
| 3 | ALERT | 开漏信号到既有预留GPIO18，上拉到工具3.3V；仅作为状态/转换就绪信号预留 |
| 4 | SDA | 接ESP32-S3 GPIO9，共用工具3.3V的I²C上拉 |
| 5 | SCL | 接ESP32-S3 GPIO10，共用工具3.3V的I²C上拉 |
| 6 | VS | 工具3.3V，近端对GND接100nF去耦；器件供电允许2.7～5.5V |
| 7 | GND | 工具公共地 |
| 8 | VBUS | 接DUT_PWR_P，即开关和分流之后的工具输出端 |
| 9 | IN− | 分流器DUT_PWR_P侧独立Kelvin端，经10Ω接入 |
| 10 | IN+ | 分流器VSEL_P侧独立Kelvin端，经10Ω接入 |

100nF差模电容跨接**芯片侧**IN+与IN−，两根采样线成对布置，远离DC/DC、天线及功率开关节点。每臂10Ω只在采样支路内，不承载3A主电流。官方建议输入滤波串阻通常≤100Ω、电容0.1～1µF；本轮10Ω＋100nF在该建议范围内，10Ω还用于改善输入dV/dt耐受。[S1第34页]

两臂合计20Ω与100nF的差模截止频率约79.6kHz，主要抑制高频干扰；约秒级读数由ADC转换与平均决定。手册差分输入阻抗为92kΩ典型，20Ω串阻造成的比例加载约0.0217%，且还要考虑阻值失配和输入条件。它不是零误差，也不是可凭典型阻抗保证的固定误差。[S1第6页；电路计算]

## 四端分流器与焊盘映射

**WSK2512R0200BEA**依据官方编码表组合：`WSK2512`型号、`R0200`表示0.020Ω、`B`表示0.1%、`EA`表示无铅卷带。其0.1%选项覆盖0.01～0.2Ω，所以20mΩ属于官方有效组合。该完整料号未核验现货、报价及供应商实际交付包装。[S2第1页]

| 参数 | 官方规格及本项目含义 |
| --- | --- |
| 端子结构 | 真正四端，载流端I1/I2与电压端E1/E2独立 |
| 额定功率 | 1W@70℃，超过70℃按官方曲线降额，到170℃为0 |
| 初始阻值容差 | 0.1%，可纳入每台增益校准；不能由此消除温漂、自热和校准仪表误差 |
| 整件TCR | 20mΩ所属0.005～0.2Ω档为±35ppm/℃；首页材料温漂小于20ppm/℃不替代整件规格 |
| 外形及封装 | 2512、约6.35mm×3.18mm；使用该阻值档的专用四端焊盘图，不能套普通两端2512封装 |

官方第3页是立体连接示意，**I1与E1在同一端，I2与E2在另一端**。E为电压采样端，I为载流端；官方图没有数字焊盘编号。图中两端较小的sense触片呈对角分布，不能凭“上排采样、下排载流”判断。绘制封装时结合第2页机械/焊盘尺寸和第3页连接图确定方向；如EDA库必须编号，单独记录自定义编号与I1/E1/I2/E2的对应，不冒充厂商pin号。[S2第2～3页]

| 官方端子 | 本项目网络 |
| --- | --- |
| I1 | VSEL_P，来自已选择的真实电池或外部电源通路 |
| E1 | 经10Ω到INA228 IN+ |
| I2 | DUT_PWR_P，接工具输出端 |
| E2 | 经10Ω到INA228 IN− |

电流从I1流向I2为正，反向为负。Kelvin线从独立E端引出，不让主电流经过E端，也不要在器件之外先用载流铜皮把E端与I端短接，否则采样会包含额外铜箔压降。充电反向电流经过相同分流器，不增加第二量程。

## 固定量程、转换时间及寄存器字段

20mΩ分流在3A时产生60mV，因此选`ADCRANGE=0`的±163.84mV宽档。±40.96mV窄档覆盖不了此目标，不设计运行中自动换档。宽档原始分流电压步长312.5nV，对应电流步长15.625µA；该量化步长不是测量精度。[S1第5～6、22、24页]

| 寄存器字段 | 主推荐初值 | 用途 |
| --- | --- | --- |
| CONFIG.ADCRANGE，bit4 | 0 | 固定宽档±163.84mV |
| CONFIG.TEMPCOMP，bit5 | 0 | 不启用内部温度补偿 |
| CONFIG.CONVDLY，bits13:6 | 0 | 不添加初始转换延迟 |
| ADC_CONFIG.MODE，bits15:12 | Bh | 连续分流电压＋VBUS转换，不转换温度 |
| ADC_CONFIG.VBUSCT，bits11:9 | 6h | VBUS单次2074µs |
| ADC_CONFIG.VSHCT，bits8:6 | 6h | 分流电压单次2074µs |
| ADC_CONFIG.AVG，bits2:0 | 4h | 两个活跃通道均128次平均 |
| ADC_CONFIG.VTCT，bits5:3 | 保留默认 | MODE未启用温度转换，不参与本配置周期 |

官方说明所有活跃通道完成相应平均后更新输出寄存器，因此双通道名义周期为`(2074＋2074)µs×128＝0.530944s`。软件约每秒读取一次作为初稿方向。两通道依次转换，不能把它们当严格同时采样。[S1第13、23～24页]

| 配置 | 双通道内部名义更新周期 | 阶跃后取得完整新窗口的时间上界量级 | 宽档noise-free ENOB典型 | 20mΩ折算噪声估计 |
| --- | ---: | ---: | ---: | ---: |
| **2074µs、128次：主推荐** | 0.530944s | 接近2周期，即1.061888s | 18.7位 | 约38.5µApp |
| 2074µs、256次：比较 | 1.061888s | 接近2周期，即2.123776s | 19.7位 | 约19.2µApp |

ENOB取自手册第33页表8-2；该表的265.472ms/530.944ms为单通道转换时间乘平均次数，不能直接当双通道更新周期。噪声按`327.68mV/2^ENOB/20mΩ`估算，是由典型表格反推的峰峰量级，**不是最大保证，也不是含全部误差的精度**。[S1第32～33页]

连续平均时，电流在一个窗口中间变化，下一组输出可能混有变化前样本，再下一组才全部来自变化后。因此刷新周期不能直接当任意阶跃后的稳定时间；软件约每秒轮询还会叠加读取延迟，芯片时钟公差、模拟电路和热稳定也影响最终时间。128次更接近已确认的约1秒等待量级，但不保证“阶跃后恰好1秒就能读到达标值”。此处不新增自动重启转换、自动丢弃样本、动态切换平均次数或自动调零行为。

如使用CURRENT寄存器，宽档换算公式为`SHUNT_CAL＝13107.2×10^6×CURRENT_LSB×RSHUNT`。选`CURRENT_LSB＝15.625µA`、名义20mΩ可得`SHUNT_CAL＝4096`，计算跨度约±8.192A；**工具额定仍为±3A**。这一数值只是名义换算初值，不代表已完成实际零点/增益校准，也不提高ADC真实分辨率。[S1第24、30～31页]

## 信号与误差预算

| 实际电流幅值 | 20mΩ上的分流信号 | 含义 |
| --- | ---: | --- |
| 100µA | 2µV | 与芯片失调、焊点热电势同属微伏量级 |
| 1mA | 20µV | 校准和小电流验证点 |
| 10mA | 200µV | 已确认绝对/相对误差分段交界 |
| 3A | 60mV | 分流器耗散0.18W；占板内150mV总压降目标中的60mV |

INA228表列电气规格默认25℃、VS3.3V、VCM48V，另列测试条件者除外。±1µV最大输入失调有转换时间>280µs条件；手册分别列出VCM0V和48V条目。本配置2074µs满足转换时间条件，但仍需对实际0～15V共模、15～35℃和布局进行验证。[S1第5～6页]

| 误差项 | 20mΩ下的影响或计算示例 |
| --- | --- |
| 输入失调最大±1µV | 等效±50µA；零点校准能修正当时的固定偏移，不消除后续漂移 |
| 失调漂移最大±10nV/℃ | 等效±0.5µA/℃；若25℃校准，到15/35℃的10℃变化对应约±5µA |
| INA228增益误差最大±0.05% | 3A处对应±1.5mA，条件见官方电气表 |
| INA228增益漂移最大±20ppm/℃ | 相对校准点10℃变化对应±0.02%量级 |
| 分流器初始容差±0.1% | 未校准时3A处对应±3mA |
| 分流器整件TCR±35ppm/℃ | 相对校准点10℃变化对应±0.035%；分流器自身温升还需另外计入实际温差 |
| 量化步长15.625µA | 表示相邻原始码间隔，不直接按一整步当作独立最大误差相加 |
| 128次平均的典型噪声估计约38.5µApp | 提供噪声量级参考，不可代替实测分布或最大误差保证 |
| 输入滤波串阻与输入阻抗 | 约0.0217%的典型比例加载，须纳入增益校准及实测，不能忽略 |
| 布局、热电势、外部接线和校准仪表 | 无现成整机保证值，必须由样机和参考仪表建立预算 |

上述项目的测试条件和统计含义不同，不能把它们简单当作全部独立、全条件最大项相加后宣称已闭合。ENOB噪声统计已经反映ADC输出结果，不能再把其已包含的量化贡献作为独立噪声重复相加。3A处允许误差为±30mA，器件初始增益及分流容差有一定余量；小电流±100µA目标对应仅±2µV输入预算，主要困难是失调、噪声、温差和校准边界，不能靠“20位ADC”直接保证。若要严格判断设备是否低于100µA，±100µA的工具误差本身不足以在阈值附近作可靠判定；本轮仍保持用户已确认目标，不改成新的验收指标。

1W额定给0.18W分流耗散留出功率余量，但额定功率不代表0.18W时温升可忽略。应验证3A工作后的热稳定、回到小电流后的零点变化，并避免接插件和采样焊点处温差形成热电势。[S2降额曲线；电路分析]

## 测量负载、电压与共模边界

VBUS接DUT_PWR_P，测开关及分流之后的工具输出端电压，不含外接线缆压降。手册活动状态输入阻抗0.8～1.2MΩ，15V时取电约12.5～18.75µA，实际值待验证。这个负载经过分流器时属于定义内的总电流，不是应自动扣除的芯片测量误差；设备未接时仍不一定有零电流。[S1第6页]

INA228的VS由工具3.3V独立供电，电气表列工作电流典型640µA、最大750µA，不能把该电流直接加到被测设备电池负载。IN+/IN−偏置表中的2.5nA最大值对应VCM85V的特定条件，不能直接当作0～15V全范围最大值。[S1第6页]

VBUS原始步长195.3125µV，满足1mV显示分辨率的数值条件；表列偏移最大±2.5mV的测试点为VBUS20mV，增益误差最大±0.05%。这些参数不等于已证明全0～15V、15～35℃的电池接口电压目标达标，仍需单独做零点/增益校准及验收；四路外部电压输入≥5MΩ的要求不套到VBUS。[S1第6页]

INA228输入共模允许−0.3～85V，VBUS测量范围0～85V。对本工具接近0V的双向电流，须分别核对IN+、IN−实际电压及各自引脚允许范围：20mΩ在3A反向时两端相差60mV，不能仅凭“共模支持0V、支持双向”推导任意一个端子允许继续向负压延伸。线缆及开关瞬态同样须按逐脚极限检查。[S1第5～6页]

官方允许VS与被测总线电压独立先后上电，不会仅因该顺序损坏芯片；这不替代整机I²C、ALERT、保护器件及外部接线的掉电反灌核验。[S1第12页]

## 样机阶段首先验证的项目

1. 核对EDA符号/封装的DGS顶视引脚，以及WSK专用四端焊盘和I/E映射；检查载流线、Kelvin线和VBUS实际测点。
2. 在定义一致的总电流边界接入参考仪表；零点夹具不能把VBUS及其他真实负载直接归零。参考仪表不确定度、校准温度、读数时间及零点噪声均需记录。
3. 覆盖双向100µA、1mA、10mA、分段交界两侧及3A；检查不同共模、15～35℃、Wi-Fi收发、供电噪声和大电流后回到小电流的变化。
4. 分别记录ADC更新时间、电流阶跃后的首个混合窗口及完整新窗口；测试128次平均能否同时满足噪声目标和约秒级使用体验，不能凭平均次数直接宣称已达标。
5. 验证VBUS及四路电压探线接入前后的实际取电，检查串口及其保护/上拉是否形成额外供电或回流路径；参考仪表读数必须对应同一个电流边界。
6. 验证3A温升和压降、接近0V时正反向引脚电压、输入热插拔及供电切换瞬态；本模块不增加过流自动关断、运行中调零或温度补偿。
