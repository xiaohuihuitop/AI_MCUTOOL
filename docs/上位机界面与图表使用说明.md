# 上位机界面与图表使用说明

适用于 MCU TOOL 0.4.1、工具板固件 0.1.2。六路固定每路每秒 10 次；四路外部电压依次转换，共用时间轴并不表示同时采样。桌面版与浏览器使用同一界面和真实采样数据。

## 页面

- **供电与测量**：左侧供电、充电和按键；右侧电池电压、电流数值与双轴曲线。
- **四路电压**：AIN1～AIN4 的最新数值和共用时间轴的四条曲线。
- **串口与记录**：目标串口收发及原始数据记录。
- **操作记录**：人工和 AI 的操作结果、来源、任务编号与连接事件。
- **设备设置**：Wi-Fi、校准、供电切换参数，以及“后台与客户端”、诊断导出和退出。

## 电池图表

蓝色实线为电池接口电压，读左轴；橙色虚线为电池端电流，读右轴，单位为 mA。最新数值固定在图内上方；暂停曲线时最新数值仍会更新。

“时间游标与统计”默认关闭。打开后，拖动 A、B 或直接填写时间，查看两个时刻的电压、电流，以及区间最大值、最小值、平均值和净电量。关闭该开关只收起分析内容，保留所选区间。

- 平均值按时间加权，不是简单地平均所有样本。
- 净电量以 mAh 显示，按电流正负方向累计；正值表示经测量通路向被测设备供电，负值表示反向流动。它不是电池标称容量或剩余电量。
- 游标落在相邻有效采样之间时显示线性插值读数。缺失、无效读数和超出保留历史的区间不进行相应积分或统计。
- 每组图表保留最近 4 小时的完整原始采样，可以查看和统计超过 3 小时的波形。超过上限会明确提示；旧选区不自动移动，可点击“重选当前历史”。
- 不同设备或不同启动的数据不拼接。更换设备或设备重启后，重新建立该段历史和游标。

未校准、超量程、校准无效和过期状态仍显示在读数旁。统计功能不提升硬件采样频率或测量精度。

## 四路电压图表

每路数值始终显示，曲线隐藏不停止采集。

1. **点通道名称**：只能选中一路，Y 轴刻度随所选通道变化；所选曲线为实线，其余为虚线。选择隐藏通道不会自动显示它。
2. **点“曲线显示／曲线隐藏”**：只切换该条曲线显隐，不修改通道选择和最新数值。
3. **电压 / 格**：单位为 V。例如 1 表示一格为 1 V，0.001 表示一格为 1 mV。数值越小，波动显示越大。
4. **偏移 / 格**：正数向上、负数向下。偏移为 0 时，0 V 在中线，上正下负。它只移动显示位置，不是测量校准。
5. **颜色**：每路独立选择，曲线和标识同步变色。

四路纵向比例各自独立，不能把其他曲线的高度直接按当前所选通道的 Y 轴读成电压。最新数值和悬停读数始终显示各自真实测量值。

上述显示设置在当前页面会话内有效，重新加载页面后恢复初始设置；它们不会改动工具板的测量校准。

## 鼠标操作

| 位置与动作 | 效果 |
| --- | --- |
| 图内滚轮 | 缩放共用时间轴；实时模式保持右侧最新采样持续更新 |
| 拖动图内空白处 | 平移并进入历史回看，采集继续 |
| 回到实时 | 恢复最新采样跟随，保留缩放跨度、纵轴与A/B区间 |
| 电池图左右刻度区滚轮／拖动 | 分别缩放／平移电压和电流轴 |
| 四路图左侧刻度区滚轮／拖动 | 仅调整当前选中通道的比例／偏移 |
| 拖动 A、B | 改变统计区间 |
| 暂停显示 | 冻结该图的曲线和统计样本，后台采集与原始记录继续 |
| 双击或恢复视图 | 恢复跟随时间和默认纵轴；保留 A/B、颜色、通道选择和曲线显隐 |

时间轴显示相对于本图起点的秒数、分秒或时分秒。曲线按设备实际采样时间绘制；超过 0.25 秒、明确丢样或无效点处断开，不跨缺口计算电量。长时间绘图保留每像素的首尾和极值，游标、统计及导出仍使用完整原始采样。

## 开始、暂停、清空和导出

电池图有独立的一组按钮；四路电压共用另一组。两组互不影响，连接后默认显示。

- **暂停／开始**：暂停冻结本图曲线、时间范围和统计，读数与后台采集、文件记录继续。开始恢复包含暂停期间新采样的历史并跟随最新数据，保留缩放跨度。
- **清空**：清除本图保留的波形和 A/B 游标，从下一份新样本建立新的时间起点。保留通道颜色、比例、偏移和显隐。暂停时清空仍保持暂停。已保存文件保留。
- **导出**：将本图当前保留的全部历史导出为 UTF-8 无 BOM CSV。电池图导出电压和电流；四路图导出全部四路，包括隐藏曲线。暂停时导出冻结的历史。桌面版弹出保存位置选择，浏览器使用下载。
- CSV 包含设备、启动、绝对采样秒数、相对秒数、通道、数值、单位、质量和断点。电池电流原始单位为 **A**，图中显示为 **mA**；无效或缺失值不补零。导出范围是全部保留历史，不仅是可见窗口或 A/B 区间。
- 页面刷新、关闭程序或后台/设备重启会重新建立显示历史。需要跨会话或超过 4 小时保存时，提前在“串口与记录”开启持续记录；文件记录没有固定时长上限。
