## 使用目标与职责

- 服务开发者自己的 MCU 项目，供 AI 调用。
- 工具提供模拟人工操作的硬件能力及测量数据。
- 项目侧 AI 编排测试、解释设备串口日志、结合其他工具获取的信息判断结果。
- 项目开发时设计相应状态输出；测试流程及合格阈值由具体项目确定。

## 通用性与适配原则

- 被测设备会随项目变化，工具提供可复用的操作和测量能力。
- 调用能力由工具接口参数及已明确的电气额定值决定，不要求特定设备型号、电池类型、工作功率、休眠行为或状态日志格式。
- 测试步骤、日志解释、工作与充电状态关系、合格阈值均由具体项目和项目侧 AI 定义。
- 工具自身的测量量程、接口电平、通路额定电压电流和保护互锁属于适配条件；这些条件应在规格及能力说明中明确。
- 四路电压检测与供电切换通路的额定值分别定义；用户已分别认可两者的 0～15V 设计目标，具体器件及整机能力仍待验证。

## 已确认工具能力

| 能力 | 需求边界 |
| --- | --- |
| 按键模拟 | 五路独立无极性触点，每路两个接线端，各路不强制共地；两端电压差不超过 6V、电流不超过 20mA；支持单击、长按、连续点击及组合，设置步进 1ms、最短按下/释放间隔以 10ms 为目标，本地执行，物理时序须验证 |
| 真实电池通路 | 电池经工具连接被测设备，用于正常运行及充电测试 |
| 外部可控电源接入 | 外部可控电源承担电池模拟等可控供电任务，本工具负责接入、通路选择及测量；端口支持电压由工具通路额定值确定，不按示例设备限定为 2.8～4.3V |
| 供电通路切换 | 控制真实电池与外部电源通路选择，允许设备断电；设计目标为正电压 0～15V、双向 3A |
| 充电输入模拟 | 外接独立 5V 充电器，本工具控制 5V/2A 充电通路通断，在真实电池通路进行充电测试 |
| 电池电压及电流测量 | 固定量程、充放电双向测量，电流幅值上限 3A；绝对值 0～10mA 的误差目标 ±100µA，超过 10mA 至 3A 为 ±读数的 1%；约每秒 1 组稳定电流读数；环境 15～35℃、每台一次零点与增益校准，实际精度待硬件验证 |
| 外部电压检测 | 四路共地、正电压、0～15V，分辨率 1mV；用户接受近零偏差，准确下限待实测；离开近零区以±（读数的0.2%＋5mV）为目标，输入阻抗≥5MΩ，约每秒完成一轮四路顺序采样；精度验收条件为 15～35℃、每路零点与增益校准，无负电压需求 |
| 串口 | 一路 3.3V TTL UART，9600～921600 常用波特率可配，默认 115200、8N1，无 RTS/CTS；全双工原始字节透传；TX经100Ω直连，由AI显式启用；初始化及禁用时GPIO14设为输入、无上下拉，RX仍可接收，上电/复位阶段引脚表现待验证 |
| 电脑通信 | Wi-Fi保留；2026-11-04新增现有Type-C的原生USB下载、日志及双向命令交互，固件支持待实现 |

模拟电池的电压调节、输出功率及稳压由外部可控电源承担，本工具不集成可调电源。项目侧 AI 通过外部电源自身接口直接控制它，不经本工具转发；本工具负责接入、通断、切换和测量。

## 主控与硬件方案

- 用户指定 ESP32-S3 N16R8 配置，并确认 ESP32-S3-WROOM-1-N16R8 模组直接焊在工具 PCB 上。
- 2026-10-20 确认两路供电选择采用背靠背 MOS 开关，保留各支路独立关闭、两路互斥及先断后通；具体 MOS 和驱动器型号待定。已确认 3A 时板内总压降不超过 150mV 为设计目标，包含开关、采样电阻、走线和板载端子，不含外接线；本地切换动作按 100ms 量级设计，不包含网络传输、设备电容放空或设备重启，实际互锁间隔待验证。
- 2026-10-20 确认独立 5V/2A 充电通路也采用背靠背 MOS，只切正极、地保持连接，关闭时双向阻断；具体器件待定。2A 时开关、走线及板载端子总压降目标不超过 100mV，不含外接线；本地通断动作按 100ms 量级设计，不包含充电口残余电压消退或设备识别插拔时间，沿用真实电池充电互锁。
- 已完成 [主控适配评估](ESP32-S3-N16R8主控适配评估.md)，官方 WROOM-1-N16R8 模组资源满足首版需要。
- [硬件方案](MCU开发辅助工具硬件方案.md)已整理模块连接和 17 根 GPIO 提案；原理图及 BOM 尚未定版。
- 用户已认可五路按键的原理图初稿方案：TLP176AM＋onsemi MMBT3904LT1G，LED限流240Ω、基极680Ω、B-E下拉10kΩ，五路复制；[器件核验](五路按键驱动器件核验.md)及具体连接已整理，仍需样机验证后定版。
- [双向功率开关评估](零至十五伏双向功率开关评估.md)已核验光伏驱动配合背靠 N-MOS 的低电压通路候选；[BOM 与供电核算](首版BOM核价与供电核算.md)记录局部公开价格及工具自身功耗，均不代表整机已达标。
- 用户已认可两路主供电的原理图初稿：每路 VOM1271T＋两颗CSD17577Q3A＋MMBT3904LT1G，输入限流100Ω、基极330Ω、B-E下拉10kΩ；[单路器件核验](双路供电开关单路器件核验.md)、逐网络连接及两路控制关系已整理。该方案待原理样机验证VGS、瞬态、动作和压降后定型，充电通路单独细化。

- 电池端采样原理样机推荐INA228AIDGSR＋WSK2512R0200BEA（20mΩ/0.1%/四端、1W@70℃、整件TCR±35ppm/℃），每臂10Ω并在芯片侧跨接100nF差模滤波；[器件核验](电池端电流采样器件核验.md)及硬件方案记录具体连接。固定宽档覆盖±3A，3A时分流压降60mV、耗散0.18W；VBUS继续测分流之后的工具输出端。保留已确认误差目标及校准要求，尚未实测达标，分流器库存、报价和采购后缀仍需复核。
- 2026-11-03用户确认四路电压采用ADS1115IDGSR＋TLV9001IDBVR（C398363）×4、3.3V单电源跟随器，取消LM7705负轨及偏置反馈。每路单颗10MΩ/1MΩ分压，0.6875mV/LSB，约1秒四路一轮。用户接受接近0V时的偏差，不再承诺该区间原精度；准确下限待样机确认，其他输入负载、采样目标保留。详见[单电源改版核验](四路电压单电源改版核验.md)。
- 2026-11-03用户确认删除TX缓冲U16（SN74AUP1G125DBVR）及R76/R77/C26，GPIO14经R79=100Ω直连目标TX；GPIO38释放为预留。RX保留U17及R78/R80/C27。禁发送由GPIO14输入、无上下拉实现，直连后的启动/复位和掉电反灌能力待实测。详见[串口发送直连改版核验](串口发送直连改版核验.md)。

## 工具供电

- 用户于2026-10-23确认工具DC与Type-C均统一使用5V，取消工具12V输入支持，并改用LDO生成3.3V工作电源。适配器按5V/2A选择；DC仍为5.5×2.1mm、内正外负，丝印标明5V。该变更仅作用于工具自身供电，设备通路及四路电压测量的0～15V目标继续保留。
- 2026-11-04确认Type-C兼作5V供电、原生USB下载、日志及双向命令交互，不做PD升压协商；保留CC识别电阻和原供电链路。人工二选一：USB接电脑时不接DC，DC供电时通过Wi-Fi使用。电脑USB口供电能力和Wi-Fi瞬态须样机验证。
- 两路经防倒灌通路汇合后共用稳压，避免给闲置输入口回送电压；不要求同时供电、优先级管理或不中断切换，具体器件及压降待核算。
- 已确认不增加独立电源开关，插入所选有效工具电源即启动，拔出该电源后断电，上电默认状态沿用已确认规则。
- 人工选择适配器；当前不引入供电预算识别或自动调整输出策略。
- 充电用 5V 由独立外接充电器提供，本工具不集成充电用 5V 电源变换器。
- 设备充电输入与工具 DC/Type-C 自身供电正端分开，共用参考地；设备充电输入采用 2.54mm 排针。
- 本工具仍需为主控、测量和开关控制电路提供内部工作电源，其功耗及电源电路单独核算。
- 2026-11-04用户最终确认工具稳压U3采用微盟ME6211A33PG-N（C236673，标称500mA），接受电流余量取舍；前级保留两颗SS34，C3/C4均为10µF/16V/X7R陶瓷（C408142）。工具仍为5V双入口人工二选一、单级3.3V LDO。详见[替换核验](工具电源C236673替换核验.md)，PCB待统一更新。
- 0.75A是历史供电预留验证值，并非实测持续电流或最大耗电。实际平均值与Wi-Fi瞬态须样机确认；例如假设平均200mA，5V到3.3V线性路径损耗约0.34W，属于算例。5V/2A适配器供工具自身，不包含外部设备功率；前级SS34压差、输出电容稳定性、温升与掉电表现待验证。

## 成本与尺寸

- 外部测试接口全部采用2.54mm排针，覆盖电池及外部电源通路、充电通路、按键、电压检测和UART；2026-10-23确认首版使用朝上的直排针，四路电压接口各为独立1×2排针，1脚AIN、2脚GND，四个地针在板内共地。工具自身供电采用已确认的DC和Type-C。主通路3A、充电2A的设计目标继续保留，具体排针及配套连接件、线材承流和压降待核验。
- 单台元器件 BOM 以不超过 200 元为选型目标；PCB、焊接、外壳、适配器和线材单独核算，目标尚未经过器件查价验证。
- 整机外形不超过 100mm × 100mm × 100mm，包含固定接插件，不含外接线缆。

## 上电与通信中断行为

- 工具上电或重启后，五路按键触点全部断开，充电输出和被测设备供电均关闭，由 AI 显式启用。
- 对外部可控电源，以上关闭状态指本工具的供电通路断开，不代表外部电源自身输出被关闭。
- Wi-Fi 通信中断时，保持当前被测设备供电及充电输入通断状态。
- 已下发的定时按键操作继续按原定时长执行并释放，不因通信中断而延长。
- 重连后由 AI 读取实际状态，再决定后续操作。

## 已确认的读数等待与充电互锁

- 电池接口电压测点已确定在开关及采样电阻之后的工具输出端，不包含外接线缆压降，也不占用四路外部检测接口。目标为 0～15V、1mV 分辨率、约每秒 1 组，误差 ±（读数的 0.2%＋5mV），验收条件为 15～35℃且完成零点与增益校准；具体器件及实际表现待验证。
- 电池端电流读数定义为实际流过采样电阻的双向总电流，包含经过该通路的测量接入负载；披露这些负载，不自动减去固定常数，不将读数直接解释为设备未接工具时的自身耗电。
- 不增加供电输出主动放电电路；供电通路关闭不代表被测设备端电压立即归零。
- 允许约 1 秒的稳定读数等待量级，实际采集稳定时间经硬件验证确定。
- 2026-10-21 确认电流读数约每秒 1 组，不承诺捕获启动瞬间电流峰值；0～10mA 的误差目标 ±100µA，超过 10mA 至 3A 为 ±读数的 1%，以电流绝对值分段，两个方向相同。精度验收条件为环境 15～35℃、每台完成一次零点和增益校准；具体器件、校准方法及整机表现仍待验证。
- 只有真实电池通路允许开启充电输入；切换到模拟电池前必须先关闭充电输入。
- 对上述条件冲突的命令，工具拒绝执行并返回原因，由 AI 调整调用顺序。

## AI 接入、配网与数据保存

- 2026-11-04用户确认删除J3五针下载排针，改用Type-C直连ESP32-S3原生USB Serial/JTAG；GPIO19/20各串22Ω，接口添加D5静电保护。BOOT/RESET/CONFIG保留，GPIO43/44预留未连接，与被测设备业务UART分开。详见[原生USB接口改版核验](原生USB接口改版核验.md)。
- 本机配置 BOOT、RESET、配网三个独立小按键，以及一颗电源 LED、一颗状态 LED；配网按键具体长按时间及状态灯闪烁规则在固件设计中确定。
- 调用链路为：电脑端 MCP 服务 → 局域网 HTTP API → 工具设备。
- 电脑端向 AI 提供工具能力；设备固件执行命令并返回数据，项目侧 AI 负责测试编排。
- 首次配网由人工通过手机或电脑连接工具配置热点，填写目标局域网信息。
- 再次配网由人工按键触发；正常运行失联时不自动切换为配置热点。
- 长期测量记录和串口日志保存在电脑端，工具设备只保留短时内存缓存。
- 工具断电后，尚未传出的缓存会丢失；电脑端明确标记数据缺失。

## 功能优先级与项目测试流程

首版提供按键操作、供电通路控制、充电器插拔模拟、电压电流测量及串口收发。项目侧 AI 可按实际设备组合这些能力，自行定义操作顺序及结果判定。

首版暂不实现模拟波形与数字时序采集。
