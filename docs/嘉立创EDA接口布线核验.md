# 嘉立创 EDA 接口布线核验

日期：2026-11-05。主工程：`D:\LCEDA\projects\AI_TOOL\AI_TOOL.eprj3`。

## 结果

本轮通过嘉立创专业版 4.1.78 的官方 CLI/API 完成布线、覆铜重建与保存。未通过改写工程源码添加铜线；原理图、器件选型、器件布局、中文丝印、28 个焊线孔、板框和制造规则保持。

保存重开后为 **957 条铜线、157 个过孔、4 块覆铜**。实际使用窗口和逐文件摘要一致的独立后台副本，原理图及 PCB 的原生 DRC 均为零。140 颗器件、415 个逻辑引脚的完整网名和 Unique ID 一致；423 个器件焊盘及 28 个独立镀铜焊线孔均保留。

## 布线安排

| 部分 | 本轮处理 |
| --- | --- |
| 主电流通路 | 3A 主干采用 2.5mm；分流器电流端局部采用 1.2mm；MOS 并联源脚各以 0.3mm 短支路汇入 1.2mm 母线 |
| 独立充电 | 2A 通路采用 2.0mm 铜线，保留独立充电输入与产品充电输出 |
| 电流采样 | 四端分流器的电流端和采样端独立引出；滤波后负采样线由约 12.59mm 缩短至 4.32mm |
| 工具供电 | 3.3V 和公共地以短线、过孔接内层平面；LDO 输入散热铜仍为 LDO_VIN，保留 6 个输入网络散热过孔 |
| USB | 成对主段置于顶层，宽 0.30mm、名义间距 0.18mm；保持邻近 L2 公共地参考；先为 Type-C 并联供电脚留出 0.6mm 出口，再补回接口端局部信号线 |
| 四路模拟输入 | 保留分压、高阻节点、输入滤波与运放局部反馈的短连接 |
| 普通信号 | 常规宽度至少 0.20mm，按原有间距规则检查；通孔采用 0.60/0.30mm |
| 接口和天线 | 保留排针与 28 个同网焊线孔、中文用途标识和天线禁布区 |

已逐段比较 123 段关键走线及 120 段供电扇出对应的实际铜几何，并检查主通路各端点之间的宽铜连通。编辑器会合并共线线段、把端点归并至焊盘中心，几何比较允许 3µm 的量化及归并误差；没有放宽 PCB 制造规则。

## 验收依据

1. 实际窗口保存、关闭 PCB 图页并重开，原生严格 PCB DRC 为零。对应原始回包：`docs/temp/pcb-routing-20261105/post-route-check.json`。
2. 完整网表逐脚核对 415 个逻辑引脚及器件 Unique ID，原理图 DRC 为零；八页原理图文件 SHA256 与布线前一致。
3. 后续核验时，全部物理铜线、过孔、焊盘、覆铜、器件、网络和规则记录，与上述已通过 DRC 的快照一致。一次额外重复 DRC 调用超时，未将其超时返回作为验收结果。
4. 将整个工程目录复制到独立临时目录，逐文件 SHA256 一致，再以隐藏渲染会话重新打开。副本原理图和 PCB DRC 均为零，线段及过孔统计一致。
5. 后台导出顶面、底面及双面原生画布，包含多层通孔焊盘和焊线孔；不需要桌面截图或用户切换前台。

详细机器记录：`hardware/easyeda-local/api-routing-check.json`。本轮原始接口调用、候选几何及回包位于 `docs/temp/pcb-routing-20261105/`。

原生布线器的成功计数不能代替上述验收。本轮分批布通后，修正了 5 处实际断点和 3 处加宽电源铜附近的间距问题，均通过官方图元接口完成。覆铜边框解除锁定后可正常使用官方接口重铺，本轮没有改写填充数据。

## 地参考与实测边界

已从接口回读的实际填充轮廓检查 L2 公共地：USB 成对主段的中心投影没有跨越地层分割或长槽。四处孔盘避让靠近主线边缘，边缘退铜投影合计约 0.114mm²，已在机器记录中保留位置；不能据此宣称全线已完成制造阻抗验证。

当前名义四层叠层为 1.6mm 板厚，USB 的实际阻抗仍需按板厂介质、铜厚和生产层叠确认。DRC 和几何核验不代替样机的 USB 通信、压降、温升及测量精度验证。本轮没有投板。
