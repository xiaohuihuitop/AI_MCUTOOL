## 实际改进

1. **三路模拟输出去回折、清理冗余铜环。** U14/U18/U19 输出支线原先与反馈线围成冗余铜环；缩短回折段，并去掉重合段、焊盘内部无用短段和铜环的多余支路。反馈 OUT→IN− 及 OUT→ADC 串联电阻两类路径，各三路均由插件按实际铜线证明为顶层、零过孔连通。
2. **USB 地参考边缘余量改善。** 保持主段 0.30mm 线宽、名义 0.18mm 间距，成对调整局部位置并将 MCU 复位线向板边让出 0.15mm。中心投影不跨地层分割；主线边缘落入孔盘避让区的投影面积由约 0.114mm² 减少到约 0.055mm²，减少约 52%。这是几何余量指标，不是性能提升比例或制造阻抗认证。
3. **清理 USB 重叠铜线并整理转角。** 删除约 0.303mm 的重复短线，普通新改线路采用直线/45°连接。没有新增器件或过孔。

三路输出/反馈网络全部铜线中心线总长度，包含同网分支：

| 网络 | 优化前 | 优化后 | 减少 |
| --- | --- | --- | --- |
| U14 输出/反馈网络 | 13.338mm | 10.874mm | 2.464mm |
| U18 输出/反馈网络 | 13.338mm | 10.916mm | 2.422mm |
| U19 输出/反馈网络 | 13.338mm | 10.916mm | 2.422mm |

局部回折段由约 1.36～1.42mm 缩短到约 0.53～0.55mm；上述全网总长度还包含随后消除冗余铜环的收益，二者不是同一口径。

## 插件提示与覆盖限制

插件 DFM 警告由 **216** 条变为 **213** 条，锐角提示 9→6，重复段 1→0，重建的间距错误始终为 0。插件的综合布局分维持 64.7，结论为 `incomplete`；本轮未以提高分数为目标搬动已确认的布局。

原始 `pcb check` 的 `passed:false / incomplete:true` 保留，不能宣称插件 DFM 全部通过。主要解释如下：

| 提示 | 实际核对与处理 |
| --- | --- |
| 11 个多边形焊盘不支持 | 插件覆盖限制，涉及 Type-C、电源 MOS、LDO 等。未把它们当空几何；保留原始观测，使用完整官方焊盘数据核对，并以原生 DRC 验收整板连接和间距 |
| 34 个悬空端点 | 用完整 451 焊盘几何核对，34 个均接触同网实际焊盘；插件清单不包含 28 个独立焊线孔，另有多边形焊盘覆盖缺口 |
| 33 个单层过孔 | 30 个属于 TOOL_3V3，3 个属于 LDO_VIN，分别连接内层电源面或散热铜，保留 |
| 2 个过孔压焊盘 | 按真实 OVAL 及旋转计算，两处铜重叠面积均为 0；钻孔与焊盘的间距约为 0.511mm、0.158mm，未为消除误报移动过孔 |
| 通用 3W、地线宽度 | 需结合差分耦合、并行长度、平面及实际支路电流判断；不是通用值覆盖项目要求的依据。未放宽制造规则 |
| 插头间距、天线、Mark 提示 | 插头外壳包络含估算，当前为用户确认的直排针与焊线孔；天线禁布区保持原核验几何。贴片与外壳装配边界仍需按实际工艺检查 |

解锁反馈线时，编辑器在已有交叉点自动拆分线段，原删除计划的数量断言因此停止。已回读完整实际线段，按新 ID 生成新的清理计划，没有跳过失败步骤或重放旧删除队列；最终六份路径证明和两轮 DRC 覆盖其恢复结果。
