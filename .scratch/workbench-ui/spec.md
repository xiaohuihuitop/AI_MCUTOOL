# 上位机浅色工作台与测量图表

用户于 2026-11-13 确认交互预览并授权正式实施。

## 已确认范围

- 浅色、紧凑工作台，以供电和电池测量为主；保留现有控制、记录、校准、诊断与桌面功能。
- 电池电压、电流最新数值与双轴图合并；左侧电压、右侧电流，共用时间轴。
- 鼠标拖动平移、滚轮缩放；纵轴可分别调整；恢复视图；保留显示暂停。
- 单一开关控制 A/B 游标和统计，默认关闭。开启后显示两时刻读数及区间极值、时间加权平均值、带符号净电量 mAh。关闭保留选区。
- 操作记录独立页面。
- 四路电压独立页面，同一时间轴；每路独立 V/格、偏移/格和颜色。
- 四路零偏移时 0 V 在中线，上正下负。名称按钮单选，所选通道提供 Y 轴刻度、显示实线，其余虚线。
- 另设曲线显隐按钮，只影响曲线；数值持续显示，名称选择与显隐互不联动。附清晰操作提示。
- 同一设备同一启动的数据才能进入同一图表；无效点、采样缺口不得连线或跨缺口积分，历史不足明确提示。

## 实施边界

前端接真实接口，无示例数据进入生产。沿用既有 2.5 秒连续采样间隔判据和前端缓存规模，不改固件及硬件输出规则。不新增自动重连、兜底协议或其他降级路径。不提交或推送 Git。

## 验证

类型检查与前端构建；测量数学的单位、插值、缺口、跨启动与时间加权积分；浏览器验证真实后台测试夹具闭环以及新增图表交互；重新打包包含新网页的桌面交付物。测试设备不代表实板精度验收。
