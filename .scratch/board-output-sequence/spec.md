# 三路开关板上时序

真实电池通路、外部电源通路和充电器通路由 ESP32 计时。上位机一次指定每步持续时间、重复次数、正常结束状态和取消状态。通信中断或写权到期后，已受理的有限序列继续运行。串口不在此次范围内。

复用已有按键时序、充电循环和单次供电入口。新增混合序列使用全断、真实电池、外部电源和真实电池并充电四种组合。两路主供电互斥，充电只允许真实电池供电。AI 编排换源时在两种通电状态间显式安排全断段，时长至少为设备当前的先断后通保护间隔；固件在接受动作前检查整个序列及重复边界。

每个完整输出段的精度目标为 ±5 ms。板端保存完整段的最大调度延迟。实物验收按接口测量真实输出边沿，分别报告负载、接线、仪表、持续时间与取消后的状态。
